先查技能，再动手

技能只有被主动路由才会被用上。请求恰好命中 description 时技能会自动生效——但那是被动的。把下面五条规则粘贴进你的全局指令文件（ZCode：~/.zcode/AGENTS.md · Claude Code：~/.claude/CLAUDE.md · 其他工具用等价的全局指令文件），agent 就会在每个任务开始时主动找技能。完整说明见 GLOBAL-RULES.md。

  1. 任何专业任务开始时，先查已安装技能里有没有匹配项：扫各 SKILL.md 的 description 触发词（「当用户…」「Use when…」「Do NOT…」）。
  2. 任务进入新阶段或遇到新子问题时再查一次（写作→发布、数据→图表、草稿→审计都是换技能信号）。
  3. 命中后先读完整个 SKILL.md 再开工，遵守其流程与边界（尤其 Do NOT）；技能写明「交给 XX 技能」时，把那个技能也查出来一起用。
  4. SKILL.md 的约定与你的默认习惯冲突时，以 SKILL.md 为准。
  5. 查不到匹配就正常干活，不许硬套技能。

已克隆仓库？检索器 python3 skills/meta/skill-finder/scripts/find_skill.py search <关键词>（中英文均可）；多步任务查 skills/skill_chains.json——每域有编排器（entry），按链的 step 推进。
