# 方向 v2：通用场景工作流库（Scenario Workflow Library）

> 状态：**现行战略**。本文档取代《EXPERT-REVIEW-AND-ROADMAP.md》§四"中国内容平台垂直"的裁决——该结论降级为本战略下的**第一个已验证品类**，而非终点。
> 制定依据：agentskills.io 开放规范（2025-12-18 发布，持续演进）、Anthropic Skill Authoring Best Practices、SkillsBench / AgentSkillOS 论文实证数据、2026-08 生态调研。配套规范见《SKILL-STANDARD-v2.md》。

---

## 一、产品重定义

**一句话：把普通人与 AI 对话中磨出来的隐式工作流，封装成机器可执行的标准技能包——用户下载、丢给 AI、说一句话，整条流程自动跑完。**

三个等价表述：

| 表述 | 含义 |
|---|---|
| **提示词的 npm 化** | 散落在个人聊天记录里的提示词串 → 可版本化、可分发、可一键安装的公共资产 |
| **工作流的显式化** | 人脑中的隐性流程（问需求→写 prompt→提交→轮询→修正→交付）→ 机器逐步可执行的显式指令 |
| **场景的标准化** | "用 X 工具做 Y"的每个具体组合（豆包生成视频、千问生成视频、GPT 生成图片）= 一个独立 skill |

典型用户故事：用户装了 `ai-media-toolkit` 包后说"帮我把这段文案做成竖屏短视频"→ AI 自动命中 video-generation 技能 → 一轮问清缺失信息（时长/比例/风格）→ 写好符合平台公式的 prompt → 提交生成任务 → 轮询到完成 → 下载产物 → 交付本地路径。**全程用户只说了那一句话。**

## 二、为什么这个方向成立（四条论据）

1. **资产错配是普遍痛点**。每个重度用户的聊天记录里都埋着几十条私有工作流，但它们不可复用、不可分发、换设备即失。Agent Skills 开放标准（40+ 兼容产品：Claude Code、Codex、Cursor、Gemini CLI、Copilot…）恰好是这类资产的容器格式——格式问题已被行业标准解决，缺的是**内容供给方**。
2. **市场结构性空白**。2026-08 的生态两极分化：一极是编程技能（superpowers、vercel-labs 等），一极是横向货架（SkillHub 10.7 万技能、SkillsMP 190 万抓取）。**没有人系统性供给"大众日常场景"的端到端工作流**：AI 生图/生视频/做 PPT/发公众号/剪视频/改简历——这些是最大众的高频刚需，且每个都藏着"只有踩过坑才知道"的平台暗知识（我们的核心竞争力）。
3. **学术实证支持产品形态**。SkillsBench（47,150 技能样本）：聚焦的 2-3 个针对性技能 **+18.6 分**，单体大杂烩技能 **-2.9 分**；精选优质技能平均提升 agent 任务通过率 **+16.2 分**。→ "一个场景一个包、每包 2-3 个技能、宁精勿多"是最优解，也是本项目的组织原则。
4. **方法论已在内部验证**。18 个中文发布技能就是把踩坑经验封装成机器指令的成功案例（知乎 Draft.js 坑位图、微信 errcode 速查表、默认 dry-run 守卫）。同样的方法论平移到媒体生成、办公场景即可，无需发明新东西。

## 四、"说一句话"体验契约（产品验收标准）

北极星指标：**安装后，一句自然语言 → 正确技能触发 → 至多一轮信息补全 → 全流程执行 → 产物交付**，全程无人工干预失败。分解为四个技术承诺（实现细则见《SKILL-STANDARD-v2.md》）：

1. **触发可靠**：description 含中英文触发短语，应触发场景命中率 ≥90%（触发测试矩阵验证）；
2. **输入协议**：技能开头声明必需/可选输入清单 + 缺失时的一次性询问模板；
3. **执行自愈**：每个步骤自带预期输出与失败处置分支，常见错误码有速查表；
4. **交付明确**：成功定义 + 产物格式（文件命名、存放路径、如何验证）写死在技能里。

## 六、新增风险与对策

| 风险 | 对策 |
|---|---|
| 媒体平台 API/界面变化比内容平台更快 | 每技能强制 `metadata.verified-date` + VERIFY BEFORE USE 标记 + issue 快修 SLA；端点集中在一个文件便于热修 |
| 技能依赖用户本地环境（网关、CLI、凭据） | `compatibility` 字段必填；SKILL.md 第一步固定为"前置自检"（端点可达性/凭据存在性探测命令），失败即给出修复指引而非带病执行 |
| 场景泛化后质量稀释（重蹈上游 33 技能覆辙） | 门禁 validator 按 12 分制打分，<9 分不入主包；宁缺毋滥 |
| 与平台官方技能撞车（如各模型厂商自发生成技能） | 我们的价值在**跨工具编排 + 中文语境 + 踩坑暗知识**，不做单厂商 API 文档的搬运工 |
