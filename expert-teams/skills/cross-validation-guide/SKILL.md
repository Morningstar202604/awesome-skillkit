# 多方法交叉验证指南（cross-validation-guide）

本 skill 供**数学/学术/工程/数据相关角色**共用。目标：任何结论性数字或关键判断，必须通过 ≥2 种独立方法交叉核对收敛，杜绝"一种方法算出来就当答案"的自证陷阱。

## 这是什么

一套「定义结论 → 选独立方法 → 逐一执行 → 量纲自检 → 边界反例 → 敏感性检验 → 验证矩阵」的交叉验证规程。

核心原则：**单一方法自证不可靠**。同一个结论用两种不同算法、不同口径、不同数据源、或手算对照，结果收敛才算稳。如果两种方法结果不一致，说明至少有一种方法有问题，必须排查而非取平均糊弄。

"独立方法"的判定：
- 不同算法（如解析解 vs 数值积分、精确公式 vs 蒙特卡洛）
- 不同口径（如年化 vs 月度累计、绝对值 vs 百分比）
- 不同数据源（如官方统计 vs 第三方调研、训练集 vs 验证集）
- 手算对照（小规模样本手算 vs 程序全量计算）
- **不独立**的情况：同一库的不同函数、同一公式的代数变形、同一数据源的不同切片——这些不算第二种方法。

## 何时使用

- **数值求解后**：方程求解、优化结果、积分/微分计算、仿真输出。
- **统计结论**：假设检验结果、效应量、置信区间、回归系数、p 值。
- **性能数据**：基准测试结果、延迟/吞吐量指标、资源占用数据。
- **模型输出**：机器学习预测、分类准确率、损失函数收敛值。
- **任何"结论性数字"**：只要交付物中有一个数字是核心结论，就必须交叉验证。
- 用户要求"验证一下这个结果"、"换种方法算算"、"这个数稳不稳"时。

## 核心步骤

1. **定义被验证结论**：明确写出要验证的结论是什么（具体数字、判断、或模型输出），以及它在交付物中的作用（核心结论 / 辅助数据 / 中间结果）。核心结论必须验证，辅助数据建议验证。
2. **选 ≥2 种独立方法**：为该结论选择至少 2 种真正独立的验证方法，写明每种方法的原理和为什么它与第一种独立。禁止用同源方法凑数。
3. **逐一执行并记录**：每种方法独立执行，记录完整过程（输入、参数、计算步骤、输出）。不得让第一种方法的结果影响第二种方法的执行（避免锚定）。
4. **量纲与数量级自检**：
   - 检查结果的物理/统计量纲是否正确（速度是 m/s 不是 m、概率在 [0,1] 不是 150%）。
   - 检查数量级是否合理（年收入不会是 10^-3 万元、延迟不会是 10^6 秒）。
   - 量纲或数量级异常 = 验证失败，必须排查。
5. **边界/极端值反例测试**：
   - 取输入的边界值（最小值、最大值、零、空集）代入，看结论是否仍然成立或合理退化。
   - 取极端值（远超正常范围的输入）测试，看方法是否崩溃或给出荒谬结果。
   - 边界反例暴露的问题必须记录，不能因为"正常输入不会这样"就忽略。
6. **敏感性检验**：将关键输入参数 ±10%（或合理扰动范围），观察结论变化幅度：
   - 输入变 10%，结论变 <5% → 稳健。
   - 输入变 10%，结论变 5%-20% → 敏感，须标注敏感性。
   - 输入变 10%，结论变 >20% 或符号翻转 → 高敏感/不稳定，结论不可靠，须重新审视方法或标注强依赖假设。
7. **输出验证矩阵**：方法 × 结果 × 是否收敛 × 备注。若全部收敛，结论通过；若不收敛，列出差异、排查原因、给出最终采信值及理由。

## 验证清单

- [ ] 核心结论性数字已用 ≥2 种真正独立的方法验证（非同源、非同一公式变形）。
- [ ] 每种方法的执行过程已完整记录（输入/参数/步骤/输出）。
- [ ] 量纲自检通过（单位正确、数值在合理范围内）。
- [ ] 边界/极端值反例已测试，异常已记录或已解释。
- [ ] 敏感性检验已完成（输入±10%），结论稳健性已标注。
- [ ] 验证矩阵已输出，不收敛项已排查并说明采信理由。

## 易错点

- **两种方法实为同源**：用 numpy 算一遍再用 pandas 算一遍——底层都是同一套 BLAS，不算独立方法。必须选原理不同的路径。
- **只验证好结果不验证坏结果**：方法在正常输入下对了就以为稳了，边界值一跑就崩。边界反例是强制项。
- **忽略量纲**：算出来 500 就交了，没发现单位应该是 kHz 而不是 Hz，差了 1000 倍。量纲自检必须做。
- **把"大概对"当收敛**：两种方法差了 15% 就说"差不多"。必须定义收敛阈值（通常 <1% 或与方法精度匹配），超阈值就是不收敛，要排查。
- **锚定效应**：第一种方法算出结果后，第二种方法不自觉地往第一个结果上凑。执行第二种方法时必须独立推导，不看第一个结果。
- **敏感性检验走过场**：扰动了 1% 就说"变化不大"。必须按 ±10% 标准扰动，且记录具体变化幅度。
