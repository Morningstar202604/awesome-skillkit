# 搜索陷阱与规避

## 引擎限制陷阱

1. **SearXNG 公共实例不稳定**
   - 现象：间歇性超时或返回空结果
   - 规避：实现多实例自动切换，设置合理超时
   - 建议：生产环境自建 SearXNG 实例

2. **DuckDuckGo 反爬**
   - 现象：连续请求后返回 CAPTCHA 或空结果
   - 规避：请求间隔 ≥1 秒，使用代理池
   - 建议：限制频率，不要高频调用

3. **Brave Search 额度耗尽**
   - 现象：返回 403 或空结果
   - 规避：监控额度使用，实现自动降级
   - 建议：免费额度足够个人使用

## 结果质量问题

4. **搜索结果无关**
   - 现象：返回的结果与查询无关
   - 规避：优化查询词，使用引号精确匹配
   - 建议：提供多个备选查询

5. **结果过期**
   - 现象：返回的内容已过期或链接失效
   - 规避：检查结果日期，优先选择近期内容
   - 建议：标注结果发布日期

6. **重复结果**
   - 现象：同一内容出现在多个结果中
   - 规避：URL 去重，合并相似结果
   - 建议：设置去重阈值

## 缓存陷阱

7. **缓存污染**
   - 现象：缓存了错误结果，后续所有请求都返回错误
   - 规避：缓存前验证结果有效性
   - 建议：设置缓存有效期，过期自动清除

8. **缓存击穿**
   - 现象：高热点查询导致缓存频繁失效
   - 规避：延长热点查询的缓存时间
   - 建议：实现缓存预热

## 解析陷阱

9. **HTML 结构变化**
   - 现象：搜索引擎更新页面结构导致解析失败
   - 规避：使用健壮的解析器，支持多种选择器
   - 建议：监控解析成功率，及时更新

10. **编码问题**
    - 现象：中文结果出现乱码
    - 规避：正确设置编码，使用 UTF-8
    - 建议：检测编码并自动转换

## 安全陷阱

11. **恶意网站**
    - 现象：搜索结果包含恶意网站
    - 规避：过滤可疑域名，标注安全风险
    - 建议：使用安全搜索引擎白名单

12. **隐私泄露**
    - 现象：搜索请求泄露用户隐私
    - 规避：使用匿名引擎，不记录搜索历史
    - 建议：本地部署搜索引擎

## 工程陷阱

13. **资源泄漏**
    - 现象：大量搜索请求导致内存泄漏
    - 规避：使用连接池，及时释放资源
    - 建议：监控内存使用

14. **循环依赖**
    - 现象：搜索模块被其他模块循环依赖
    - 规避：清晰定义模块边界
    - 建议：使用依赖注入
