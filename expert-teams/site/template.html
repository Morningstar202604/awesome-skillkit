GET STARTED

三种方式，接入任意 Agent

01

直接读团队 Markdown

适合支持「读文件 + 派子 agent」的框架：把团队目录交给它，专家即可被路由调用。

teams/content-writing-team/
团队自包含：TEAM.md 编排 + agents/ 专家 + skills/ 技能
02

一键导出 system prompt

运行导出脚本，得到每名专家的纯文本提示词与全队汇总包，直接粘贴进任何 agent。

python3 export-agents.py
输出 dist/agents.json + {{N_AGENTS}} 份单专家文本 + {{N_TEAMS}} 份整队汇总
03

整目录复制

把 teams/ 目录整体复制给支持目录式专家的框架，配置即完成，无需转换。

cp -r teams/ /your/agent/path
无运行时依赖，复制即用
