# 个人信息保护合规指南

本 skill 是 legal-privacy-officer 的工作手册。核心原则：**个人信息处理"告知—同意—最小必要"三原则贯穿始终；敏感信息与出境须单独同意。** 本 skill 输出为初步合规提示，不构成正式法律意见。

## 这是什么

一套个人信息保护合规评估流程。从处理活动梳理出发，核对告知同意、最小必要、敏感信息、共享出境、用户权利响应，出整改建议。依据《个人信息保护法》《数据安全法》《网络安全法》及配套规定。

## 何时使用

- legal-privacy-officer 接到"收集用户数据合规吗/写隐私政策"任务时，必须加载本 skill。
- legal-compliance-officer 做业务合规审查时，涉及数据处理参考本指南。
- legal-contract-reviewer 审数据处理/共享合同时，参考本指南核数据责任条款。
- legal-qa-reviewer 终检时，核对告知同意与单独同意场景是否覆盖。

## 核心步骤

1. **梳理处理活动**：列清收集哪些个人信息、目的、方式、存储期限、是否共享/出境。
2. **核对告知同意**：隐私政策是否清晰告知处理者/目的/种类/权利；是否取得同意。
3. **最小必要**：收集范围是否为实现目的所必需，有无过度收集。
4. **单独同意场景**：敏感信息（人脸/行踪/金融账户）、向第三方共享、公开、出境，是否取得单独同意。
5. **用户权利响应**：查阅/复制/更正/删除/撤回同意/注销，是否有响应渠道与时限。
6. **安全与出境**：安全措施、数据出境合规路径（标准合同/认证/评估）。
7. **整改建议**：按高/中/低风险列整改项与依据。

## 清单

- [ ] 处理活动梳理了（种类/目的/方式/期限/共享/出境）。
- [ ] 隐私政策告知了处理者/目的/种类/权利。
- [ ] 同意机制存在，非捆绑同意。
- [ ] 收集符合最小必要，无过度收集。
- [ ] 敏感信息取得单独同意。
- [ ] 向第三方共享/公开取得单独同意。
- [ ] 数据出境有合规路径。
- [ ] 用户权利（查阅/更正/删除/注销）有响应渠道与时限。
- [ ] 安全措施与存储期限写清。
- [ ] 每条风险标了等级并给整改依据。
- [ ] 文末含"不构成正式法律意见"声明。

## 易错点

- **隐私政策照搬模板**：政策里写的和实际收集的不一致，实际收集了位置但政策没提。政策要与实际活动一致。
- **捆绑同意**：不同意收集非必要信息就不能用 App，违反"不得拒绝提供服务"。同意要可拆分。
- **漏单独同意**：收集人脸、向第三方 SDK 共享、数据出境，没单独同意，直接违规。
- **无响应渠道**：用户想注销账号找不到入口，投诉高发。要建响应流程与时限。
- **存储无期限**：数据永久存储，超出必要期限仍留存，违反最小必要。
