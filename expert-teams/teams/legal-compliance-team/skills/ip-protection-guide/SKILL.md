# 知识产权保护指南

本 skill 是 legal-ip-specialist 的工作手册。核心原则：**IP 风险"先查后用"；权属条款写清楚；被侵权先固定证据再维权。** 本 skill 输出为初步风险提示，不构成正式法律意见。

## 这是什么

一套 IP 风险排查与保护流程。从商标查重、著作权权属、专利侵权、商业秘密四个维度评估，核对合同中的 IP 归属条款，出保护与维权建议。依据商标法、著作权法、专利法、反不正当竞争法。

## 何时使用

- legal-ip-specialist 接到"商标能注册吗/被侵权了/IP 条款怎么写"任务时，必须加载本 skill。
- legal-contract-reviewer 审涉及 IP 归属的合同（开发/委托/合作）时，参考本指南。
- legal-compliance-officer 做品牌/产品上线合规时，参考本指南查商标与素材授权。
- legal-qa-reviewer 终检时，核对权属条款与查重结论。

## 核心步骤

1. **商标查重**：在注册类别内查近似商标，评估注册成功率与使用侵权风险。
2. **著作权权属**：核对委托/职务作品归属，素材（图片/字体/音乐）是否有授权。
3. **专利侵权排查**：产品技术方案是否落入他人专利权利要求，评估自由实施空间。
4. **商业秘密**：保密措施、竞业限制、涉密人员管理是否到位。
5. **权属条款**：合同中 IP 归属、使用范围、改进成果归属是否写清。
6. **侵权应对**：被侵权时先固定证据（公证/时间戳），再发函/投诉/诉讼。

## 清单

- [ ] 商标在注册类别内做了近似查重。
- [ ] 素材（图片/字体/音乐）授权链清晰。
- [ ] 委托/职务作品著作权归属明确。
- [ ] 产品技术方案做了专利侵权初筛。
- [ ] 商业秘密有保密措施与涉密人员管理。
- [ ] 合同 IP 归属与使用范围写清。
- [ ] 改进成果归属有约定。
- [ ] 被侵权时有证据固定方案（公证/时间戳）。
- [ ] 每条风险标了等级与依据。
- [ ] 文末含"不构成正式法律意见"声明。

## 易错点

- **商标想当然注册**：没查重就提交，或只查文字不查图形，注册被驳回或侵犯他人在先权利。先查重。
- **素材无授权**：官网/海报用了网图、商用字体，收到侵权律师函。素材授权链要留存。
- **委托开发权属不清**：外包做的设计/代码，合同没写归谁，后期扯皮。权属条款必须写。
- **商业秘密无措施**：只靠保密协议，没有物理/技术保密措施，发生纠纷时不被认定为商业秘密。
- **被侵权不固定证据**：发现侵权直接开骂，没公证，证据灭失后维权难。先固定证据。
