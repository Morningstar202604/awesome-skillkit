# 税务合规检查清单

本 skill 是 finance-tax-advisor 的工作手册。核心原则：**税务处理必须有政策依据，标注文号；优惠享受要满足条件并留痕；不凭记忆报税，政策变化要跟踪。** 本 skill 内容不构成正式税务/法律意见，重大事项须咨询主管税务机关或持证税务师。

## 这是什么

一套税务合规自查流程。从业务实质判断税种与税率，核对申报口径，检查发票与优惠适用，识别风险点。每个结论标注政策依据文号，不凭印象。

## 何时使用

- finance-tax-advisor 接到"这笔怎么交税/申报/税务筹划"任务时，必须加载本 skill。
- finance-accountant 做涉及税费的分录时，参考本指南核对税种与科目。
- finance-audit-support 应对税务稽查时，参考本指南整理底稿。
- finance-qa-reviewer 终检时，核对税务口径与政策依据。

## 核心步骤

1. **判业务实质**：先看交易实质（销售/服务/资产处置/跨境），定涉及税种与纳税义务发生时间。
2. **核税率与口径**：增值税（一般/小规模/征收率）、企业所得税（税率/扣除限额）、个税（代扣代缴）、印花税（税目）逐项核对。
3. **查优惠适用**：小微企业、研发加计、高新等优惠，核对是否满足条件并留存备查资料。
4. **发票管理**：销项开票合规、进项发票可抵扣、三流一致（合同/发票/资金）。
5. **风险扫描**：常见风险（视同销售未申报、费用扣除超限、跨境未代扣代缴、关联交易定价）。
6. **申报留痕**：申报底稿、政策文号、计算过程留存备查。

## 清单

- [ ] 业务实质判断正确，税种无遗漏。
- [ ] 纳税义务发生时间与收入确认匹配。
- [ ] 增值税税率/征收率适用正确。
- [ ] 企业所得税扣除限额（招待费/广告费/福利费）核对过。
- [ ] 个税代扣代缴口径正确。
- [ ] 税收优惠满足条件且留存备查资料。
- [ ] 发票三流一致，进项抵扣合规。
- [ ] 视同销售、跨境代扣代缴等常见风险点扫描过。
- [ ] 每个结论标注了政策依据文号。
- [ ] 重大事项提示须咨询主管税务机关/持证税务师。

## 易错点

- **凭记忆报税**：税率/扣除限额记混，政策已更新仍用旧口径。必须核政策文号。
- **优惠乱享**：不满足条件硬享优惠，留后患。优惠条件要逐项核对。
- **漏视同销售**：自产货物用于福利/赠送未视同销售，增值税与所得税都漏。
- **费用扣除超限**：业务招待费按发生额全额扣，未按 60% 与收入 5‰ 孰低。
- **跨境未代扣**：向境外支付服务费未代扣代缴增值税/所得税。
- **三流不一致**：合同方、发票方、付款方不一致，进项抵扣被否。
