# 成本分析指南

本 skill 是 finance-cost-controller 的工作手册。核心原则：**成本要先归集准确再谈分摊；分摊动因要与成本发生逻辑匹配；降本分析要落到具体动因，不能只砍总额。** 算不准的成本会导致错误的定价与产品线决策。

## 这是什么

一套成本核算与分析流程。先归集直接成本，再按合理动因分摊间接成本，算产品单位成本；用标准成本对比实际，拆量差与价差；识别降本机会。

## 何时使用

- finance-cost-controller 接到"算产品成本/成本为什么超/降本"任务时，必须加载本 skill。
- finance-budget-planner 编成本预算时，参考本指南的成本性态与分摊口径。
- finance-report-analyst 分析毛利率变动时，参考本指南拆成本结构。
- finance-qa-reviewer 终检时，核对成本分摊逻辑一致性。

## 核心步骤

1. **归集直接成本**：直接材料、直接人工按产品/工单归集，单据可追溯。
2. **划分成本性态**：固定成本（折旧/租金）与变动成本（材料/计件人工）分开。
3. **分摊间接成本**：制造费用按合理动因（机器工时/人工工时/产量）分摊，说明动因依据。
4. **算单位成本**：汇总直接+分摊间接，得产品单位成本。
5. **差异分析**：标准成本 vs 实际，拆价差（价格波动）与量差（耗用效率）。
6. **识别降本点**：按动因找最大成本项，给可行动降本建议（换料/提效/集采）。

## 清单

- [ ] 直接成本归集到产品/工单，单据可追溯。
- [ ] 固定/变动成本性态划分正确。
- [ ] 间接成本分摊动因与成本发生逻辑匹配，有依据。
- [ ] 单位成本计算过程完整可复算。
- [ ] 标准成本与实际差异拆了价差与量差。
- [ ] 降本建议落到具体动因，不是"整体降 5%"。
- [ ] 成本口径与财务报表成本科目一致。
- [ ] 分摊方法前后期间一致，不随意变更。
- [ ] 识别了亏损产品/产能闲置等结构性问题。

## 易错点

- **分摊拍脑袋**：制造费用按产量平均分摊，高耗时产品承担不足，低耗时产品被高估，定价决策出错。
- **不分成本性态**：把固定成本当变动成本，以为销量上去单位成本就降，实际固定成本不随量变。
- **差异只给总数**："材料成本超了"不拆是价格涨了还是耗多用了，无法行动。
- **口径漂移**：本期分摊方法和上期不同，单位成本趋势不可比。
- **忽略闲置产能**：固定成本已发生，仍全额摊给在产品，掩盖了产能浪费。
