# 财务报告编制指南

本 skill 是 finance-report-analyst 的工作手册。核心原则：**报表是算出来的，不是编出来的；三张表必须勾稽一致，任何差异都要有出处。** 数字来自总账与明细账，不拍脑袋填。

## 这是什么

一套报表编制与解读流程。从科目余额表出发编三大报表，核对表间勾稽（净利润→未分配利润、货币资金→现金净流量），再用指标拆解经营变动。每个指标写清口径与时间窗。

## 何时使用

- finance-report-analyst 接到"出月报/分析利润变动"任务时，必须加载本 skill。
- finance-accountant 月结后编表时，参考本指南核对勾稽。
- finance-qa-reviewer 终检时，按本指南核对表间勾稽关系。
- finance-budget-planner 做预算时，参考本指南取历史基线口径。

## 核心步骤

1. **取数**：从科目余额表/明细账取数，核对试算平衡（借方=贷方）。
2. **编资产负债表**：按科目填列，核对资产=负债+所有者权益。
3. **编利润表**：按收入/成本/费用/税金逐项填，算到净利润。
4. **编现金流量表**：区分经营/投资/筹资活动，核对期末现金及等价物与资产负债表货币资金勾稽。
5. **勾稽核对**：净利润→未分配利润变动；现金净流量→货币资金变动；应收/应付与往来明细核对。
6. **指标与解读**：算毛利率、净利率、应收账款周转率、资产负债率等，拆解变动原因（量/价/成本/费用）。

## 清单

- [ ] 试算平衡（借方=贷方）核对过。
- [ ] 资产负债表满足资产=负债+所有者权益。
- [ ] 利润表从收入到净利润逐项无遗漏。
- [ ] 现金流量表三类活动划分正确。
- [ ] 净利润与未分配利润变动勾稽一致。
- [ ] 现金净流量与货币资金变动勾稽一致。
- [ ] 应收/应付与往来明细核对一致。
- [ ] 关键指标算出口径（分子/分母/时间窗）。
- [ ] 变动分析拆到量/价/成本/费用，不只给总数。

## 易错点

- **表间不勾稽**：利润表净利润变动和资产负债表未分配利润对不上，又不查原因直接调平。差异必须有出处。
- **现金流量表拍数**：不按业务实质分类，把经营活动现金塞进筹资，导致现金流结构失真。
- **指标口径漂移**：本月毛利率的分母和上月不同，趋势不可比。口径必须前后一致。
- **只给总数不给原因**："利润降了 10%"就交差，没拆是销量、价格还是成本导致。
- **漏重分类**：应收/应付明细账出现贷方/借方余额，未做重分类，资产负债表虚增。
