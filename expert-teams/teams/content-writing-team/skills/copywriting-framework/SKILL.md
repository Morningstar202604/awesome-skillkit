# 广告文案框架

本 skill 是 copywriter 的工作手册，提供四个经过验证的文案模型。它不替你写句子，只给结构——先用哪个模型，再按模型填内容，避免一上来就堆形容词。核心原则：**痛点先于卖点，Benefit 先于 Feature，CTA 单一明确。**

## 这是什么

四个经典文案模型的速查与选用指南。每个模型有适用场景、结构骨架、一个例子。copywriter 接到 brief 后先选模型，再动笔，而不是自由发挥。

## 何时使用

- copywriter 在 Phase 1 接广告/落地页/电商/EDM 单时，必须加载本 skill。
- 主理人审广告稿时，用本指南判断"结构对不对"。
- title-expert 写广告标题时，参考本指南的 4U 模型。
- 任何成员写转化型文案时，先查本指南选模型。

## 核心步骤

1. **判场景选模型**：
   - **AIDA**（注意→兴趣→欲望→行动）：适用于落地页、长广告。
   - **FAB**（Feature→Advantage→Benefit）：适用于电商详情、产品介绍。
   - **PAS**（Problem→Agitate→Solve）：适用于痛点型广告、EDM。
   - **4U**（Useful/Urgent/Unique/Ultra-specific）：适用于标题、slogan。
2. **按模型搭骨架**：把 brief 里的卖点填进模型的对应位置。
3. **落到 Benefit**：每一条 Feature 都要回答"对用户意味着什么"，停在 Feature 就算没写完。
4. **CTA 单一**：一页只让用户做一个动作（买/留资/加微），不并列多个按钮。
5. **过合规词表**：绝对化用语（最/第一/国家级）规避；医疗/金融类用词严格。

## 清单

- [ ] 选对了模型（不是四个都用一遍）。
- [ ] 每条 Feature 都落到了 Benefit。
- [ ] CTA 只有一个，不是"立即购买/了解更多/关注我们"并列。
- [ ] 删光了形容词（"极致/完美/卓越"），换成具体数字或场景。
- [ ] 过了广告法绝对化用语检查。
- [ ] slogan 给了 3–5 个候选，不是只写一个。
- [ ] 首屏 3 秒内能看懂"这是什么、对我有什么好"。

## 易错点

- **模型堆砌**：一篇稿同时用 AIDA+FAB+PAS，结构打架。选一个主模型即可。
- **停在 Feature**：写"我们有 256GB 存储"就完了，没写"装 5 万首歌不用删"。FAB 必须落到 B。
- **CTA 贪多**：首屏"立即购买"、次屏"了解更多"、结尾"关注公众号"，用户不知道点哪。一个页面一个主 CTA。
- **形容词轰炸**："极致体验/卓越品质/完美之选"——全是空话。换成具体数字、具体场景、具体对比。
- **绝对化用语**：手滑写"最好/第一/国家级"，发布即违规。写完必扫。
- **痛点假**：编一个用户没有的痛点（"你还在为找不到优质咖啡而烦恼吗"），用户不买账。痛点必须来自真实洞察。
