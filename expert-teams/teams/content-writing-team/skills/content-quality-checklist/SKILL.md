# 内容质检清单（强制闸门）

本 skill 是内容战队的**强制闸门**。它把内容行业的五条底线——忠于 brief、不洗稿、事实可溯、标题不党、平台不串味——变成可逐条勾选的动作。所有成员在**开工前**与**每段产出回传前**必须逐项过单；**任意一项未过即停手**，按「思想纪律」回头查根因，不得带病进入下一阶段。

## 这是什么

一份跨角色通用的内容自检 checklist，适用于从策略师到审读官的全部 14 个成员。它不教"怎么写好"，只教"写完之前先查什么"。它与 `content-strategy-canvas`、`title-crafting-guide`、`multi-platform-adaptation-guide`、`copywriting-framework`、`seo-writing-guide` 并列必查：那五份是"方法依据"，本份是"纪律闸门"。

## 何时使用

- 主理人在 Phase 0 派单时，把本清单随 brief 一并下发给每个成员。
- 任一主笔/编辑/适配师**开工前**先过 A 组闸门。
- 任一成员**回传主理人前**先过 B 组闸门。
- `content-reviewer` 终检时，把本清单当评分表逐项打勾。
- 一篇稿子被打回第 3 次时，必须停下来过一遍 C 组"出错即停"信号。

## 核心步骤

1. **A 组开工前**：接到任务先在心里默念五条——brief 对齐、平台对齐、读者画像对齐、红线词表看过、本阶段该用的 skill 已加载。
2. **B 组产出后**：成稿/改稿后逐条核对——观点一句话说清、事实有出处、无洗稿痕迹、标题与正文一致、平台调性没串味、无空转句。
3. **C 组出错即停**：同一稿被打回 2–3 轮、或写到一半发现论据撑不住观点，立刻停手回主理人复核 brief，而不是再写一版。
4. **D 组终审**：reviewer 把整篇稿从头到尾按本清单过一遍，H 级问题（事实错误/合规红线/洗稿）一票否决。
5. **交接**：回传时在最终输出里附上"本稿自检勾选项截图式清单"，让主理人一眼看到过了哪些、没过哪些。

## 清单

### A 组：开工前闸门
- [ ] 我清楚本次严格以哪份 brief/素材/品牌指南为准，范围边界锁定。
- [ ] 已扫团队 `skills/` 目录，命中相关 skill（含本清单）即按它来。
- [ ] 能一句话说清"这篇让读者看完做什么"（点赞/转发/下单/记住）。
- [ ] 知道目标读者是谁、在什么场景刷到、什么平台。
- [ ] 已看过品牌禁用词表与敏感行业合规红线。
- [ ] 已标出本稿最大 2 个翻车点（事实无出处/标题党/平台串味）及兜底。

### B 组：产出后闸门
- [ ] 核心观点一句话说得清，没有跑题。
- [ ] 每个关键数据/引述/名人名言都标了来源；拿不准的标了 [待核实]。
- [ ] 没有洗稿/复制网文/教材原文；引用比例与改写方式合规。
- [ ] 标题不夸大、不震惊体、与正文事实一致；避开了平台限流词。
- [ ] 平台调性与 brief 指定平台一致，没把公众号腔搬到小红书、没把白皮书腔搬到朋友圈。
- [ ] 删掉了"众所周知/综上所述/毋庸置疑"这类空转句。
- [ ] 与上游大纲/策略一页纸首尾咬合，没有中途漂移。

### C 组：出错即停信号
- [ ] 思考明显出界（发散到 brief 没要的主题、加了用户没要的卖点）。
- [ ] 同一稿被打回 2–3 轮仍不达标——判定是 brief 理解偏了，不是"再写一版"能解决。
- [ ] 任一闸门项连续两次勾不上且找不到合理解释。

### D 组：终审（reviewer 专用）
- [ ] 事实核查：所有外部断言可溯源。
- [ ] 合规红线：医疗/金融/教育/未成年等敏感行业表述合规。
- [ ] 原创度：无大段抄袭、无 AI 味套话。
- [ ] 一致性：标题/封面/正文/改编版本之间不矛盾。
- [ ] 发布就绪：字数、格式、标签、发布时间建议齐备。

## 易错点

- **只看 B 组不看 A 组**：开工前没对齐 brief，写到一半才发现方向错了，白写三千字。
- **把"待核实"当句号用**：标了 [待核实] 却不跟进来源，等于在终稿里留雷。reviewer 会一票否决。
- **标题党惯性**：主笔写稿时顺手起了个震惊体标题，title-expert 还没介入就被发到主理人手里——必须交工作标题即可，最终标题走 title-expert。
- **平台串味**：长文作者把白皮书的正式腔直接搬到小红书，multiplatform-adaptor 之前没提醒。
- **自检流于形式**：勾选时凭感觉打勾，不真的逐条核对。H 级问题漏到 reviewer 那里才发现，返工成本翻倍。
- **出错即停却硬撑**：被打回第 2 轮还在原方向改，不回主理人复核 brief，浪费时间。
