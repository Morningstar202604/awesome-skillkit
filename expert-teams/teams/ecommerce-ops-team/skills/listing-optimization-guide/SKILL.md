# Listing 优化指南

本 skill 是详情页/Listing 的工作手册。核心原则：**标题吃搜索、主图吃点击、卖点吃转化、合规吃长久。** 详情页不是把产品参数堆上去，而是让搜索流量点进来、看下去、下单。

## 这是什么

一套从标题到主图到详情页的转化优化流程。标题埋关键词拿搜索流量，主图决定点击率，前 3 屏卖点决定转化，全程合规不踩极限词。

## 何时使用

- ecommerce-listing-optimizer 接到"优化详情页/写 Listing"时必须加载。
- ecommerce-qa-reviewer 审详情页时，按本指南检查极限词与卖点。
- ecommerce-market-research 调研竞品卖点时参考。
- ecommerce-ops-team-lead 判断 Listing 转化瓶颈时使用。

## 核心步骤

1. **写标题**：核心关键词前置 + 属性/场景/规格；不堆砌、不堆同义词；覆盖用户会搜的词。
2. **做主图**：首图白底产品图（平台规范）；第 2~5 图展示卖点/尺寸/场景/对比；主图带利益点不堆字。
3. **排前 3 屏卖点**：按用户决策顺序排——解决什么问题、核心卖点、规格参数、信任背书（资质/销量）。
4. **写五点描述/A+**：每点一个卖点，开头加粗利益点，后接说明；不写空泛形容词。
5. **埋信任元素**：尺寸图、使用场景图、售后承诺、资质证书；降低下单顾虑。
6. **合规自查**：删极限词（最/第一/国家级）、无据功效（治病/100% 有效）、虚假对比图。

## 清单

- [ ] 标题核心关键词前置，覆盖用户搜索词。
- [ ] 首图符合平台规范（白底/尺寸）。
- [ ] 第 2~5 图展示卖点/尺寸/场景/对比。
- [ ] 前 3 屏按决策顺序排卖点。
- [ ] 五点描述每点一个利益点。
- [ ] 有尺寸图/场景图/售后承诺等信任元素。
- [ ] 删了极限词与无据功效宣称。
- [ ] 卖点与产品实际一致，不过度承诺。

## 易错点

- **标题堆砌**：塞满同义词和符号，搜索引擎不收录、用户看着乱。关键词自然分布。
- **首图违规**：首图堆满文字/牛皮癣，被平台限流或拒审。按平台规范来。
- **卖点空泛**：写"质量好、性价比高"等于没说。要写具体（材质/耐用次数/容量）。
- **无信任元素**：只放产品图，不放尺寸/售后，用户不敢下单。
- **极限词**：写"最好用的""全网第一"，违反广告法被投诉。一律删。
- **过度承诺**：详情页说"永久不坏"，收到就差评+退货。承诺留余地。
