# 定价策略指南

本 skill 是电商定价的工作手册。核心原则：**定价锚成本、对标竞品、守毛利，促销真实不玩套路。** 价格定高了没转化，定低了亏利润，促销玩假折扣被投诉。

## 这是什么

一套从成本到价格到促销的定价方法。先算底线成本，再对标竞品价格带，定出日常价与促销价，保证毛利健康且促销真实。

## 何时使用

- ecommerce-pricing-strategist 接到"定价/促销力度"时必须加载。
- ecommerce-product-selector 算利润时，按本指南的成本结构口径。
- ecommerce-qa-reviewer 审促销是否假折扣时对照使用。
- ecommerce-store-operator 报活动前，按本指南核算底价。

## 核心步骤

1. **算底线成本**：单件总成本 = 货品成本 + 平台扣点 + 物流 + 推广分摊 + 退货损耗；售价必须高于总成本且留 ≥15% 净利。
2. **对标价格带**：看竞品集中在哪个价格带，选跟随（同价略低）或差异化（高配高价/简配低价）。
3. **定日常价**：日常价留促销空间——日常价是标价，大促价是成交价；不先涨后降。
4. **设计促销**：满减/折扣/赠品按毛利倒推；促销底价 = 成本 + 最低可接受净利，不破价。
5. **价格心理**：尾数定价（9.9/19.9）、划线价（真实划线，不能虚高原价）。
6. **小步测试**：新品先测 2~3 个价格点，按转化率与毛利选最优，不一锤定音。

## 清单

- [ ] 算了单件总成本（含扣点/物流/推广/退货）。
- [ ] 售价保证净利 ≥15%。
- [ ] 对标了竞品价格带，说明了跟随或差异化。
- [ ] 日常价留了促销空间，不先涨后降。
- [ ] 促销底价 = 成本 + 最低净利，不破价。
- [ ] 划线价真实，不虚高原价。
- [ ] 新品测了 2~3 个价格点。
- [ ] 标注了不同渠道/活动的价格差异。

## 易错点

- **不算全成本**：只减货品成本就定价，忘了扣点与推广，实际亏钱。
- **假折扣**：先把原价从 99 涨到 199 再打 5 折，被平台判定价格违规。划线价必须真实。
- **促销破价**：大促为了冲量打到成本线以下，GMV 涨了利润亏了。设促销底价红线。
- **定价拍脑袋**：竞品卖 59 我就卖 59，不算自己成本比人家高多少。成本结构不同不能照搬。
- **不留促销空间**：日常价定到底，大促没法降价就没活动价。日常价留 20~30% 促销空间。
- **不测试**：一上来定死价格，不知道更高点有没有转化。小步测价格。
