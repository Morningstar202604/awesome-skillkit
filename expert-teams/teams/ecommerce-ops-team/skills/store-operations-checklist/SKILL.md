# 店铺运营检查清单

本 skill 是店铺日常运营的工作手册。核心原则：**按节奏巡检、活动不漏报、流量结构健康、动销不压货。** 店铺运营不是等订单来，而是每天盯指标、报活动、调流量、清滞销。

## 这是什么

一套从日/周/月运营节奏到活动报名到流量结构到动销管理的检查清单。让运营按表巡检，不漏关键动作。

## 何时使用

- ecommerce-store-operator 接到"店铺运营/报名大促"时必须加载。
- ecommerce-ops-team-lead 巡检店铺健康度时使用。
- ecommerce-data-analyst 复盘时，对照本清单看哪些动作没做。
- ecommerce-supply-planner 联动动销率管理库存。

## 核心步骤

1. **每日巡检**：看昨日 GMV/访客/转化/客单；盯异常（暴跌/暴涨/差评）；处理待发货与售后工单。
2. **活动报名**：关注平台活动日历（大促/品类日/秒杀），按截止时间报名；核对报名价与库存。
3. **流量结构**：免费流量（搜索/推荐）+ 付费流量（直通车/万相台）+ 活动流量；免费占比过低要优化标题主图，付费 ROI 差要调价。
4. **动销管理**：动销率 = 有销量 SKU / 总 SKU；滞销品（30 天无动销）下架或清仓，不占库存。
5. **标题主图迭代**：每周挑转化率低的 Listing 优化标题/主图/卖点，A/B 测试新主图。
6. **月复盘**：对照目标看 GMV 达成、流量结构、客单、复购；调整下月运营重点。

## 清单

- [ ] 每日看了 GMV/访客/转化/客单并处理异常。
- [ ] 关注了平台活动日历，按截止时间报名。
- [ ] 报名活动核对了价格与库存。
- [ ] 检查了流量结构（免费/付费/活动占比）。
- [ ] 付费流量 ROI 差时调了出价或关键词。
- [ ] 算了动销率，滞销品有处理方案。
- [ ] 每周优化了低转化 Listing 的标题/主图。
- [ ] 每月对照目标做了 GMV 复盘。

## 易错点

- **不报活动**：平台免费活动流量不报名，白白浪费。活动日历按截止时间盯。
- **只靠付费流量**：付费一停就没单，免费流量占比过低。必须优化搜索/推荐占比。
- **SKU 越多越好**：上了一堆不动销的 SKU，占库存还拉低店铺动销率。滞销就清。
- **报名价不核算**：报活动按平台要求直接降价，没算底价，破价亏利润。报名前按定价指南核算。
- **不迭代 Listing**：上架后就不管，转化率慢慢掉。每周优化低转化品。
- **只盯 GMV 不盯结构**：GMV 涨了但全靠付费烧，停投就崩。看流量结构健康度。
