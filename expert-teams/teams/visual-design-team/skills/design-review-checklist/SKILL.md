# 设计评审清单（交付闸门）

本 skill 是视觉设计战队的**交付前独立闸门**。只读质检员在 Phase 3 照此逐项审，H 级问题不通过就打回，绝不带病交付。

## 这是什么

一份五维设计评审清单：风格一致性、信息层级、可读性与可访问性、版权合规、落地参数。质检员按它出《评审报告》，每个问题定位到具体位置并定级（H/M/L），只提建议不改稿。

## 何时使用

- 视觉方案完成、要交付前的独立质检环节。
- 主理人对风格没把握、需要第三方视角挑问题时。
- 用户拿现成设计稿来"看看有什么问题"时。

## 核心步骤

1. **审风格一致**：跨物料的配色/字体/版式是否统一，有无一张一个风。
2. **审信息层级**：主次是否分明、对齐是否到网格、元素有没有互相打架。
3. **审可读可达**：字号够不够、文字/背景对比度是否 ≥4.5:1、小图能不能辨认。
4. **审版权合规**：素材来源可商用吗、字体授权吗、有无违禁/夸大文案。
5. **审落地参数**：出血/分辨率/色彩模式/尺寸达标吗，印得出来投得出去吗。

## 清单

- [ ] 跨物料配色/字体/版式统一
- [ ] 视觉焦点明确、3 秒抓到重点
- [ ] 信息层级主次分明、不堆信息
- [ ] 元素对齐到网格、无错位
- [ ] 文字无乱码错字、无截断
- [ ] 文字/背景对比度 ≥4.5:1
- [ ] 缩略图/小屏可读
- [ ] 素材来源可商用、已标注
- [ ] 字体授权干净
- [ ] 无广告法违禁/夸大文案
- [ ] 出血/安全区到位（印刷件）
- [ ] 分辨率 ≥300dpi（印刷）/合适（屏幕）
- [ ] 色彩模式正确（CMYK 印刷/RGB 屏幕）
- [ ] 所有问题已定位并定级

## 易错点

- **凭个人审美打回**：评审以 brief 为基线，不把"我不喜欢"当问题。
- **只说"不够高级"**：建议必须可操作——哪个元素、改成什么样。
- **漏查版权**：视觉没问题但图是扒的，交付即侵权，这是 H 级。
- **漏查落地参数**：屏幕稿没转 CMYK 就送印，印出来偏色。
- **H 级放行**：风格错乱/侵权/参数错到无法落地，绝不能放过。
