# 色彩与字体排版速查手册

本 skill 是全队配色与排版的**通用速查依据**。设计师在定主色、搭配色、选字体、定字号网格时照此执行，保证全队色彩与字体成体系、有依据，不凭感觉挑色选字。

## 这是什么

一页式的色彩与排版工程参数表。它把"配色要和谐""排版要专业"翻译成可直接抄用的规则：用什么色彩关系、面积比例多少、对比度多少算达标、字号怎么分级、网格怎么分栏。适用于屏幕与印刷两类场景。

## 何时使用

- 主理人 Phase 0 定风格、需要给项目配色/字体方向时。
- 任何品类设计师动手前，需要先立配色与字体规矩时。
- 评审时拿不准对比度/字号是否达标，回来查标准时。

## 核心步骤

1. **定主色**：按行业与品牌情绪选 1 个主色（科技蓝/活力橙/自然绿/高端黑金/信任红），记下 HEX。
2. **搭配色**：用色彩关系选辅助色（互补制造对比/类似求和谐/三分色活跃），按 60-30-10 分配面积（主 60%/辅 30%/点缀 10%）。
3. **补中性色**：配 5-9 阶灰阶，承载文字与背景。
4. **校对比度**：正文文字对背景对比度 ≥4.5:1（WCAG AA），大标题 ≥3:1；避免纯红配纯绿。
5. **选字体**：标题用展示/衬线，正文用易读无衬线；中文主字体配一款气质协调的西文字体。
6. **定层级**：按 1.25 模数排 H1-H4 + 正文 + 注释字号，正文行高 1.5-1.75。

## 清单

- [ ] 主色 HEX/RGB/CMYK 都给了
- [ ] 辅助色+点缀色+中性灰阶齐了
- [ ] 60-30-10 面积比例写了
- [ ] 文字/背景对比度 ≥4.5:1 验过
- [ ] 避开红绿色盲不友好组合
- [ ] 中西文字体各定了一款且气质协调
- [ ] 字号阶梯（H1-H4/正文/注释）给了数值
- [ ] 正文行高 1.5-1.75 写了
- [ ] 网格栏数/栏距/边距给了
- [ ] 字体授权类型标注了

## 易错点

- **颜色太多**：一张图超过 3 个高饱和色必乱，点缀色只点睛不大面积铺。
- **对比度不够**：浅灰字配白底在投影/手机上看不清，必须实测比值。
- **字体混搭失控**：超过 2 种字体且气质冲突，立刻收。
- **凭感觉定字号**：没有模数阶梯，标题只比正文大一点点，层级出不来。
- **只给屏幕色**：印刷件忘了转 CMYK，印出来偏色。
