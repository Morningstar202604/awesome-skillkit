# 电商视觉自查清单

本 skill 是电商设计师的**交付前强制闸门**。主图能不能在信息流里被点开、详情页能不能顺着看完、会不会被平台判违规限流，全靠这份清单逐项过。

## 这是什么

一套面向转化与合规的电商视觉检查清单。它覆盖主图点击率、卖点可视化、详情页动线、促销氛围、平台尺寸与牛皮癣、广告法合规六个维度，电商设计师交稿前、评审时照单勾选。

## 何时使用

- 电商设计师产出主图/详情页后，自检时。
- 主理人中转电商方案、打回前对照时。
- 评审质检员审电商物料时。

## 核心步骤

1. **缩略图测试**：把主图缩到信息流大小，看 1 秒内能不能认出产品+核心卖点。
2. **卖点前置**：确认核心卖点在首屏/主图大字，不藏在详情页深处。
3. **促销突出**：价格/优惠/限时用对比色 badge 突出，但不盖产品主体。
4. **详情页动线**：按"痛点→产品→卖点→信任→规格→促销"排屏，一屏一信息。
5. **合规与尺寸**：核对平台比例、牛皮癣限制、广告法违禁词，避免限流。

## 清单

- [ ] 缩略图下产品+卖点 1 秒可辨
- [ ] 主标题卖点大字、不堆砌
- [ ] 核心卖点前置到首屏
- [ ] 价格/优惠/限时标签突出
- [ ] 详情页一屏一信息、动线顺
- [ ] 卖点图标化/可视化，不堆文字
- [ ] 平台尺寸比例正确（主图 1:1/3:4 等）
- [ ] 无过度牛皮癣导致限流
- [ ] 无广告法违禁词/不虚构功效
- [ ] 移动端小图文字可读
- [ ] 素材版权与字体授权干净

## 易错点

- **主图太满**：产品+N 个卖点+促销标签全塞，缩略图糊成一团。
- **卖点靠文字**："超长续航"只写字不配对比图，没说服力。
- **违规风险**：用"最/第一/国家级"等违禁词，或虚假功效，直接被平台卡。
- **牛皮癣超标**：文字堆太多被平台判低质限流。
- **忽略小屏**：设计时看大图觉得挺好，手机信息流缩略图根本看不清。
