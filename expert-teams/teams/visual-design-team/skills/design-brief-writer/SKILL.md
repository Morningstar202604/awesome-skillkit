# 设计需求简报拆解模板（Design Brief）

本 skill 是视觉设计战队的**开工第一份文档**。任何视觉设计任务在动手前，都应先把模糊需求拆成一份结构化简报——用途、受众、尺寸、风格、必含元素、交付格式一次问清，从源头避免"做完一版不是想要的"。

## 这是什么

一份把"帮我做个海报"翻译成可执行设计任务的标准模板。它强制在开工前锁定范围边界，让主理人知道本次以什么为准、让设计师知道往哪发力。简报不是越长越好，而是**每个字段都有明确答案**，答不上来的就是要找用户确认的点。

## 何时使用

- 接到任何视觉设计任务，需求还比较笼统时（"做个好看的图""设计一下"）。
- 主理人 Phase 0 拆解需求、向用户确认风格方向时。
- 设计师开工前发现缺关键信息、需要回传补需求时。
- 跨成员交接时，作为统一上下文传递。

## 核心步骤

1. **定目标**：这张图/这套设计要达成什么——是转化（点进来/下单）、认知（记住品牌）、还是氛围（烘托活动）？一句话写清。
2. **定受众与场景**：给谁看、在哪看——手机信息流 / 印刷物料 / 大屏 / PPT 投影？场景决定尺寸与阅读距离。
3. **定尺寸与规格**：列出需要的所有成品尺寸与比例，标注是屏幕（RGB）还是印刷（CMYK+出血）。
4. **定必含内容**：逐字写出必须出现的文案（主标题/副标题/活动信息/号召）、必须放的 logo/二维码/联系方式，一字不改。
5. **定风格方向**：给 2-3 个风格候选 + 参考描述（可引配色字体 skill），向用户确认后锁定。
6. **定交付物**：要几个尺寸、什么格式、是否需要源文件、截止时间。

## 清单

- [ ] 目标一句话（转化/认知/氛围）写清了
- [ ] 受众与观看场景写明了
- [ ] 全部成品尺寸/比例列出了
- [ ] 屏幕还是印刷（RGB/CMYK/出血）标了
- [ ] 必含文案逐字写清（不改字）
- [ ] 必含 logo/二维码/联系方式列出了
- [ ] 风格方向给了 2-3 个候选并待确认
- [ ] 品牌已有色值/字体/规范附了
- [ ] 交付格式与截止时间写明了
- [ ] 答不上来的字段标了 [待用户确认]

## 易错点

- **需求不确认就动手**：风格/尺寸没锁定就开画，必然返工——简报确认是第一道闸门。
- **文案写"大概意思"**：主标题必须逐字，不能让设计师自己编活动名/优惠力度。
- **漏场景**：只说"做张海报"没说投在哪，结果竖版投横版位被裁。
- **风格空泛**："要高级感/要大气"无法执行，必须落到参考方向或关键词组合。
- **尺寸只给一个**：KV 通常要多尺寸延展，简报里就要列全，别等做完再补。
