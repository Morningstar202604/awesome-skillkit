# 海报与主视觉 KV 版式模板库

本 skill 是海报/主视觉设计师的**版式依据**。从构图选型到文字层级、再到多尺寸延展，给出可直接套用的经典版式规则，避免每次从零想构图。

## 这是什么

一套经过验证的海报/KV 版式方法论：几种经典构图各自适合什么信息结构、文字怎么排成四级阶梯、主 KV 怎么做多尺寸裁切延展。它给的是版式骨架，具体配色与画面按各项目 brief 定。

## 何时使用

- 主理人派给海报设计师、要做活动海报/主视觉时。
- 设计师构图拿不准、需要选版式方向时。
- KV 定了母版要延展成竖版/横版/方图时。

## 核心步骤

1. **读信息结构**：先看这张图的信息有几层——只有一个大主张？还是标题+活动信息+时间地点？信息层决定构图。
2. **选构图**：单一焦点用居中对称；动感/故事用对角线；图文混排用三分法；冲击感用满版出血。
3. **排文字层级**：主标题 > 副标题 > 活动信息 > 行动号召，字号按 3:1.5:1 阶梯，主标题占视觉重心。
4. **定视觉焦点**：主体（产品/人物/主视觉图形）放在视觉重心，文字避开它不被压住。
5. **延展母版**：以主 KV 为母版，竖版保主标题与主体、横版延展背景、方图居中重排，核心元素不裁丢。

## 清单

- [ ] 构图选型与理由写了
- [ ] 主标题是视觉重心、3 秒可读
- [ ] 四级文字层级（主/副/信息/号召）齐了
- [ ] 主体与文字不互相遮挡
- [ ] 主色+辅助+点缀三色成体系
- [ ] 安全区避开裁切
- [ ] 各延展尺寸（竖/横/方）核心元素都在
- [ ] 出血与分辨率按用途标了
- [ ] 必含 logo/二维码没被裁

## 易错点

- **信息堆砌**：把所有信息都放大，结果没有焦点——必须分主次。
- **主体被文字压住**：字压在人脸/产品关键细节上，又没留留白。
- **只做一个尺寸**：KV 不做延展预案，换尺寸时主体被裁掉。
- **特效过多**：渐变+阴影+光效堆满，显得廉价，学会留白。
- **文字太小**：竖版海报在远处/小图下读不到主标题。
