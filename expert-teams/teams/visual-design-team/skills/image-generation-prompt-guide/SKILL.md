# AI 生图提示词工程指南

本 skill 是全队写生图提示词的**结构化模板**。把"帮我画张好看的图"翻译成结构化描述：主体、构图、视角、光影、材质、风格、画质逐槽位填，再加负面词排雷。适用于任何文生图工具，不绑定特定产品。

## 这是什么

一套生图提示词的槽位模板与排雷清单。好提示词不是堆形容词，而是按"主体→环境→构图视角→光影→材质→风格→画质权重"分层组织，每个槽位给具体可感的描述，而非"好看/高级"。

## 何时使用

- 设计师要用生图工具出海报背景/插画/产品场景图时。
- 生图结果总是跑偏（构图乱/手畸形/风格不对）需要重写提示词时。
- 系列图要保持风格一致、需要固定风格槽位时。

## 核心步骤

1. **写主体**：最具体地描述画什么——对象、数量、动作、表情、服饰、位置。
2. **写环境与背景**：在哪、有什么道具、景深如何。
3. **写构图与视角**：景别（特写/中景/全景）、视角（平视/俯视/仰视）、画幅比例。
4. **写光影**：光源方向、软硬、色温、氛围（黄金时刻/影棚柔光/逆光轮廓）。
5. **写材质与风格**：材质（金属/玻璃/布料/哑光）+ 艺术风格（扁平/油画/3D 渲染/胶片）。
6. **写画质与负面词**：加画质词（高清/细节丰富），列负面词排除畸形/伪文字/多余肢体。

## 清单

- [ ] 主体描述具体到对象+动作+位置
- [ ] 背景与环境写清了
- [ ] 景别与视角指定了
- [ ] 光源方向/软硬/色温写了
- [ ] 材质与艺术风格指定了
- [ ] 画幅比例写明了
- [ ] 负面词排了畸形/伪文字/水印/多余肢体
- [ ] 要保留文字的地方用明确排版说明，不指望 AI 写字
- [ ] 系列图复用同一风格槽位保一致
- [ ] 负面词排除水印、签名、多余文字框

## 易错点

- **堆空洞形容词**："高清精美大图"对构图毫无帮助，要落到具体光影材质。
- **指望 AI 写对文字**：AI 生图里的文字必乱码，需要文字的地方留空位后期排版。
- **不写负面词**：手畸形、多手指、伪文字、水印高频出现，必须显式排除。
- **风格槽位不固定**：系列图每张重写风格词，结果一张一个风。
- **比例不说**：没写画幅比例，生出来裁切不对。
