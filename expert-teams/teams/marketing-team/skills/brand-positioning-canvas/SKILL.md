# 品牌定位画布

本 skill 是品牌定位的工作手册。核心原则：**定位是说给谁听、和谁不一样、凭什么信。** 不是起个好听的名字，而是在目标用户心智里占一个清晰位置。

## 这是什么

一套品牌定位画布工具。从人群痛点出发，对比竞品，提炼差异点与价值主张，再推导出统一传播口径与 slogan。

## 何时使用

- marketing-brand-pr 接到"品牌定位/传播口径/PR 稿"时必须加载。
- marketing-strategist 在策略阶段，用本画布明确品牌主张。
- marketing-content/social-media 创作前，按本画布统一话术。
- marketing-qa-reviewer 审核口径是否偏离定位时对照使用。

## 核心步骤

1. **锁定目标人群**：一句话描述核心人群及其最痛的一个点（如"加班没时间做饭的年轻白领，想吃得健康又快"）。
2. **列竞品与替代方案**：列 3~5 个直接/间接竞品，标注它们各自占的心智位置。
3. **找差异空位**：找竞品都没占、且人群在意的空位；不与头部正面硬刚。
4. **写价值主张**：一句话——"对谁，我们提供什么独特价值，因为什么可信"。
5. **推导传播口径**：统一对内外话术，列出必须说的关键词与禁止说的表述。
6. **提炼 slogan**：slogan 要短、含差异点、可被用户复述；给 2~3 个备选并说明取舍。

## 清单

- [ ] 核心人群与其最痛的一点写清。
- [ ] 列了 3~5 个竞品及其心智位置。
- [ ] 找到了竞品未占的差异空位。
- [ ] 价值主张含人群+独特价值+信任理由。
- [ ] 列了必须说的关键词与禁止表述。
- [ ] slogan 给了 2~3 个备选并说明取舍。
- [ ] 口径可被内容/社媒/达人统一复用。
- [ ] 标注了定位重审触发条件（竞品占位变化/人群迁移）。

## 易错点

- **定位太大**："我们为所有人提供好产品"等于没定位。聚焦一个人群一个痛点。
- **和竞品正面撞**：头部已经占了"更便宜"，你再说自己便宜没人记得住。找空位。
- **没有信任理由**：只说"我们更好"，凭什么信？要给证据（成分/数据/背书）。
- **slogan 自嗨**：用词华丽但用户记不住、复述不出。要口语、可传播。
- **口径不统一**：官网说 A、达人说 B，用户认知混乱。必须统一关键词。
- **定位一成不变**：竞品占位变化或人群迁移时，要重审定位，不抱着旧画布不放。
