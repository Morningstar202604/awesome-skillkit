# 音频剪辑流程指南

本 skill 是 audio-editor 的工作手册。核心原则：**先粗剪定骨架，再精剪去瑕疵，最后归一导出；剪完要听不出剪过的痕迹，只留该留的信息。** 剪辑是把好素材剪成好成品，不是把好信息剪掉。

## 这是什么

一套播客后期剪辑的标准流程。规定粗剪删什么、精剪去什么、对话怎么对齐、音量怎么归一、按什么标准导出。它让不同剪辑师产出的成片质量一致。

## 何时使用

- audio-editor 接剪辑任务时必加载。
- sfx-designer / music-producer 在剪辑后的音频上铺内容时参考节奏。
- qa-reviewer 核对剪辑导出规范时以本指南为准。
- host 预听干声判断是否需重录时参考。

## 核心步骤

1. **粗剪定骨架**：删大段冷场、口误整段、跑题内容；保留所有有信息点。
2. **精剪去口癖**：去"嗯啊""那个""嘶"，删重叠对话与过长留白（保留自然呼吸感）。
3. **对话对齐**：双人节目对齐双方句子，删抢话与尴尬停顿。
4. **补过渡**：剪掉大段后若逻辑断裂，补过渡句或静音填充。
5. **音量归一**：人声电平统一，爆音压缩，轻声提升。
6. **按平台导出**：导出 WAV/MP3，响度达标，标章节时间点。

## 清单

- [ ] 粗删掉了大段冷场与跑题。
- [ ] 有信息点没被误剪。
- [ ] 口癖已去除，无剪辑痕迹。
- [ ] 双人对话对齐，无尴尬停顿。
- [ ] 剪掉处逻辑连贯，无断裂。
- [ ] 人声电平统一。
- [ ] 爆音已压缩。
- [ ] 响度达平台标准（如约 -16 LUFS）。
- [ ] 已标章节时间点。
- [ ] 导出格式正确。

## 易错点

- **剪太狠**：把有价值的讨论当跑题删掉。拿不准先留着。
- **剪辑痕迹**：去口癖后留下咔哒声或呼吸断裂。注意补过渡。
- **留白过度**：把所有停顿剪光，听着像机关枪。留自然呼吸。
- **音量不归一**：忽大忽小，听众要一直调音量。必须归一。
- **爆音不压**：喷麦爆音直接导出。压缩处理。
- **导出不达标**：响度或格式不对，平台拒收。按平台标准。
- **章节缺失**：长节目不标章节，听众跳着听不方便。标时间点。
