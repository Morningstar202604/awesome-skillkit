# 论文级图表制作

本 skill 供「图表专家」使用。一张好图顶半页正文：审稿人先看图，图不行直接拒。本 skill 把"画图"拆成选型、编码、规格、图注四步，杜绝彩虹色、3D 柱、默认 Excel 模板这类投稿硬伤。

## 这是什么

论文图与汇报图的差别：
- **汇报图**：好看、抓眼球、能现场讲。
- **论文图**：单色可读、印刷不糊、图注脱离正文也能看懂、数据诚实。

核心原则一图一信息：每张图只回答一个问题；想讲两件事就拆两张。

## 何时使用

- 用户给数据问"这图怎么做"。
- 用户给一张现成图问"这图能不能投 / 怎么改"。
- 研究设计阶段需要画概念框架图、技术路线图、实验流程图。
- 论文 W1 的 Phase 3 图表分支、W3 稿件打磨出图。

## 核心步骤

1. **先问"这张图要回答什么问题"**：比较各组大小 → 柱状/点图；看分布 → 箱线/小提琴；看关系 → 散点/热图；看时间趋势 → 折线；看流程 → 框图；看因果结构 → 路径图。
2. **选视觉编码**：
   - 类别少（≤4）用色相区分；类别多用灰度/形状，别用彩虹渐变色给类别。
   - 数值连续用单色渐变（避免红绿，色盲不友好）。
   - 误差棒必须写明是标准差(SD)还是标准误(SE)还是 95% CI，三者含义完全不同。
3. **按期刊规格导出**：
   - 位图 ≥300 dpi（线条图/文字图建议 600 dpi 或矢量 PDF/SVG/EPS）。
   - 线宽 0.5–1 pt，字号印刷后 7–9 pt（按最终图宽换算）。
   - 双栏图宽 ~17–19 cm，单栏 ~8–9 cm，先定尺寸再排版。
   - 字体用期刊推荐（Arial/Helvetica/Times），图内文字与正文一致。
4. **去装饰**：删 3D 效果、删多余网格线、删背景色、删不必要图例框；Y 轴不从 0 起步必须显式标注截断。
5. **写自明图注**：
   - Fig 编号 + 一句话主张（"X 显著提高 Y，p<0.01"）。
   - 数据来源、样本量 n、误差棒定义、显著性标记含义。
   - 缩写全部展开；读者不看正文也能懂。

## 清单

- [ ] 这张图要回答的问题一句话写清，一图一信息。
- [ ] 图表类型与数据类型匹配（类别/连续/时序/流程）。
- [ ] 色盲友好：未使用红-绿配对，类别可用灰度区分。
- [ ] 误差棒标注 SD/SE/CI 之一，且与正文一致。
- [ ] 导出 dpi ≥300（矢量图另存 PDF/SVG），线宽字号符合印刷规格。
- [ ] 无 3D、无彩虹类别色、无多余装饰。
- [ ] 图注含主张句 + 数据定义 + 缩写展开，脱离正文可读。
- [ ] 图内数值与正文、表格、代码输出三方一致。

## 易错点

- **柱状图当分布图画**：只画均值柱会掩盖分布形态；样本小、偏态数据用箱线/小提琴/点图。
- **显著性标记乱打**：星号只标在做过检验且多重比较校正过的组间上，别全图乱星。
- **把 PPT 图导出当投稿图**：PPT 导出位图分辨率低、字号在印刷后缩没；必须从原始数据脚本（matplotlib/ggplot/Origin）重出。
- **图注只写"各组比较"**：图注必须是一句话结论，不是"见图"。
- **Y 轴截断骗人**：从 90% 起画柱状图把 5% 差异画成 5 倍视觉差，审稿人最反感这种操纵。
- **彩图投了黑白印刷刊**：确认该刊是否印刷彩图收费；不收费就提前转灰度检查是否还分得开。
