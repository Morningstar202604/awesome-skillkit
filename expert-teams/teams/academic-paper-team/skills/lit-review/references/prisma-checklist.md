# PRISMA 2020 核对表与流程图骨架

> 配套 `lit-review/SKILL.md` 使用。本文件是一页可打印版，综述结束前逐项打勾。

## 一、检索前（方案阶段）

- [ ] 综述问题写成 PICO/SPIDER 一句话。
- [ ] 纳入标准：研究类型、时间窗、语言、人群、发表类型各 ≥1 条。
- [ ] 排除标准：至少写清"哪些看似相关但不要"，如仅摘要、社论、撤稿。
- [ ] 数据库清单已定（≥2 英文库 + 视情况中文库）。
- [ ] 检索式已在目标库试跑，命中量落在 200–2000 之间。
- [ ] 双人初筛已指定，分歧处理规则（第三人仲裁）已写。

## 三、筛选阶段数字（PRISMA 四框）

```
Identification
  数据库识别文献 n1 =  n_WoS + n_Scopus + ...
  其他来源（引文追溯、手检） n2
  合计 n = n1 + n2
        │
        ▼ 去重后 n_uniq = n - n_dup
Screening
  标题摘要初筛：
    纳入 n_screen_in
    剔除 n_screen_out（原因码：不相关/非实证/非目标人群…）
Eligibility
  全文复筛：
    评估全文 n_fulltext = n_screen_in
    剔除 n_full_out（原因码：数据不可用/方法不符…）
Included
  最终纳入 n_included
```

数字必须闭环：`n_uniq = n_screen_in + n_screen_out`；`n_fulltext = n_full_out + n_included`。

## 四、证据提取表字段（每篇一行）

- 作者(年份)、国家、研究类型（RCT/队列/横断面/建模/案例）
- 样本量、抽样方法
- 核心自变量、因变量、控制变量
- 方法/模型、显著性结果、效应量
- 作者声称的主要结论
- 作者自陈局限 + 我读出来的局限
- 与本综述问题的相关度（高/中/低）

## 五、综合写作三段式

1. **共识**：多篇独立研究结论一致处，明确写"X 对 Y 的正向作用在 N 项研究中被重复"。
2. **争议**：结论打架处，列出分歧双方、各自方法差异，不强行裁决。
3. **空白**：没人做/数据缺失/方法有硬伤处，回链给 paper-topic-selector 作为候选选题。
