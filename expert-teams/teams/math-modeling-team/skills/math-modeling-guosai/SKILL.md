# 国赛数学建模资料库（高教社杯 CUMCM）

本 skill 为「数学建模战队」深度定制，面向**全国大学生数学建模竞赛（国赛）**，与美赛 MCM/ICM 区分：国赛**不要求英文摘要**、强调**现实意义与机理建模**、**查重极严**、论文**摘要单独成页**、程序与数据放**附录**。

## 文件索引
- `references/question-type-map.md`：A/B/C/D/E 题型 → 建模方向 → 常用方法 → 判分关注点
- `references/model-library.md`：国赛高频模型速查（评价/预测/优化/分类/图论/微分方程/仿真）
- `references/paper-template.md`：国赛论文 LaTeX 骨架、结构规范、摘要单页、附录程序、图表规范
- `references/judging-checklist.md`：评审要点自查表、查重规避、3 天时间节奏

## 使用约定
- **主理人**在 Phase 0 加载本库完成「题型识别 + 路线规划 + 创新点设计」。
- **范数模（建模）**在 Phase 1 查阅 `model-library.md` 与 `question-type-map.md` 选模型。
- **苏解元（求解）**在 Phase 2 依模型库落地代码，并按 `judging-checklist.md` 做灵敏度/检验。
- **毕成文（写作）**在 Phase 3 严格套用 `paper-template.md` 结构与摘要规范。
- 所有成员输出须回扣 `judging-checklist.md` 的评审要点，确保「模型—求解—结论」一致且可溯源。
- 本团队将持续安装更多**专用 skill**。所有成员开工前须先扫团队 `skills/` 目录，命中相关 skill 即按它执行、积极参考——详见各 Agent MD 的「技能调用协议」（主理人 MD 与每位成员 MD 均含「开工必查」规则）。
- **思想纪律（主人铁律）**：全员严格忠于用户给的原文/赛题，照原意执行；不过度思考、不绕圈；一旦思考出界或同一答案反复出错 2–3 轮仍无解，立刻停手回头查根因（判定是前提/理解/方法错了），上报主理人复核，**绝不在错误前提上继续堆工作量**。详见各 Agent MD 的「思想纪律（开工必守）」与主理人 MD 的「思想纪律」整节。
- **思维强化（能力升级）**：在纪律框架内把思考质量做上去——主理人升级「题意拆解/多方案利弊推演/风险预判/一致性总控」；modeler 强化「机理优先推理/假设可追溯/边界反事实/选型论证」；solver 强化「量纲直觉自检/方法为什么/异常归因/稳健性推演」；writer 强化「论证链可追溯/摘要因果自洽/一致性精校/查重下原创表达」。详见各 Agent MD 的「思维强化（受控深度思考·能力升级）」。
- **自检清单技能 `math-modeling-selfcheck`**：把上述两条铁律固化成「开工前 / 产出后」可勾选闸门（A 组 5 项 + B 组 5 项 + 出错即停触发 + 停后回溯），全员每阶段必过，任一不过即停手。详见该 skill 的 `SKILL.md` 与 `references/self-checklist.md`。

## 核心速查

### 题型映射摘要（详见 references/question-type-map.md）
- **A 题（连续/机理）**：物理工程过程，用 ODE/PDE、变分、插值拟合与机理优化；判分看机理是否站得住、方程推导与量纲边界是否严谨。
- **B 题（离散/运筹）**：调度、选址、网络与博弈，用图论网络流、整数/非线性规划、多目标与智能算法；判分看可行性、最优性论证与约束完整性。
- **C 题（数据/大数据）**：清洗、统计推断、预测分类，用回归/时序/机器学习、聚类与可视化；判分看数据质量处理、方法适配与结果可解释性。
- **D 题（经管/人文）**：评价决策与政策量化，用 AHP/熵权/TOPSIS、博弈、系统动力学；判分看指标体系合理性与现实政策含义。
- **E 题（环境/跨学科）**：可持续发展与生态能源，用机理+数据混合、系统动力学、多目标仿真；判分看现实意义与跨学科自洽。

### 模型库摘要（详见 references/model-library.md）
- **评价类**：AHP（主观赋权，须一致性 CR<0.1）、熵权法（客观赋权，先归一化）、TOPSIS（方案排序，做向量归一）。
- **预测类**：多元回归（查共线性）、ARIMA（先平稳化）、灰色 GM(1,1)（小样本≥4）、LSTM（大数据防过拟合）、马尔可夫链（稳态假设）。
- **优化类**：LP（linprog 先标准化）、整数/0-1 规划（pulp）、NLP（初值敏感防局部最优）、多目标 NSGA-II（讲清权衡）、GA/PSO（参数别乱设）。
- **分类/聚类**：K-Means（定 K+标准化）、随机森林/SVM、PCA 降维；工具 sklearn。
- **图论/网络**：最短路 Dijkstra、最大流、最小生成树、匈牙利匹配；工具 networkx。
- **微分方程/机理**：ODE（solve_ivp，初值与量纲）、PDE（有限差分/FEM，网格别太粗）、差分方程、元胞自动机。
- **仿真/检验**：蒙特卡洛、参数敏感性（Sobol）、bootstrap 置信区间、交叉验证。
- **选型铁律**：无数据走机理、有数据走数据驱动；一个主模型+至多一个对比模型；写清「为什么用它」，创新点在摘要点明。

### 论文结构要点（详见 references/paper-template.md）
- **摘要单页**：评委最先看，含七要素（问题/假设/模型/方法/关键数值/检验/创新点），必须出现具体数字，匿名不写队伍信息。
- **正文五节**：问题重述 → 假设与符号说明 → 模型建立与求解（按小问分节）→ 检验/灵敏度/稳健性 → 评价改进与推广，外加参考文献。
- **附录**：核心程序代码与原始数据，标注文件名与运行环境，须与正文逻辑一致。
- **图表规范**：图题在图下、表题在表上、三线表、坐标轴带单位与标签、符号全文统一编号、≥300dpi。

### 评审自查要点（详见 references/judging-checklist.md）
- **模型一致性**：假设—模型—求解—结论首尾咬合，符号/数值不漂移；随机种子固定、代码可复现。
- **查重规避**：不抄往届论文/教材原文，表述原创改写，程序自己写，引用数据与方法标注来源。
- **3 天节奏**：Day1 选题+定模型框架，Day2 跑通主模型出数值+搭写作骨架，Day3 成稿终审+打包（PDF+程序+数据）。

## 何时加载与加载后先做什么
- **主理人 Phase 0（开赛即加载）**：① 通读三题，用题型映射摘要判 A/B/C/D/E 方向并定选题；② 按队伍擅长（数值推导/优化编程/数据统计）给选题建议，并把每小问串成「假设→模型→求解→检验」路线；③ 选定主模型类别与创新点，下发本题可用 skill 清单，再交范数模。
- **范数模 Phase 1**：先读 `question-type-map.md` 对应题型的小问落点，再翻 `model-library.md` 选定主模型+一个对比模型，写清假设、符号与选型理由，过 selfcheck 开工前闸门。
- **苏解元 Phase 2**：按模型库工具表搭代码，固定随机种子、跑通出关键数值，补参数敏感性与稳健性仿真，结果回传前过产出后闸门。
- **毕成文 Phase 3**：套 `paper-template.md` LaTeX 骨架，摘要单页七要素、图表规范、程序入附录，全程对齐查重规避。
- **全员**：加载本库后先过 `math-modeling-selfcheck` 开工前闸门；每阶段产出回传前再过产出后闸门，任一不过即停手回溯根因，不在错误前提上堆工作量。
