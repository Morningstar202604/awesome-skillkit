# 国赛题型映射（A/B/C/D/E）

> 国赛本科组通常出 A/B/C 三题（近年为 A 连续/B 离散/C 数据），专科组 D/E。选题直接影响建模方向与判分重心。**主理人 Phase 0 先用本表识别题型并给出选题建议**，再交给范数模定模型。

## 总览表
| 题号 | 典型性质 | 核心建模方向 | 高频方法 | 判分关注 |
|------|---------|-------------|---------|---------|
| **A 题** | 连续型 / 机理分析 | 物理/工程/地理过程机理建模 | 微分方程（ODE/PDE）、变分、插值与拟合、优化 | 机理是否站得住、方程推导严谨、量纲与边界条件 |
| **B 题** | 离散型 / 运筹优化 | 资源配置、网络、调度、博弈 | 图论与网络流、整数/非线性规划、排队论、多目标优化、智能算法 | 模型规模与可行性、最优性论证、约束完整性 |
| **C 题** | 数据型 / 大数据 | 数据清洗、统计推断、预测、分类 | 回归/机器学习、时间序列、聚类分类、文本/图像特征、可视化 | 数据质量处理、方法适配、结果可解释性 |
| **D 题** | 经管 / 人文 | 评价、决策、政策量化 | 评价模型（AHP/熵权/TOPSIS）、博弈、系统动力学 | 指标体系合理性、现实政策含义 |
| **E 题** | 环境 / 跨学科 | 可持续发展、生态、能源 | 机理+数据混合、系统动力学、多目标、仿真 | 现实意义、跨学科自洽 |

## 选题决策树（主理人用）
1. 队伍擅长数值计算/推导 → 优先 A；擅长优化/编程 → 优先 B；擅长数据/统计 → 优先 C。
2. 数据给得全且干净 → C 易出结果；数据缺失严重 → 谨慎，转 A/B 以机理为主。
3. 想冲高奖：选「能做出清晰创新点」的题，而非「看起来简单」的题。
4. 三问结构：国赛一题意含多小问（通常 3–5 问递进），路线须把每问串成「假设→模型→求解→检验」闭环。

## 每小问建模落点
- 第 1 问：定义与描述（重述+指标/变量定义+简单模型铺底）。
- 第 2 问：核心模型（主模型建立与求解，全文重点）。
- 第 3 问：深化/对比（改进模型、灵敏度、稳健性、情景分析）。
- 第 4+ 问：推广/决策（泛化条件、政策建议、可行性论证）。
