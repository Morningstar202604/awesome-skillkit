# 国赛建模自检清单（强制闸门）

本 skill 是战队的**强制闸门**。它把「思想纪律」与「思维强化」两条铁律，变成可逐条勾选的动作。所有成员在**开工前**与**每段产出回传前**必须逐项过单；**任意一项未过即停手**，按「思想纪律」回头查根因，不得带病进入下一阶段。

> 配套可读：本 skill 的 `references/self-checklist.md` 是一页可打印版，供照单勾选。

## 一、开工前闸门（Pre-work Gate）

适用：主理人 Phase 0 定路线、成员接到任务开工前。

- [ ] **原文对齐**：我清楚本次严格以哪份原文（赛题 / 数据 / 约束）为准，并已锁定范围边界，不擅自扩张。
- [ ] **技能扫描**：已扫团队 `skills/` 目录，命中相关 skill（含本自检清单）即按它来。
- [ ] **题意拆解**：能回答主理人四问——① 到底决策/优化什么？② 已知未知边界？③ 背后机理因果链？④ 原文哪句暗示方向？每个答案都回扣原文某处。
- [ ] **风险预判**：已标出本题最大 2 个翻车点（数据缺失 / 模型不可算 / 结论对不上）并写明兜底。
- [ ] **不出界**：本轮要做的都落在本题范围内，没有发散到无关主题、没引入原文没有的复杂框架。

## 二、产出后闸门（Post-output Gate）

适用：modeler / solver / writer 回传主理人前，主理人中转前。

- [ ] **忠于原文**：产出未偷换题意、未脑补原文没有的假设 / 数据 / 结论。
- [ ] **边界与反事实**：已想关键参数取极端、数据缺失、换口径会怎样；脆弱点已说明或兜底。
- [ ] **论证链可追溯**：每个结论都能回链到上游假设 / 数值 / 证据，无无源结论。
- [ ] **一致性**：符号 / 数值 / 结论与上游产出首尾咬合，无漂移、无对不上。
- [ ] **不绕圈**：本段是一次到位，没有在同一分支反复自我推翻又重来。

## 三、出错即停触发（Error-Stop）

出现以下任一信号，**立刻停手**，判定是前提 / 理解 / 方法错了，回主理人复核，绝不在原方向硬磕：

- 思考明显出界（发散到无关主题、引入原文没有的复杂框架）。
- 同一答案 / 结论反复出错或对不上 **2–3 轮仍无解**。
- 任一闸门项连续两次无法勾选且找不到合理解释。

## 四、回溯动作（Stop → Root-cause）

1. 暂停当前方向，禁止继续堆工作量。
2. 回头逐条复核：原文哪句读偏了？假设哪条不成立？方法为什么错？
3. 定位真正偏差点，向主理人（及用户）明确上报「哪里可能理解错了」。
4. 由主理人决定是否纠偏或向用户确认，再重启。

## 五、与主理人 protocol 的关系

- **主理人**在 Phase 0 把「本题可用 skill 清单」与「自检清单」一并下发；成员调度时明确「开工前 + 产出后必过单」。
- **成员**若某一项长期勾不上，不在原方向硬试，直接回传主理人：判定是「对题意读偏 / 题型判错 / 模型不可算 / 上游矛盾」之一，由主理人带其复核原文。
- 本清单与 `math-modeling-guosai` 资料库、各阶段专用 skill **并列必查**；清单是「纪律闸门」，资料库/专用 skill 是「方法依据」。
