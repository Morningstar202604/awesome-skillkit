# 国赛建模自检清单（一页打印版）

> 用法：每个 Phase 开工前勾「A 组」，产出回传前勾「B 组」。任一 □ 未勾 → 停手，按「思想纪律」回溯，禁止带病进入下一阶段。

## A. 开工前闸门（Pre-work）

| # | 检查项 | 勾 |
|---|--------|----|
| A1 | 原文对齐：锁定以哪份原文为准 + 范围边界，不擅自扩张 | ☐ |
| A2 | 技能扫描：已扫 `skills/`，命中 skill 即按它来（含本清单） | ☐ |
| A3 | 题意拆解四问全答，且每答回扣原文某处 | ☐ |
| A4 | 风险预判：最大 2 翻车点 + 兜底已写明 | ☐ |
| A5 | 不出界：本轮都在本题范围内，无发散 | ☐ |

## B. 产出后闸门（Post-output）

| # | 检查项 | 勾 |
|---|--------|----|
| B1 | 忠于原文：未偷换题意 / 未脑补假设·数据·结论 | ☐ |
| B2 | 边界与反事实：极端/缺失/换口径已想，脆弱点已说明 | ☐ |
| B3 | 论证链可追溯：每结论回链上游假设/数值/证据 | ☐ |
| B4 | 一致性：符号/数值/结论与上游首尾咬合 | ☐ |
| B5 | 不绕圈：一次到位，无反复自我推翻 | ☐ |

## C. 出错即停（任一出现 → 立刻停）

- [ ] 思考明显出界（无关主题 / 原文没有的框架）
- [ ] 同一答案反复出错或对不上 **2–3 轮仍无解**
- [ ] 任一项连续两次勾不上且无合理解释

## D. 停后动作（Stop → Root-cause）

1. 暂停，禁堆工作量
2. 复核：原文哪句读偏？假设哪条不成立？方法为何错？
3. 上报主理人（及用户）：「哪里可能理解错了」
4. 主理人定夺：纠偏 / 向用户确认 → 再重启
