# 剪辑方法论（节奏 · 转场 · 音画同步）

本 skill 是剪辑的方法论核心。它把"剪得好"拆成可执行的动作：先粗剪定结构、再精剪调节奏，转场按情绪选，切点卡在动作与音乐上。平台中立，不绑定任何剪辑软件。

## 这是什么
一套剪辑流程与判断标准：粗剪解决"讲什么、多长"，精剪解决"什么节奏、在哪切"，转场服务情绪不炫技，音画点精准咬合。它让成片有呼吸感而不是匀速拖长。

## 何时使用
- 拿到素材要从粗剪开始时。
- 成片节奏拖沓、看着累时。
- 转场生硬、音画对不齐时。
- 剪辑师开工时。

## 核心步骤
1. **粗剪定结构**：按分镜把素材排成叙事骨架，先不纠结细节，定总时长。
2. **画节奏曲线**：标全片快慢起伏——信息密集处快、情绪点处留停顿。
3. **找切点**：在动作顶点、语言停顿、音乐重音处切，让转场隐形。
4. **选转场**：日常叙事用硬切，时间/情绪跳跃用叠化，动势连续用动势接/匹配剪辑；不为炫技加花哨转场。
5. **音画同步**：对白、音效、音乐的起承转合对齐画面切点。
6. **删冗余**：剪掉不承担叙事功能的素材，宁短勿拖。

## 清单
- [ ] 粗剪结构完整、总时长达标。
- [ ] 节奏有快慢起伏，不是一个速度到底。
- [ ] 切点落在动作/停顿/重音上。
- [ ] 转场按情绪选用，没有炫技转场。
- [ ] 音画点对齐，不滞后不抢拍。
- [ ] 前 3 秒钩子镜头剪进去了。
- [ ] 必含信息点没被删掉。
- [ ] 无黑帧/废镜头/卡顿点。
- [ ] 节奏曲线已标注供下游卡点。
- [ ] 转场数量克制，不喧宾夺主。

## 易错点
- **匀速到底**：全程一个节奏，观众疲劳——设计快慢呼吸。
- **切点生硬**：在动作中间切，看着跳——在动作顶点/停顿处切。
- **转场滥用**：堆叠化/闪白/特效转场，喧宾夺主——叙事优先硬切。
- **舍不得删**：拍得好但没用的镜头硬留——按叙事功能取舍。
- **音画脱节**：音乐起了画面还没动，或音效早于画面——逐点对齐。
