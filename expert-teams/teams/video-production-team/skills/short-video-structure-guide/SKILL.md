# 短视频结构方法论（竖屏完播导向）

本 skill 是竖屏短视频的完播结构方法论。它解决一个问题：怎么让刷到的人不停下来划走，一直看到结尾。平台中立，不绑定任何平台或工具。

## 这是什么
一套以"留存"为目标的短视频结构：前 3 秒强钩子抓人，中段每 5-10 秒给刺激点防划走，结尾行动号召。附带竖屏构图安全区与节奏密度规则。

## 何时使用
- 做竖屏短视频/信息流广告时。
- 完播率低、观众前几秒就划走时。
- 不知道前 3 秒放什么时。
- 短视频专家开工时。

## 核心步骤
1. **判平台与时长**：定 9:16 竖屏、目标时长（15s/30s/60s/90s）。
2. **选钩子**：从前 3 秒四类里选——悬念（这是怎么做到的）/痛点（你是不是也…）/反常识（90% 的人都做错了）/利益（3 秒教你…）。
3. **排刺激点**：中段每 5-10 秒安排一个信息/反转/笑点/金句，防止留存掉。
4. **控信息密度**：一条只讲一个核心点，口语短句，无废话。
5. **竖屏构图**：主体居中、重要信息避开底部字幕区与两侧 UI 热区。
6. **收尾 CTA**：明确动作引导，不留"谢谢观看"式空尾。

## 清单
- [ ] 前 3 秒是四类钩子之一，不是空镜/自我介绍。
- [ ] 每 5-10 秒有一个刺激点（信息/反转/笑点/金句）。
- [ ] 全片只讲一个核心点。
- [ ] 口语短句，无书面长句。
- [ ] 主体居中，信息避开底部与两侧 UI 区。
- [ ] 结尾有明确 CTA。
- [ ] 时长落在目标区间，不拖沓。
- [ ] 无绝对化/夸大宣传等违规话术。
- [ ] 开头即进入正题，无自我介绍铺垫。
- [ ] 竖屏主体不被平台 UI 裁切。

## 易错点
- **铺垫式开场**：先报家门/放 logo，3 秒后人已划走——钩子第一秒就上。
- **节奏平**：全程一个语速一个信息量，中段掉留——定时给刺激点。
- **贪多**：一条塞三四个卖点，结果都没记住——聚焦一个点。
- **构图失误**：主体或字幕被平台 UI 挡住——竖屏预留安全区。
- **夸大违规**：为博眼球用"最/第一/必看"等绝对化用语——合规优先。
