# 分镜设计指南（从脚本到可拍镜头表）

本 skill 是把脚本翻译成分镜表的方法论。它规定分镜表的标准字段、景别与运镜的情绪语义、时长累计与转场标注，以及如何提前预判拍不出来的镜头。平台中立，不绑定任何拍摄/绘图软件。

## 这是什么
一套分镜设计方法：一张标准分镜表把脚本逐镜拆开，每镜标景别、运镜、画面、对白、时长、转场。它让拍摄有依据、剪辑师拿到就能剪，并在开工前暴露高难度镜头。

## 何时使用
- 定稿脚本出来后要做分镜时。
- 不知道某个台词该用什么景别/运镜时。
- 竖屏视频要规划构图安全区时。
- 分镜师开工时。

## 核心步骤
1. **逐镜拆分**：按脚本段落，一句话一个镜头，镜号连续编号。
2. **选景别**：特写给情绪/细节，近景给表情，中景给动作关系，全景给环境/信息，远景给交代。
3. **选运镜**：固定给稳定感，推近给强调/代入，拉远给揭示，摇移给跟随/展示，跟拍给沉浸。
4. **填字段**：每镜写画面内容、对白/旁白、预估时长、转场方式。
5. **累计时长**：逐镜加总，确保与脚本时长预算一致。
6. **标高难度**：标⚠高难度镜头并给替代方案；竖屏标安全区。

## 清单
- [ ] 每个镜头都有镜号、景别、运镜、画面、对白、时长。
- [ ] 景别与情绪匹配（情绪点用特写，交代用全景）。
- [ ] 总累计时长 = 脚本预算 ±10%。
- [ ] 开场首镜与结尾收束镜单独标注。
- [ ] 镜头间转场标了（硬切/叠化/动势接）。
- [ ] 高难度镜头标⚠并给替代镜头。
- [ ] 竖屏标了主体居中与底部字幕安全区。
- [ ] 必含信息点都有镜头覆盖。
- [ ] 镜号连续、无重复无遗漏。
- [ ] 高难度镜头已标注拍法或替代。

## 易错点
- **景别单一**：全程中景固定机位，看着平——按情绪变化切景别。
- **运镜炫技**：无目的推拉摇移，分散注意——运镜服务情绪才用。
- **时长失控**：不累计秒数，拍完才发现超时长——边画边加总。
- **拍不出的镜头**：分镜写得酷但现场拍不了——提前标⚠给替代。
- **忽略竖屏安全区**：主体被 UI/字幕挡——竖屏构图预留底部与两侧安全区。
