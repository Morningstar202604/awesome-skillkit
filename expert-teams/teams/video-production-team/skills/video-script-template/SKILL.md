# 视频脚本结构模板（钩子 → 展开 → 行动号召）

本 skill 是写视频脚本时的**结构骨架**。它把模糊的 brief 套进一个经过验证的三段式结构，让脚本一次到位、可拍可剪。平台中立：不绑定任何剪辑软件或 AI 视频工具，只给方法论、表格模板与检查清单。

## 这是什么
一套通用视频脚本骨架：先用一句话定核心主张，再按「钩子 → 展开 → 行动号召」分段，每段标注秒数、画面、旁白、字幕与音效提示。适用于短视频、口播、广告、宣传片；纪录片/访谈在此骨架上把"展开"换成叙事弧线即可。

## 何时使用
- 接到 brief 要从零写脚本时。
- 脚本写得散、不知道前 3 秒放什么时。
- 时长压不下来、信息塞不下时。
- 编剧导演、短视频专家、口播纪录片专家开工时。

## 核心步骤
1. **定核心主张**：一句话写清"这条片子要观众看完后做什么/记住什么"，作为全片锚点。
2. **分配时长预算**：按目标时长给三段分配秒数（参考 60s：钩子 3s + 展开 45s + CTA 12s；30s：钩子 3s + 展开 20s + CTA 7s）。
3. **写钩子（前 3 秒）**：从悬念/痛点/反常识/利益四类里选一个，第一句就给理由看下去。
4. **写展开**：按"问题→方案→证明"或"一个核心点讲透"推进，每 5-10 秒一个信息/情绪点，删掉不承担功能的注水段。
5. **写行动号召（CTA）**：明确具体动作（关注/评论/点击链接/购买），不含糊。
6. **填脚本表**：逐段写画面、旁白/对白、字幕、音效提示，标注每段秒数。

## 清单
- [ ] 一句话核心主张写出来了。
- [ ] 前 3 秒有强钩子（不是铺垫式开场）。
- [ ] 每段秒数相加 = 目标时长 ±10%。
- [ ] 旁白/对白是口语短句，没有书面长难句。
- [ ] 每 5-10 秒有一个信息或情绪点。
- [ ] 必含信息点全部覆盖。
- [ ] CTA 是具体动作，且不违反广告法。
- [ ] 每段都标了画面/字幕/音效提示。
- [ ] 删掉了不承担叙事功能的注水段。

## 易错点
- **开场铺垫太长**：前 3 秒还在自我介绍/空镜，观众已划走——钩子必须第一句就上。
- **信息超载**：一条片子塞多个核心点，结果一个都没记住——只讲一个主张。
- **书面腔**：旁白像念文章，听着累——按说话节奏写短句。
- **CTA 含糊**：结尾只说"谢谢观看"，没有明确动作——给出下一步。
- **时长失控**：不按秒数预算写，写完全片超时长一半——先预算后填内容。
- **没有视听提示**：只写旁白不写画面/字幕/音效，下游没法落地——每段都标视听提示。
