# 产品指标体系指南

本 skill 是 product-data-analyst 的工作手册。核心原则：**先定义口径再读数，指标必须能指导行动；虚荣指标（注册量）看着好看但不指向决策，要追可行动指标（激活率/留存）。** 没有指标的功能上线等于盲飞。

## 这是什么

一套指标搭建与读数流程。从北极星指标出发，按 AARRR（获取/激活/留存/变现/传播）拆层级指标，每个指标写清口径（分子/分母/时间窗）、数据源、看板位置。A/B 实验需事前定假设、样本量、显著性阈值（p<0.05）。

## 何时使用

- product-data-analyst 接到"定核心指标/分析效果"任务时，必须加载本 skill。
- product-prd-writer 写 PRD 埋点需求时，参考本指南明确事件与指标口径。
- product-roadmap-planner 评估功能价值、定成功指标时，参考本指南选取可行动指标。
- product-qa-reviewer 终检时，核对指标口径是否一致、有无事后挑数。

## 核心步骤

1. **定北极星**：一句话代表产品为用户创造的核心价值（如"周活跃完成关键动作的用户数"），不超过 1 个。
2. **拆 AARRR 层级**：按获取→激活→留存→变现→传播拆二级指标，每环节选 1-2 个可行动指标。
3. **写指标口径**：每个指标写分子/分母/时间窗/去重规则/数据源；如"激活率=注册后 7 日内完成 A 动作用户数/注册用户数"。
4. **搭漏斗与留存**：关键转化路径画漏斗，定位掉点；用留存曲线判断功能是真留存还是一次性热闹。
5. **设计 A/B 实验**：事前写假设（"改 X 会提升 Y%"）、实验分组、样本量、观测周期、显著性阈值（p<0.05），不偷看提前下结论。
6. **读数与归因**：数据变动先拆维度（渠道/人群/版本），排除季节性与活动扰动，再给因果假设。

## 清单

- [ ] 北极星指标唯一、能反映核心价值。
- [ ] AARRR 各环节有 1-2 个可行动指标，不是虚荣指标。
- [ ] 每个指标写清分子/分母/时间窗/数据源。
- [ ] 关键转化路径有漏斗，标注掉点位置。
- [ ] 留存曲线画了，区分一次性与真留存。
- [ ] A/B 实验事前写了假设/样本量/周期/显著性阈值。
- [ ] 数据变动拆了维度，排除了季节性/活动干扰。
- [ ] 结论区分了相关与因果，不过度归因。
- [ ] 口径与历史报表一致，无事后改定义。

## 易错点

- **虚荣指标自嗨**：追注册量/曝光量，但这些数涨了不代表产品变好。要追激活、留存。
- **口径不一致**：PRD 说的"活跃"和报表里的"活跃"定义不同，对不上账。先统一口径。
- **A/B 偷看提前停**：数据刚好看上去好就提前停实验，结果是随机波动。必须跑满预定周期。
- **把相关当因果**：新功能上线后留存涨了，就归功于功能——可能是同期活动或季节因素。
- **事后挑数**：结论先定，再挑支持它的时间段和维度。口径必须事前冻结。
