# 本地化清单

本 skill 是 cultural-adaptor 的核对清单。核心原则：**忠实度不动，只把表达方式换成目标市场读者熟悉且不冒犯的。** 直译准确但本地看不懂或会冒犯时，才动用本清单。

## 这是什么

一份本地化适配的逐项检查清单。规定文化梗怎么换算、单位货币日期怎么转、语气怎么匹配、哪些禁忌必须规避、字幕的物理长度约束。它让本地化从"凭感觉"变成"逐项打勾"。

## 何时使用

- cultural-adaptor 在营销/界面/字幕类译文做本地化时必加载。
- localization-manager 规定交付格式与单位规则时参考。
- qa-reviewer 判定文化冒犯风险时对照本清单。
- subtitle 控制单行长度与阅读时长时使用本清单字幕项。

## 核心步骤

1. **扫文化负载点**：通读译文，标出典故、谐音梗、名人、俚语、双关。
2. **换算文化梗**：优先换目标市场等效梗；无双关等效则意译加简短注释。
3. **转单位货币日期**：度量衡按目标市场；货币注明换算；日期/时间/地址格式本地化。
4. **匹配语气**：按目标市场文化调整语气（如美式直接、日式委婉），不改事实。
5. **扫禁忌**：宗教、政治、性别、肤色、数字避讳逐项排查，风险处标注。
6. **字幕物理约束**：单行字符数达标（英文 ≤42/行），每条显示时长 ≥1.5 秒。

## 清单

- [ ] 文化梗已换成本地等效表达或加注。
- [ ] 双关语有处理方案（等效双关/意译加注）。
- [ ] 度量衡/货币按目标市场转换。
- [ ] 日期/时间/地址格式已本地化。
- [ ] 语气匹配目标市场文化。
- [ ] 宗教/政治/性别/肤色禁忌已排查，无冒犯。
- [ ] 数字吉利/避讳已注意。
- [ ] 字幕单行长度达标、时长 ≥1.5 秒。
- [ ] 事实信息零改动。

## 易错点

**为本地化改事实**：把"北京"改成"上海"以贴近读者，这是篡改不是本地化。事实零改动。
- **单位漏转**：英里/华氏度/加仑没转公制，本地读者没概念。逐项转。
- **梗硬译**：把中文谐音梗直翻英文，老外完全 get 不到。换等效或加注。
- **踩禁忌不自知**：某些手势、颜色、数字在特定市场有冒犯含义。逐项排查。
- **语气错位**：日式市场用美式强推销语气，显得冒犯。先研究目标市场语气。
- **字幕过长**：一行塞 60 个字符一闪而过，读不完。控长度、控时长。
- **忽略注释**：加了注释却太长破坏阅读。注释要短，紧跟梗后。
