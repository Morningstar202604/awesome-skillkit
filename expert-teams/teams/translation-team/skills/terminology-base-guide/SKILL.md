# 术语表指南

本 skill 是 terminologist 的工作手册。核心原则：**一个概念在全稿里只有一个译法，歧义词由术语专家定夺，译者不得各自发挥。** 术语表是翻译流程的第一道闸，先建表再翻译。

## 这是什么

一套术语表的结构与维护规范。规定术语表长什么样、歧义词怎么裁决、同义词怎么归一、缩写怎么处理、术语变更怎么同步给在途译者。它保证多译者并行翻译时口径一致。

## 何时使用

- terminologist 在翻译阶段前建/维护术语表时必加载。
- 所有译者开工前对照术语表，遇表外词标注时参考本指南。
- localization-manager 同步跨语种术语时参考。
- proofreader / qa-reviewer 核对术语一致性时以术语表为准。

## 核心步骤

1. **抽取术语**：通读原文，列出领域术语、专名、缩写候选，按领域分组。
2. **建表结构**：每条术语四列——原文、推荐译法、禁用译法、适用语境。表未覆盖处允许译者标 [待术语确认]。
3. **裁决歧义词**：一词多义按上下文定唯一译法；同名异义（如 commit）给不同语境下的不同译法。
4. **归一同义词**：原文多个同义词归并到同一目标语术语，避免一概念多译。
5. **处理缩写**：缩写给全称；外来词首次出现给注释。
6. **同步与变更**：术语变更记录历史，新增术语立即同步所有在途批次；变更后旧译法作废。

## 清单

- [ ] 术语表按领域分组，四列齐全（原文/推荐译法/禁用译法/语境）。
- [ ] 每个歧义词都定了唯一译法。
- [ ] 同义词已归一，无一概念多译。
- [ ] 缩写给了全称。
- [ ] 外来词首次出现给了注释。
- [ ] 表外词有 [待术语确认] 标注机制。
- [ ] 术语变更有记录并已同步在途批次。
- [ ] 译者拿到的是最新版术语表。

## 易错点

- **术语悬空**：歧义词不给裁决，把"视情况而定"留给译者，导致一概念多译。必须定死。
- **同义词不归一**：原文三种说法译出三种目标语表达，读者以为是三个东西。必须归一。
- **缩写不给全称**：首次出现的缩写读者看不懂。给全称+缩写。
- **术语表不同步**：改了术语表但在途译者还在用旧译法。变更必须广播。
- **术语越界**：把普通常用词也塞进术语表，反而增加负担。只收领域专词。
- **禁用译法不写**：只写推荐译法不写禁用译法，译者仍会踩坑。每条给禁用项。
