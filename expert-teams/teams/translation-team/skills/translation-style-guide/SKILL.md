# 翻译风格指南

本 skill 是全团队译者的文风基准。核心原则：**意思忠实优先，表达地道其次，术语一致贯穿始终。** 不逐字硬译，也不为地道而改事实。所有译者开工先读本指南，保证全稿文风统一。

## 这是什么

一套跨双向互译的语体与格式规范。规定什么场景用正式/口语语体、标点怎么打、数字单位日期怎么转、长句怎么拆、哪些翻译腔必须消灭。它不替代术语表，只管"怎么写得像目标语作者"。

## 何时使用

- zh-to-en / en-to-zh 译者开工成稿时必加载。
- technical 技术翻译确定技术语体时参考。
- proofreader 校对标点与语体时对照。
- cultural-adaptor 把握目标市场语气时参考。

## 核心步骤

1. **判文本类型定语体**：技术文档用中性正式词；营销文案用感染力词；字幕用口播短句；法律文件用严谨书面语。先定语体再动笔。
2. **定语序**：中文流水句拆成英文主谓结构；英文长从句拆成中文短句。一句一意，不堆多重定语。
3. **转写数字单位日期**：数字按目标语千分位/小数点习惯；单位按目标市场（公制/英制）；日期格式按目标市场（YYYY-MM-DD / MM/DD/YYYY）。
4. **标点规范**：英文用半角标点加空格；中文用全角标点。列表/表格/标题层级与原文对齐。
5. **消灭翻译腔**：英文稿删中式英语（"very good" 式堆砌）；中文稿删翻译腔（"被""作为……的"堆叠、超长定语）。
6. **保留结构**：编号、占位符、变量、代码、标签原样保留，不译不改。

## 清单

- [ ] 先判了文本类型并选定语体。
- [ ] 长句已按目标语语序重组，无多重从句堆叠。
- [ ] 数字/单位/日期按目标市场规范转写。
- [ ] 标点符合目标语规范（半角/全角、空格）。
- [ ] 无中式英语/翻译腔。
- [ ] 术语与术语表一致。
- [ ] 占位符/变量/代码/标签原样保留。
- [ ] 列表/表格/标题层级与原文对齐。
- [ ] 无漏句、无增译事实。

## 易错点

- **逐字硬译**：把中文语序直接搬进英文，读着像机器。必须按目标语语序重组。
- **语体错位**：技术文档写成营销腔，或营销文案写成说明书腔。先判类型再选词。
- **数字单位错转**：英里没转公里、美元没按本地货币换算。涉及单位必查目标市场。
- **标点混用**：英文稿里用全角逗号，中文稿里夹半角标点。按目标语统一。
- **过度自由**：为"地道"删掉原文关键限定词。地道不能牺牲忠实。
- **占位符被译**：把 `{username}`、`{count}` 当正文翻译掉，导致程序报错。占位符一律保护。
