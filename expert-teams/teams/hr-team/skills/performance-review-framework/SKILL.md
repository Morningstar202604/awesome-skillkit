# 绩效管理框架

本 skill 是 hr-performance-manager 的工作手册。核心原则：**绩效是管出来的，不是考出来的；目标事先对齐，过程持续反馈，考核基于事实而非最近印象。** 考核的目的是改进，不是打分。

## 这是什么

一套绩效管理闭环。从目标设定（OKR/KPI）开始，到过程辅导、考核评级、校准会议、反馈面谈与改进计划。每个环节留痕，评级经校准，避免趋中和近因偏差。

## 何时使用

- hr-performance-manager 接到"做考核/定目标"任务时，必须加载本 skill。
- hr-employee-relations 做绩效面谈/改进计划时，参考本框架。
- hr-compensation-analyst 关联调薪时，参考本框架的评级口径。
- hr-qa-reviewer 终检时，核对目标对齐与评级一致性。

## 核心步骤

1. **目标设定**：OKR 对齐上下，KPI 量化可衡量；目标员工参与制定并签字确认。
2. **过程辅导**：周期内持续 1-on-1 反馈，记录关键事件（正向/待改进）。
3. **考核评估**：员工自评 + 主管评价，基于目标达成与行为事实。
4. **评级校准**：校准会议强制分布，拉齐各部门标准，避免趋中。
5. **反馈面谈**：主管与员工面对面，讲清结果、依据、发展建议。
6. **改进计划（PIP）**：对低绩效员工，写清改进目标、期限、支持措施。

## 清单

- [ ] 目标事先与员工对齐，员工确认过。
- [ ] 目标可衡量（OKR/KPI 有验收标准）。
- [ ] 周期内有持续反馈记录，不只年底打分。
- [ ] 评价基于目标达成与行为事实，有记录。
- [ ] 评级经过校准会议，无全部门都"良好"。
- [ ] 反馈面谈双方面谈，员工知晓结果。
- [ ] 低绩效有书面改进计划（目标/期限/支持）。
- [ ] 区分了绩效结果与行为态度，不混为一谈。
- [ ] 识别并修正了趋中/近因/晕轮偏差。

## 易错点

- **目标事先不对齐**：年底主管按自己标准打分，员工觉得突然。目标必须年初确认。
- **只年底打分**：平时不反馈，年底突然给低分，员工不服。要持续记录关键事件。
- **趋中效应**：全部门都给"良好"，区分不出高绩效与低绩效。校准强制分布。
- **近因效应**：只看最近一个月表现，忽略全年。要拉全程记录。
- **PIP 走过场**：改进计划写得空，没有具体目标和期限，法律上站不住。
