# 游戏经济循环指南

本 skill 是 economy-designer 的工作手册。核心原则：**产出和消耗必须跑平，货币要有追求也要有去处，长期不能通胀也不能枯竭。** 经济是长期留存引擎，算不平会让玩家要么穷到没追求，要么富到没动力。

## 这是什么

一套游戏经济系统设计方法。规定货币体系怎么搭、产出口消耗口怎么设、商店怎么定价、通胀怎么控、付费点怎么放。它让经济循环可复算、可长期运行。

## 何时使用

- economy-designer 设计经济系统时必加载。
- balance-designer 设计产出数值时与本指南对齐。
- reviewer 评审经济是否崩坏时以本指南为标尺。
- team-lead 判断付费模型是否合理时参考。

## 核心步骤

1. **定货币体系**：免费货币（玩出来）+ 付费货币（充出来），用途边界清晰，避免互相乱兑。
2. **列产出口**：任务/战斗/签到/活动各产出多少，算玩家月产出总量。
3. **列消耗口**：养成/抽卡/商店/修理主要消耗，算月消耗总量。
4. **跑平衡**：月产出≈月消耗，留点富余做追求；淤积就加 sink，枯竭就加产出。
5. **定价商店**：商品定价对齐玩家获取难度，付费点 convenience 而非 pay-to-win。
6. **控通胀**：设长期 sink（如装备强化消耗）回收货币，防贬值。

## 清单

- [ ] 货币种类与用途边界清晰。
- [ ] 列了所有产出口及产出量。
- [ ] 列了所有消耗口及消耗量。
- [ ] 月产出与月消耗基本平衡。
- [ ] 无货币长期淤积或枯竭。
- [ ] 商店定价对齐获取难度。
- [ ] 付费点不 pay-to-win。
- [ ] 有长期 sink 控通胀。
- [ ] 产出口数值与 balance 表对齐。

## 易错点

- **只产不消**：货币越攒越多，后期没追求。必须设消耗口。
- **只消不产**：玩家穷到寸步难行弃坑。保证基础产出。
- **付费碾压**：充钱直接买战力，pay-to-win。付费买 convenience/外观。
- **定价拍脑袋**：商品价格没对齐获取难度。按月产出换算。
- **漏 sink**：长期无回收，通胀贬值。设强化/消耗型 sink。
- **数值对不上**：经济算的产出和 balance 给的不一致。对齐两表。
- **无缓冲**：产出消耗卡死平衡，没富余做追求。留合理富余。
