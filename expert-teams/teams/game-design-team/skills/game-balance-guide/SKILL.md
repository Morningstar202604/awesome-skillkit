# 数值平衡指南

本 skill 是 balance-designer 的工作手册。核心原则：**数字必须能复算，曲线必须能跑极端 case，平衡是调出来的不是拍出来的。** 好的数值让玩家有成长感，又不出现无敌套路或劝退数值。

## 这是什么

一套游戏数值平衡方法论。规定伤害公式怎么搭、成长曲线选哪种、属性怎么平衡、掉落概率与保底怎么设、怎么跑极端 case 验证。它让数值从"拍脑袋"变成"可复算可验证"。

## 何时使用

- balance-designer 设计数值时必加载。
- level-designer 定难度参数时参考。
- economy-designer 设计产出量时与本指南对齐。
- reviewer 评审平衡时以本指南为标尺。

## 核心步骤

1. **定伤害公式**：伤害=攻击力×系数-防御（或减伤公式），写清变量，算出期望对局时长。
2. **选成长曲线**：升级经验用多项式/指数；属性成长用平滑曲线，避免线性太久或指数爆炸。
3. **平衡属性**：不同职业/武器 DPS 对齐到同一区间，差异在风格而非强弱。
4. **掉落与保底**：稀有掉落设概率+保底次数，期望产出可算。
5. **跑极端 case**：验证满配 vs 零氪、最优 vs 最烂搭配，找无解/无敌套路。
6. **出表**：等级-属性-经验对照表，标注关键节点。

## 清单

- [ ] 伤害公式写清变量并可复算。
- [ ] 期望对局时长符合设计。
- [ ] 成长曲线平滑，不爆炸不拖。
- [ ] 各职业/武器 DPS 在同一区间。
- [ ] 稀有掉落有概率+保底。
- [ ] 跑过满配/零氪极端 case。
- [ ] 无明显无敌或无解套路。
- [ ] 等级-属性-经验表完整。
- [ ] 关键节点标注了。

## 易错点

- **拍脑袋填数**：表格里数字没公式，调不动。每个数字背后有公式。
- **成长爆炸**：后期数值指数膨胀，平衡崩。控制曲线斜率。
- **职业失衡**：一个武器 DPS 碾压其他。DPS 对齐区间。
- **掉落无底**：稀有物品纯概率无保底，玩家脸黑弃坑。加保底。
- **漏跑极端**：只看平均 case，放过无敌套路。必须跑极端搭配。
- **对局时长失控**：公式导致一局打半小时。按期望时长反推系数。
- **只调不记**：调了数字不记理由，下次又乱。每次调整记理由。
