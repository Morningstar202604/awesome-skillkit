# 报表与看板搭建模板

本 skill 是报表与看板的工作手册。核心原则：**结论先行，一屏一主题，图表服务于判断而不是装饰。** 看板的目的是让人 30 秒内知道"好不好、为什么、下一步做什么"。

## 这是什么

一套报表结构与看板布局规范。日报/周报固定结构（核心指标→环比→异常→结论），看板按主题分区，图表按数据类型选型，顶部留结论区。

## 何时使用

- data-report-engineer 接到"出周报/搭定时报表"时必须加载。
- data-visualization 搭看板时，按本指南选型与布局。
- data-bi-analyst 做经营汇报时，按本模板组织页面。
- data-qa-reviewer 复核报表时，按本指南检查是否结论先行。

## 核心步骤

1. **定受众与目的**：给老板看（结论+趋势）还是给运营看（明细+下钻）；目的决定布局密度。
2. **搭核心指标卡**：顶部 4~6 个 KPI 卡片，每个含当前值、环比箭头、同比；红涨绿跌按业务约定（注意电商 GMV 涨是好）。
3. **选图表**：趋势用折线、构成用堆叠柱/饼（≤5 类）、对比用条形、转化用漏斗、分布用直方图；禁止用 3D 饼图。
4. **分区布局**：一屏一主题；上排结果指标、中排趋势、下排明细/下钻；按阅读顺序从左到右、从上到下。
5. **写结论区**：每张关键图旁写一句"发生了什么 + 可能原因 + 建议动作"，不把判断留给读者。
6. **配下钻与时间筛选**：提供日期范围、渠道、维度筛选；默认展示近 7/30 天。
7. **定刷新频率**：日报每日定时、实时指标用分钟级；标注数据更新时间，避免看旧数。

## 清单

- [ ] 明确了受众与目的。
- [ ] 顶部 4~6 个 KPI 卡片，含当前值+环比+同比。
- [ ] 图表按数据类型选型，无 3D 饼图等装饰性图表。
- [ ] 一屏一主题，布局符合阅读顺序。
- [ ] 关键图旁写了结论（发生了什么+原因+动作）。
- [ ] 提供了时间/维度筛选与默认时间窗。
- [ ] 标注了数据更新时间与刷新频率。
- [ ] 配色统一，异常值有视觉强调。

## 易错点

- **没有结论**：满屏图但不写判断，读者自己猜。每张关键图配一句话结论。
- **图表选错**：用饼图展示 10 个渠道占比，看不清。类别 >5 用条形。
- **一屏塞太多**：看板像 Excel 网格，没人看完。一屏一主题，拆成多个看板。
- **坐标轴截断**：折线图 Y 轴从 90% 开始，把 2% 的波动画成悬崖。坐标轴从 0 或合理基线开始。
- **不标数据时间**：读者不知道看到的是哪天的数据。标注更新时间。
- **红绿方向搞反**：GMV 跌标绿、涨标红，和业务直觉相反。按业务约定配色并加图例。
