# 指标树与指标体系搭建指南

本 skill 是指标体系搭建的工作手册。核心原则：**一个指标一个口径，自上而下拆解，自下而上可加总。** 指标混乱的根源是同一个名字对应多个算法，本指南强制每个指标有唯一口径定义。

## 这是什么

一套从北极星指标到可落地二级指标的拆解方法，配合口径字典模板。每个指标记录名称、业务定义、计算公式、时间窗、过滤条件、负责人，杜绝同名不同义。

## 何时使用

- data-bi-analyst 接到"搭指标体系/经营诊断"时必须加载。
- data-governance 建口径字典时，按本指南模板逐条登记。
- data-analysis-team-lead 在分析前统一口径时使用。
- data-qa-reviewer 复核指标口径时，按本指南查字典是否唯一。

## 核心步骤

1. **定北极星指标**：选一个最能反映用户价值/商业结果的指标（如 GMV、周活跃用户数），全团队对齐。
2. **自上而下拆解**：北极星 = 流量 × 转化率 × 客单价；每一层继续拆到可行动的二级指标（如流量拆为 UV × 渠道分布）。
3. **分层命名**：一级（结果指标）、二级（过程指标）、三级（诊断指标）；每层指标可加总回上层。
4. **写口径定义**：每个指标填模板——业务定义、计算公式（含字段）、时间窗（自然日/滚动 7d）、过滤条件（剔除测试单/退款单）、负责人。
5. **登记口径字典**：所有指标入字典，同名指标只允许一条；新增指标必须登记后才能用。
6. **标血缘**：记录指标由哪些表/字段计算而来，便于改动时评估影响面。

## 清单

- [ ] 选定了唯一北极星指标并说明理由。
- [ ] 指标树自上而下拆解到可行动的二级指标。
- [ ] 每层指标可加总回上层，不出现断链。
- [ ] 每个指标有业务定义+计算公式+时间窗+过滤条件。
- [ ] 剔除了测试单/退款单等噪声口径。
- [ ] 所有指标登记入口径字典，同名唯一。
- [ ] 标注了指标血缘（来源表/字段）。
- [ ] 指定了每个指标的负责人。

## 易错点

- **同名不同义**："活跃用户"一个团队算登录、一个算点击，对不上数。字典里只允许一条定义。
- **指标不可加总**：拆到二级后加不回北极星，说明拆解逻辑错了。每层必须可加总。
- **时间窗混乱**：GMV 用自然日、转化率用滚动 7d，拼起来矛盾。每个指标写清时间窗。
- **不过滤噪声**：测试单、内部单、退款单混进 GMV，数字虚高。过滤条件必须写进口径。
- **只建不管**：字典建完没人维护，新指标不登记，三个月后又乱。指定负责人定期更新。
- **指标过多**：一次上 50 个指标没人看。北极星 + 5~8 个二级即可，诊断指标按需下钻。
