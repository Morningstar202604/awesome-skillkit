# 漏斗与留存分析指南

本 skill 是转化与留存分析的工作手册。核心原则：**步骤口径先对齐，分母分子写清楚，损耗定位到具体环节再谈归因。** 漏斗不是把数字排一排，而是找到每一步"谁走了、为什么走"。

## 这是什么

一套从漏斗构建到留存同期群到归因的分析流程。先统一漏斗步骤与时间窗，再算转化率与损耗，最后用同期群和路径定位原因。

## 何时使用

- data-analyst-funnel 接到"转化掉在哪/留存为什么掉"时必须加载。
- data-bi-analyst 做经营诊断需要定位漏损环节时参考。
- data-qa-reviewer 复核漏斗转化率时，按本指南检查分母口径。
- data-analysis-team-lead 判断"这是漏斗问题还是留存问题"时使用。

## 核心步骤

1. **定步骤与口径**：列出漏斗每一步的行为事件与过滤条件；明确"一步"是否要求同一会话/同一用户/同一时间窗（如注册后 24h 内完成首单）。
2. **算转化率**：每步转化率 = 本步完成人数 / 上一步人数；注意是"漏斗转化率"（去重后逐步）还是"整体转化率"（首步到末步），二者不可混用。
3. **找损耗环节**：定位环比下降最大的一步；拆分子人群（渠道/新老/端）看是不是某群人拉低。
4. **同期群留存**：按用户首次行为日期分 Cohort，算 D1/D7/D30 留存；对比不同批次留存曲线是否下滑。
5. **路径分析**：看流失用户在该步前后的实际路径，识别是否走错路/卡在某按钮。
6. **归因与悖论排查**：拆分后检查是否存在辛普森悖论（整体升但各群都降）；下结论前核对口径是否一致。

## 清单

- [ ] 漏斗每一步都写清了事件定义与过滤条件。
- [ ] 明确了时间窗（会话/24h/7d）与去重口径。
- [ ] 分母分子一致，没有混用逐步与整体转化率。
- [ ] 定位到了环比下降最大的具体步骤。
- [ ] 拆了渠道/新老/端等子人群。
- [ ] 同期群留存按首行为日期分了 Cohort。
- [ ] 检查了辛普森悖论。
- [ ] 结论给了"哪一步、哪群人、可能原因"，不是只给总数。

## 易错点

- **步骤口径漂移**："加购"在安卓是点击按钮，在 iOS 是进入购物车，两步不可比。先对齐埋点定义。
- **分母错用**：用全站 UV 当漏斗第一步分母，转化率被稀释。分母应是真正进入该流程的人。
- **时间窗不一致**：漏斗按 24h 算、留存按 7d 算，拼在一起下结论就矛盾。统一时间窗。
- **只看整体不拆群**：整体转化降 2%，其实是某一个低质渠道拉低，其余没动。必须拆群。
- **辛普森悖论**：合并后 A 组更好，拆开后每个子群都 B 更好。不拆群会得出相反结论。
- **把相关当因果**：某步流失高≠该步设计有问题，可能是进来的人群本身不对。先看人群质量。
