# 数据清洗操作指南

本 skill 是数据清洗的工作手册。核心原则：**先备份再清洗，可追溯、可复跑，每一步都留痕。** 清洗不是"把脏的变好看"，而是把不可信的原始数据变成口径一致、可复算的分析底表。

## 这是什么

一套分层清洗流程。原始数据进 raw 层只读不动，所有清洗动作在 staging 层记录规则，产出 clean 层分析底表。清洗规则沉淀为可复跑脚本，不手工改数。

## 何时使用

- data-cleaning-engineer 接到"数据脏/口径对不上"任务时必须加载。
- data-python-engineer 用 pandas 批量处理前，按本指南定清洗规则。
- data-governance 制定数据质量规则时，参考本指南的检查项。
- data-qa-reviewer 复核清洗逻辑时，按本指南判断是否漏处理。

## 核心步骤

1. **摸底**：跑 `describe()/info()`，记录行数、字段类型、缺失率、唯一值数；缺失率 >60% 的字段单独标注，不盲目删列。
2. **去重**：按业务主键去重（如 order_id+用户），保留最新一条；记录删除行数，不直接 drop 不留痕。
3. **缺失值处理**：数值型按中位数/均值填充并标注；类别型填充"未知"；时间戳缺失直接剔除该行；不允许静默填 0 当真实值。
4. **异常值判定**：数值型用 IQR（Q1-1.5×IQR ~ Q3+1.5×IQR）或 3σ 标记，业务量纲超 3σ 的先查是不是埋点错误，再决定剔除或截断。
5. **标准化**：枚举值统一大小写与别名（如"广东/Guangdong/粤"归一）；金额统一分/元；时间统一 UTC+8；手机号/邮箱正则校验。
6. **产出质量报告**：清洗前后行数、各步删除/填充条数、字段缺失率对照表、剩余风险字段。

## 清单

- [ ] 原始数据已备份/只读，未在 raw 层直接修改。
- [ ] 记录了总行数与各字段缺失率、唯一值数。
- [ ] 去重按业务主键执行，删除条数已记录。
- [ ] 缺失值按字段类型分别处理，没有静默填 0。
- [ ] 异常值用 IQR/3σ 标记并标注是否为埋点错误。
- [ ] 枚举、单位、时间、币种已统一。
- [ ] 清洗规则可复跑（脚本/规则文档），不是手改。
- [ ] 输出了清洗前后对照与剩余风险字段。
- [ ] 关键异常样本抽 5 条人工核对过。

## 易错点

- **静默填 0**：金额缺失填 0 会让 GMV 被低估，且统计上看不出。缺失就是缺失，单独成一类。
- **盲目删行**：缺失率高的行整行删掉，可能把一个用户群删没了。先看缺失是不是系统性的。
- **异常值一律剔除**：3σ 之外可能是大客/爆款，直接删会低估头部。先查业务含义再决定。
- **别名不统一**："已完成/完成/done"算三个状态，漏斗就错了。枚举必须归一。
- **清洗不留痕**：手工 Excel 改完无法复跑，下次同样问题再来一遍。规则必须脚本化。
- **时间时区不统一**：UTC 与北京时间混用，按天聚合就会错位 8 小时。
