## 与本仓标准的合并

上述方法论进入本仓时做了三类改造：

1. **十诫化**：每个步骤补齐「预期结果 + 失败分支」（SKILL-STANDARD-v2 §3 诫 2）；
2. **确定性化**：场景文件给出固定 10 行结构公式，而非自由格式；
3. **可验证化**：新增 `scene_lint.py` 机器校验（命名连续性 + 9 个字段存在性 + 时长边界）。
   **修正（2026-09-22）**：早期表述为「把人工审查降级为脚本把门 + 人工只看创意」——
   这是**过度承诺**。探针实测（见下）证明 lint 只做形状检查，内容与镜头语法它一概不看。
   准确定位是：**脚本把形状的关，人工把内容与语法的关**。

## 镜头语法来源（批次 4 补录，2026-09-22）

SKILL.md 暗知识 1–7 的镜头语法为影视行业通行教学口径，本轮联网核实后写入：

| 暗知识 | 内容 | 采信程度 |
|---|---|---|
| 180° 线（轴线） | 对手戏保持同一侧拍摄；越轴需插入中性镜头或运动跨轴 | 采信：影视制作通行规则 |
| 30° 规则 | 相邻镜头机位变化 <30° 且景别相近 → 跳切感 | 采信：同上的通行经验规则 |
| 视线匹配 | A 看画右 → B 看画左 | 采信：剪辑语法通行规则 |
| 动作匹配 | 连续动作切在中间以掩盖剪辑点 | 采信：同上 |
| 建立镜头 | 新场景先交代环境全貌 | 采信：同上 |
| 景别梯度 | 相邻镜头跨档、全片 ≥3 种景别 | 半采信：「跨档」是通行规则；「≥3 种」是本组对"避免视觉催眠"经验的可操作化，非行业数字 |
| 单段 3–8s 可用区间 | — | **工程约束非语法**：来自生成模型单段时长与漂移特性，已在 SKILL.md 明确标注 |
| 连续性表 = prompt 前缀词表 | — | 本组设计判据（把约束表与生成动作挂上钩） |

**未采信**：未核实的「3 秒流失 X%」「完播率提升 Y%」类数字一律不写入。

## lint 探针实测记录（2026-09-22）

用构造样本对 `scene_lint.py` 做边界探测，结果如下（全部可复现）：

| 探针 | 输入 | 结果 | 结论 |
|---|---|---|---|
| 形状检查的边界 | 2 个 scene 文件，**所有字段值均为字母 `x`** | `ALL OK`，rc=0 | lint 只验「字段名: 非空值」，不验内容 |
| 时长越界 | `时长: 99s` | `FAIL: DURATION`，rc=1 | 1–10s 硬边界有效 |
| 时长不可解析 | `时长: x` | 跳过时长校验（不报错） | 正则匹配不到数字即不检查 |
| 约束表存在性 | 目录中无 `continuity.md` / `beat-sheet.md` | 仍 `ALL OK` | 两文件的存在性不在校验范围 |
| 未检查项 | 景别梯度 / 视线 / 轴线 / 连续性一致性 | 不在 REQUIRED_FIELDS | 全靠人工核对（SKILL.md 内置验证步骤语法项） |

> 记录目的：让 SKILL.md 的「诚实声明」可被独立复核；任何一条与代码不符，以代码为准并回改文档。
