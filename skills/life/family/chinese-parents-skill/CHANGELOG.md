# 更新记录

## v0.5 — 2026-08-09

前面版本全部是 0.1→0.4，这版是 0.5。这一版**不补功能点，补地基**：把 v0.4 留的那个最大的窟窿（文档写了、代码没有的多轮状态机）真正落地，并顺手堵住一个比功能缺失更隐蔽的窟窿——**假数字**。

**多轮推演状态机真正落地**（v0.4 最大的窟窿）

- `dynamics.md` 第四~七节早就把引擎写成了可执行规格：TEMP/BOND/YIELD 三状态 + K/D/COOL 三系数、雷区表 T1-T21、破冰表 C1-C19、让步判定六类、渠道折扣。但 v0.4 的 `profile.py` 只算首轮快照，问"我顶回去了她怎么反应"，它答不了。
- 现在 `simulate()` 完整实现：逐轮结算（加成只取最高一条不叠加 / 单轮净升温封顶 +35、净降温封顶 −30 / TEMP≥85 只有 [高温] 条目生效且 ×1.5、非高温反噬 +10 / 同条破冰第二次 ×0.5 第三次 ×0）、BOND 溢出伤害、六类让步判定、渠道折扣（电话/微信降温 ×0.8、微信再 ×0.8、BOND 伤害 ×1.2）、`--bond/--channel/--who`。
- `dynamics.md` 7.2 的五轮算例**逐值复现**：TEMP 24→64、BOND 69→50（−19）、说服 30/70、判定不让步、"最贵的一句"是第 3 轮的 T1 划界宣言。

**置信度三级 + 污染追踪（堵"假数字"的窟窿）**

- v0.4 遇到没给的维度就**静默填 50**——那正是 v0.4 自己警告过的陷阱（"同一个人问两次得到两份报告"）。现在缺失维度走显式三级置信度：`known`（用户给）/ `inferred`（耦合规则推，方向可信数值别当真）/ `blind`（硬填 50，结论一律作废）。
- 引入 `DYN_DEPS` 污染映射：硬填维度污染下游动力学量时，输出标 `⚠` 并**抑制相似度与读法**；`blind` 维度 ≥4 个则直接"不报相似度"。
- 只给 `CTL=90` 时，v0.4 会报"虎妈虎爸 84%"——现在是干净的"不报…回声"。宁可少说，不乱说。

**相似度舍入对齐**

- `similarity()` 改用 `_half_up`（Decimal `ROUND_HALF_UP`），与全文"数字可复算"的约定对齐，消除 Python 内置 `round()` 的银行家舍入漂移。

**工程：文档每个数字都变成断言**

- 新增 64 项 unittest（`scripts/test_profile.py`，纯标准库），把文档里的 48 个动力学数值、相似度算例、7.2 逐轮对账全部钉成断言。
- 新增 `.github/workflows/test.yml`：Python 3.8–3.12 矩阵，每版真跑；含引擎自校验、7.2 复现、题库导出 `diff`、八锚点出报告。
- **修掉一处真 bug**：`C19` 漏标 `[高温]`，爆发区本应仍生效的五条里少了一条，已补。
- **修正一处文档算例错误**：7.2 第 3 轮 T1 原写"CTL 50-74 加成 8"，实际加成只取最高一条——`IND=32≤33` 给 +10，已改文档并对齐引擎。

**定位重申**：这个 skill 的核心不是"陪聊"，是**还原一份可被自己和别人复算的中国式家长画像**。所有数值化、动力学、置信度机制都服务于一件事——让它算出来的那个"妈"，站得住、对得上、错得起（错了就说不清，而不是编得圆）。

**补充：新增 `references/quirks.md`（神人家长魔怔案例集 / 奇葩思维图谱）**。这是冲着 v0.5 定位里"站得住、对得上"最容易被 AI 演歪的那一类去的——网上叫"神人 / 魔怔 / 发疯文学"的家长，**不讲逻辑、不讲因果、没有上下文、纯情绪输出**，AI 默认用因果连贯的框架去推，永远推不对。该文件分四块：① 元认知——九条"无逻辑 / 无因果 / 无上下文 / 情绪即事实 / 双标 / 翻旧账 / 标准漂移 / 以爱兜底 / 反驳无关内容"的脑回路；② 17 种奇葩思维模板（滑坡、概念漂移、双标、翻旧账、情绪即证据、结果倒推动机、以爱收口、话题瞬移、自相矛盾、无条件反驳、道德绑架、躯体化威胁、标准漂移、选择性记忆、比较成瘾、阴谋论归因、阴阳怪气），每种配真·原话级例子；③ 按生活场景铺开的魔怔案例库（饮食 / 穿衣 / 作息 / 学习 / 工作 / 婚恋 / 消费 / 社交 / 健康 / 隐私 / 兴趣 / 过年 / 带娃 / 养老 / 夫妻 / 网络 / 养生 / 外貌 / 选专业 / 失恋 / 买房 / 减肥 / 旅游 / 政治 / 宠物……各种各样），每条标"神人在哪"教 AI 识别没逻辑长什么样；④ 给 AI 的八条反逻辑模拟纪律 + 逻辑家长 vs 神人家长对照表。同时把 `quirks.md` 接进 SKILL.md 按需加载表与第七（新增）条纪律——极端维度下禁止给台词补"因为…所以…"。

**多语言 README（中 / 英 / 日 / 韩四版可切换）**：新增 `README.en.md` / `README.ja.md` / `README.ko.md`，与 `README.md`（中文主版，GitHub 默认首页）在四个文件顶部都加统一的四语切换导航；目录结构、`CONTRIBUTING` 引用同步更新。东亚家长文化正是重灾区，日韩读者能直接读懂才有意义。

**修订（2026-08-10）—— 锚点命名本土化 + 案例再扩充 + 导航加粗**

## v0.4 — 2026-08-09

以前它只会演你妈。现在它能陪你把那场你一直不敢开口的对话，先打一遍。

**三个模式**（原来两个）

- 新增**应对模式**：给定家长画像 + 你的目标（辞职、不结婚、不买房），输出可行性分级、三条路线、12 个战术、三层深的反应树。
  这是这版最该做的一件事——v0.3 能告诉你"你妈是虎妈"，但你真正想知道的是"那我该怎么开这个口"。

**维度系统数值化**

- 10 个维度从标签升级为 0-100 分。`CTL 52` 和 `CTL 73` 都叫"严格"，但演出来必须不一样。
- 给出**相似度算法**（归一化加权曼哈顿距离），8 个参考类型有了标准向量。
  v0.3 的诊断报告印着"相似度 85%"却全文没有算法，那个数字是编的——同一个人问两次得到两份报告。这版所有数字可复算。
- 新增 10 条**维度耦合规则**：`COM≥75` + `CTL≥75` = 假民主，`INV≤20` + `COM≤24` + `CTL≥25` = 诈尸式，单看任何一维都看不出来。

**对话动力学引擎**

- 新增情绪温度 `TEMP`、关系账户 `BOND`、让步阈值 `YIELD` 三个状态量，以及升温增益 `K`、降温效率 `D`、自然冷却 `COOL` 三个静态系数，全部由维度推导，公式可手算。
- **雷区表 / 破冰表**：哪句话加多少度，哪些维度的家长对哪句话特别敏感，全部量化。
- 区分**真让步和假让步**——"行行行你自己看着办"十次有八次是假的，给了验真规则。
- 支持多轮推演。终于能回答"我顶回去了，她会怎么反应"。

**场景与角色**

- 场景 10 → 18。新增：亲戚聚会与横向比较、催婚催生与彩礼、买房与经济支援、养老与赡养、多子女与偏心、情绪与心理健康、隐私边界、非主流职业。
- 新增**多角色家庭系统**：爸妈祖辈亲戚可以各有画像，支持唱红白脸、隔代对冲、亲戚助攻的联盟建模。现实里从来不是只有一个家长。
- 新增**背景修正因子**：代际、家庭结构、经济状况变化史对维度的偏移参考。

**工程**

- SKILL.md 从 627 行单文件拆成主入口 + 8 个按需加载的 reference，不再一次性全量入 context。
- 新增 `scripts/profile.py`：纯标准库计算器，跑问卷、算相似度、出 ASCII 画像报告。文档里的 48 个数值全部与脚本复算一致。
- 新增 30 题快测题库，答案串可存档复现。
- 许可证归位到 Apache-2.0（并入上游改动）。README 从 v0.3 起就链接着 LICENSE，但那个文件一直不存在，现在能点开了。

**破坏性改动**：维度表示法从纯标签改为数值，v0.3 的画像写法仍可用（按档位中位数解析），但输出格式不再兼容。

## v0.3 — 2026-08-01

以前只有 8 种妈，现在有 59049 种。

- 10 个维度任意组合，每个维度 3-4 个档位，理论覆盖 3^10 ≈ 59049 种家长形态
- 新增诊断模式——不只模拟，还能根据用户描述反向分析家长类型
- 场景从 5 个扩到 10 个：新增社交交友、网络电子产品、健康习惯、外表形象、教育择校
- 每个场景下每个维度档位都有具体的行为影响规则
- 诊断报告带可视化维度画像、相似类型匹配、场景预测、沟通建议
- 支持混合模式：可以在参考类型基础上调整任意维度

**改动**：从 8 种固定类型重构为维度组合系统，输出格式和模拟逻辑全部重写。
