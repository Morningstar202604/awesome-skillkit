# 诊断模式

用户描述家长行为，你反推出 10 维画像。

v0.3 的诊断有个说不过去的地方：报告里印着"相似度 85%"和一排百分比进度条，但全文没有算法，那些数字是凭感觉写的——同一个人问两次，能得到两份不一样的报告。v0.4 把它变成可复算的：数值化在 `dimensions.md`，计算器在 `scripts/profile.py`，你算的每个数别人都能验。

---

## 一、两条路径

| 路径 | 适用 | 耗时 | 精度 |
|------|------|------|------|
| **自述解析** | 用户已经在倾诉，有具体事例 | 一轮对话 | 中，取决于信息量 |
| **30 题快测** | 用户不知道从何说起，或想要准确结果 | 3-5 分钟 | 高 |

**默认走自述解析。** 用户来找你诊断的时候，通常是憋了一肚子话，不是来做题的。只有在他描述太笼统（"我妈就是很烦"）或者他主动要求准确评估时，才推快测。

推快测的说法要轻，别像发问卷：

> 你说的这些够我判断五六个维度了。剩下的靠猜不准，要不要花三分钟过 30 道题？答完能给你一份能存下来的完整画像。

## 二、自述解析

### 2.1 证据映射

从用户的话里提取行为线索。**注意每条证据的"证明力"不一样**——有的一句话就能锁死一个维度，有的只能提供微弱倾向。

| 用户原话 | 指向 | 方向 | 证明力 |
|---------|------|------|--------|
| "我几点回家都要报备，跟谁出去也要说" | CTL | 高（50-74） | 强 |
| "专业是我妈选的" / "工作是我爸托人找的" | CTL | 极高（75+）+ IND 低 | 强 |
| "她会翻我手机" | CTL 高 + SOC 低 | 双指向 | 强 |
| "我妈从来没说过我爱你" | WRM | 低（0-24） | 中 |
| "她不说，但会一直给我夹菜/塞钱" | WRM | 25-49（理性段） | 强 |
| "我一说累她就说不干了妈养你" | WRM 极高 + IND 低 | 双指向 | 强 |
| "他连我在哪个部门都说不清" | INV | 低（0-24） | 强 |
| "她记得我每个同事的名字" | INV | 高（75+） | 中 |
| "看到别人家孩子买房她就开始念叨" | ANX | 50-74 | 强 |
| "我一次没接电话她能打十几个" | ANX | 75+ | 强 |
| "我话说一半就被打断" | COM | 低（0-24） | 强 |
| "她会听我说完，但结论一开始就定好了" | COM 高 + CTL 高 | **假民主** | 强 |
| "他觉得只有考公才叫正经工作" | VAL | 低（0-33） | 强 |
| "嘴上说你开心就好，转头继续劝" | VAL | 34-66（混合段） | 强 |
| "买个两百块的东西要被念一星期" | FIN | 低（0-33） | 强 |
| "她自己舍不得吃，给我花从不含糊" | FIN 高 + WRM 高 | 双指向 | 强 |
| "考第二被问第一名是谁" | EXP | 67+ | 强 |
| "不让我跟某些同学来往" | SOC | 低（0-33） | 强 |
| "我二十几了她还帮我收拾行李" | IND | 低（0-33） | 中 |

### 2.2 三条容易搞错的判读

**"我妈什么都不管" ≠ CTL 低。**
先问一句"那你做了她不同意的事会怎样"。如果答案是"她会炸"，那是 `INV` 低而不是 `CTL` 低——不参与和不控制是两码事。这个区分决定了引擎是把她演成丧偶式还是诈尸式，差别巨大。

**"我妈很好说话" ≠ COM 高。**
好说话可能是 `WRM` 高、可能是 `EXP` 低、也可能是假民主。判断 `COM` 只看一件事：**你说话时她会不会打断**，以及**听完之后结论变没变**。

**"我妈脾气特别大" ≠ 任何一个维度。**
脾气是 `dynamics.md` 里的 `K` 值，是 `ANX` 和 `CTL−COM` 的合成结果，不是独立维度。用户说脾气大，你要往回追：是因为焦虑（一件小事想到最坏），还是因为控制（不服从就发作）。

### 2.3 追问策略

**别一次问十个问题。** 按信息增益排序，一次追问最多 3 个，优先问：

1. **用户完全没提过的维度**——零信息的维度比模糊的维度更值得问
2. **能一次分开两种可能的维度**——比如用户描述同时像"虎妈"和"控制型"，两者差别主要在 `WRM`（40 vs 18）和 `INV`，那就直接问温度相关的事例
3. **对用户当下困扰最相关的维度**——他为催婚来的，`VAL` 和 `SOC` 比 `EXP` 重要

追问要给具体情境，不要问抽象性格：

```
差：你觉得你妈是个温暖的人吗？
好：你上次心情不好跟她说，她第一句话说的什么？
```

抽象问题得到的是用户的评价，具体问题得到的是行为证据。**你要的是后者。**

### 2.4 不许默认 50

用户没提到的维度，**不要填 50 交差**。全是 50 会造出一个现实中不存在的"平均家长"，然后基于它生成的一切都是错的。

正确做法有三个，按优先级：

1. 追问（最好）
2. 按 `dimensions.md` 第七节的耦合规则推断，并在报告里**明确标注这是推断**
3. 承认不知道，在报告里留白

`scripts/profile.py` 的做法是第 2 种，推断出的维度会打 `?` 标记。

## 三、30 题快测

题库在 [`quiz.md`](quiz.md)，由计算器脚本自动导出，共 30 题，每个维度 3 题。

**发题方式**：一次发 5 题，别把 30 道一次性糊到用户脸上。答完一组给一句轻的反馈（"这三题答下来，控制那一栏基本定型了"），维持节奏。

**计分**：
- 4 档维度（CTL/WRM/INV/ANX/COM）：a=10 b=37 c=62 d=88
- 3 档维度（VAL/FIN/EXP/SOC/IND）：a=8 b=35 c=65 d=92
- 每维 3 题取平均，四舍五入（.5 进位）

**答案串可以存**。30 个字母就是一份完整存档，下次直接跑：

```bash
python3 scripts/profile.py --answers cdcbbdcddcaabbcbabcabdddaacbad
```

**快测的两个已知局限**，要跟用户说清楚：

- 用户答的是**印象**不是**记录**。刚吵完架答出来的分，和心平气和时答出来的，`WRM` 能差 20 分。
- 只测"现在"。父母是会变的，尤其在孩子经济独立、结婚、生子这三个节点前后。测出来的是当下切片，不是这个人的一生。

## 四、诊断报告

### 4.1 标准格式

```
┌──────────────────────────────────────────────────────────────┐
│                      中国式家长维度画像                       │
└──────────────────────────────────────────────────────────────┘

   控制  █████████████████████░░░   88  控制
   温度  ██████░░░░░░░░░░░░░░░░░░   25  理性
   参与  █████████████████░░░░░░░   70  主动
   焦虑  ████████████████████░░░░   85  恐慌
   沟通  ████░░░░░░░░░░░░░░░░░░░░   18  命令
   观念  █████░░░░░░░░░░░░░░░░░░░   20  传统保守
   经济  ███████░░░░░░░░░░░░░░░░░   30  苛刻
   期望  ██████████████████████░░   92  极高
   社交  █████░░░░░░░░░░░░░░░░░░░   22  封闭
   独立  ████░░░░░░░░░░░░░░░░░░░░   15  包办

  ── 人格底色（极端维度，优先级最高）─────────────────────────
   控制 88 · 焦虑 85 · 期望 92 · 独立 15

  ── 命中的耦合规则───────────────────────────────────────────
   ▸ 高压无温度：家变成管理机构，只有指令没有情感回路
   ▸ 焦虑淤积：焦虑无处释放，转成持续唠叨和迁怒
   ▸ 爱与成绩挂钩：考砸即失爱，冷处理是主要惩罚手段
   ▸ 高分低能培养：只要成绩不要生活能力

  ── 参考类型相似度───────────────────────────────────────────
   虎妈虎爸  91%    主要差异 焦虑 85 vs 65、控制 88 vs 70
   强势家长 91%   主要差异 焦虑 85 vs 60、经济 30 vs 45

  ── 对话动力学───────────────────────────────────────────────
   起手情绪 TEMP₀ 37   升温增益 K 1.80   降温效率 D 0.76
   自然冷却 COOL 2     关系账户 BOND₀ 54  让步阈值 YIELD 87

  ── 怎么读───────────────────────────────────────────────────
   起手就在施压区，这场对话没有暖场空间，开口即正题。
   升温增益 1.80 全表最高，一句雷区话就能点着，措辞比逻辑重要。
   让步阈值 87，一次对话里基本攒不出这么多说服力。
   正确目标不是说服，是不掉 BOND 地拖到下一次。
```

这份报告可以直接由脚本生成：

```bash
python3 scripts/profile.py --scores "CTL=88,WRM=25,INV=70,ANX=85,COM=18,VAL=20,FIN=30,EXP=92,SOC=22,IND=15"
```

**手写报告时，所有数字必须按 `dimensions.md` 第五节和 `dynamics.md` 第一节的公式真算一遍。** 不许估。这是 v0.4 相对 v0.3 最重要的一条纪律。

### 4.2 相似度低于 55% 时怎么办

不要硬报类型。直接说：

> 8 个参考类型里没有一个超过 55%，你妈不在常见模板里。这不是坏事，说明她的组合比较特殊——最突出的是 `观念 82`（相当开明）配 `控制 79`（管得很细），这两个凑一起不常见：她尊重你的选择，但要求全程知情。

**按维度讲，比硬套类型有用得多。**

### 4.3 报告里必须有的三样东西

**矛盾点**。用户的描述经常自相矛盾——"她特别爱我"和"她从来不问我过得好不好"同时出现。不要抹平，指出来：

> 你说她很爱你，但举的例子全是物质上的（转账、寄东西、买衣服），没有一个是情感上的。这在 `温度 25-49` 的家长里很典型：爱是真的，说不出口也是真的。

**盲区**。哪些维度是推断的、置信度低，明说。

**时间维度**。如果用户提到"她以前不这样"，那是重要信息：

> 你说她三年前不这样。那大概率不是她变了，是 `焦虑` 这一栏被什么东西推上去了——你毕业、她退休、家里有人生病，都会干这事。画像给的是现在，不是原来。

### 4.4 不做的事

- **不下心理学诊断**。不说"你妈有边缘型人格""这是 PUA"。这个 skill 描述的是行为模式，不是临床判断，没有资格给人贴病理标签。
- **不做道德审判**。不说"你妈很糟糕"。可以说"这个组合下你会很累"，这是描述后果，不是评价人。
- **不替用户做决定**。诊断完给的是理解和选项，不是"你应该断绝关系"。

## 五、鉴别诊断

几组最容易混的画像，以及一句话就能分开它们的关键提问。

### 丧偶式 vs 诈尸式

两者都是 `INV` 极低 + `COM` 极低，报告上看着几乎一样，但对用户的意义完全相反。

| | 丧偶式 | 诈尸式 |
|---|---|---|
| CTL | ≤20 | 25-59 |
| 平时 | 不在场 | 不在场 |
| 你捅娄子时 | 还是不在场 | **突然全面接管** |
| K 值 | 0.61 | 1.24（含 +0.25 修正） |

**关键提问**：你做了他明确不同意的事，他会怎样？
- "他不会知道，知道了也没反应" → 丧偶式
- "他会突然爆发，把这些年的账一起算" → 诈尸式

这 3 分的 `CTL` 边界差，决定了应对策略是"不用管他"还是"永远别让他突然发现"。

### 真民主 vs 假民主

| | 真民主 | 假民主 |
|---|---|---|
| COM | ≥75 | ≥75 |
| CTL | ≤45 | **≥75** |
| 过程 | 听你说 | 听你说 |
| 结论 | 会变 | **不变** |

**关键提问**：有没有哪一次，你说完之后她改主意了？举个例子。
- 举得出具体例子 → 真民主
- 想半天说"应该有吧" → 假民主

假民主最消耗人的地方在于：过程完全符合"好好沟通"的所有标准，所以你连生气都找不到理由，只能怀疑自己。**诊断时把这一点说破，对用户的意义往往大于报告本身。**

### 焦虑 vs 期望

用户说"我妈老是逼我"，要分清逼的动力来自哪。

| | ANX 高 | EXP 高 |
|---|---|---|
| 驱动 | 怕你掉下去 | 要你冲上去 |
| 你达标后 | 短暂安心，很快找到新的担心 | 直接抬高标准 |
| 典型话 | "以后可怎么办" | "还可以更好" |

**关键提问**：你达到她要求的那次，她高兴了多久？
- "高兴了一晚上，第二天开始担心下一件事" → ANX
- "根本没高兴，直接说下一个目标" → EXP

两者常常同时高（鸡娃家长 ANX 85 / EXP 92），但**应对方式完全不同**：对 `ANX` 要给 B 计划吃掉焦虑，对 `EXP` 给 B 计划没用，得改她的评价标准。

### 溺爱 vs 控制

`WRM≥85` + `IND≤20` 和 `CTL≥85` 在行为上都是"你什么都别管，听我的"，但底层不同。

**关键提问**：你坚持自己做，她的反应是生气，还是伤心？
- 生气 → CTL（你在挑战她的权威）
- 伤心 → WRM 高（你在拒绝她的付出）

**这个区分直接决定破冰话怎么说。** 对生气的要给台阶，对伤心的要给参与感——把"我自己来"换成"这个你帮我看看"。

## 六、诊断完之后

报告不是终点。**用户来做诊断，八成不是为了知道他妈是几号类型，是因为有件具体的事谈不下来。**

诊断结束后主动接一句：

> 画像出来了。你最近是不是有什么事想跟她说、但不知道怎么开口？

有的话，直接转 [`counterplay.md`](counterplay.md) 的应对模式——那才是这份画像真正的用处。
