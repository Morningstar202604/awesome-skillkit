# 家庭系统与背景修正

v0.3 假设家里只有一个家长。现实里从来不是。

真正难对付的不是某一个人，是**结构**：一个施压、一个沉默、一个护着、一个补刀。你把妈说服了，饭桌上姑姑一句话又推回去了。只画一个人的像，就漏掉了全部的力学。

这个文件补两件事：**A** 多角色系统怎么建模，**B** 维度是从哪儿来的。

维度键、档位、耦合规则一律以 `dimensions.md` 为准。

# A. 多角色家庭系统

## A1. 角色槽

| 槽位 | 说明 |
|------|------|
| **家长甲 / 家长乙** | 通常是父母。用甲乙不用"父/母"，因为**谁强势、谁沉默、谁掌钱不由性别决定** |
| **祖辈** | 爷爷奶奶／外公外婆。可能同住，可能远程 |
| **同辈亲属** | 兄弟姐妹、堂表亲。可能是盟友，也可能是对照组 |
| **旁系长辈** | 叔伯姑姨舅。**不参与日常决策，但控制舆论场** |
| **外部关联人** | 家长的老同事、邻居、你的对象及其家庭。只在特定场景出现 |

**不给任何角色预设维度默认值。** 母亲不默认 `INV` 高，父亲不默认 `COM` 低，祖辈不默认 `WRM` 高。这些在现实里各家不同，谁高谁低完全由用户描述决定。没描述就追问，不要拿刻板印象填空。

**角色之间真实存在的结构性差异只有三条**，这三条与性别无关：

1. **是否同住**——同住的人 `INV` 的实际作用力放大，不同住的人再高的 `CTL` 也难落地。
2. **是否掌握你需要的资源**——钱、房、户口本、带孩子的人力。
3. **辈分位置**——祖辈对家长有压制力，旁系长辈对家长有舆论压力，同辈没有。

## A2. 角色的画像与两个附加属性

每个角色一行，10 维照旧，再加两个只在多角色场景下才需要的属性：

```
妈    CTL:78 WRM:65 INV:85 ANX:82 COM:35 VAL:28 FIN:55 EXP:75 SOC:30 IND:25   W:0.55  在场:全程主攻
爸    CTL:45 WRM:30 INV:25 ANX:40 COM:20 VAL:35 FIN:70 EXP:60 SOC:45 IND:60   W:0.30  在场:沉默/事后执行
奶奶  CTL:30 WRM:88 INV:60 ANX:35 COM:40 VAL:20 FIN:60 EXP:25 SOC:35 IND:40   W:0.10  在场:护短/情绪缓冲
姑姑  CTL:—  WRM:35 INV:20 ANX:—  COM:25 VAL:18 FIN:—  EXP:70 SOC:25 IND:—    W:0.05  在场:舆论/补刀
```

**W（决策权重，0–1）**：这件事上他说了算的比例。全家 W 之和归一到 1。
**在场模式**：他在冲突现场干什么。常见五种——主攻、沉默、护短、补刀、和稀泥。

旁系亲属允许留 `—`。他们只在少数维度上对你有作用（通常是 `VAL`、`EXP`、`SOC`），其余不必猜。

## A3. W 怎么定：按维度算，不按角色套

**默认不要用"一般都是妈管这个"这类经验值。** 按下面三步算：

**第一步，看场景关键维度是谁高。** 场景与关键维度的对应沿用 `dimensions.md` 第五章的场景加权表：

| 场景 | 主导方判据 |
|------|-----------|
| 学业／工作 | `INV + EXP` 之和更高的一方 |
| 人生选择（辞职、转行、异地） | `CTL + (100−VAL)` 之和更高的一方 |
| 婚恋 | `(100−VAL) + (100−SOC)` 之和更高的一方 |
| 金钱／大额支出 | 实际掌握资金的一方，与维度无关 |
| 日常生活 | 同住的一方 |

**第二步，加资源修正。** 谁掌握这件事需要的实物资源（钱、户口本、房产证、带孩子的人力），谁的 W 直接 `+0.2`，且**在这件事上拥有实质否决权**——不管他 `COM` 多高、态度多温和。这一条经常被忽略，也是最多人翻车的地方。

**第三步，加辈分修正。** 祖辈在场且明确表态时，被压制的那位家长 W `−0.1`；祖辈不在场时这个修正不生效。

算完归一化。**W < 0.1 的角色不进合力计算**，但要单独登记——他们不决定结果，却能改变现场气氛（见 A4 的补刀位）。

## A4. 联盟关系模型

家庭内的力量组合有固定几种。识别出是哪一种，比逐个分析成员更有用。

### 红白脸

一个施压，一个安抚。**本质是同一个目标的分工，不是意见分歧。**

- 识别：安抚方从不反对施压方的**结论**，只反对**语气**。"你妈说话难听了点，但她也是为你好。"
- 陷阱：安抚方看起来是盟友，实际是收网的人。你被施压方逼到墙角，安抚方递来一个"折中方案"——那个方案通常就是施压方的原始目标打个九折。
- 应对：**判断标准是安抚方有没有推动过结论本身的改变**。如果没有，就不要把他当盟友，也不要在他面前松口。
- 合力计算：两人视为一个单元，`CTL` 取两人较高值，`COM` 取两人较低值（因为你实际能用的沟通带宽由硬的那个决定）。

### 隔代对冲

祖辈的溺爱抵消父母的严格。

- 识别：同一件事，祖辈的 `WRM` 比家长高 30 分以上，`EXP` 低 30 分以上。
- 效果：**它降低冲突烈度，但不改变决策方向**。奶奶能让你今晚不挨骂，不能让你妈同意你辞职。别把缓冲误当成支持。
- 代价：用祖辈挡枪一次，你妈的挫败感会转成对下一次的加倍施压，而且这笔账会算在祖辈头上，制造两代人之间的矛盾。**这就是那个"代价落在别人身上"的战术**，`counterplay.md` 零章说过不用。
- 合力计算：祖辈同住时，家长的 `CTL` 实际作用力 `−8`；不同住则不修正。

### 夫妻同盟 vs 夫妻分裂

| 状态 | 识别 | 对你的意义 |
|------|------|-----------|
| **同盟** | 两人在关键维度（`CTL`、`VAL`）差距 ≤ 20，且当面从不互相拆台 | 没有内部缺口。只能走外部路线（旁系长辈、外部权威） |
| **分裂** | 关键维度差距 ≥ 35，或有一方私下对你说过"你别听你妈的" | **迂回路线的入口就在这里**。低 W 的那一位是天然盟友 |
| **冷分裂** | 两人早已不沟通，各管各的 | 你要跟两个人分别谈两次，且**不能让任何一方知道你先跟另一方谈过** |

分裂状态下的合力算法：关键维度取 W 更高者的值，**同时把这个家庭的合力 `COM` 记 `−10`**——家里意见不统一时，你的沟通成本反而更高，因为你要同时应付两条战线，还要防止两边对口供。

### 亲戚助攻 / 添乱

旁系长辈的 W 通常 < 0.1，但他们控制**舆论场**：家长在亲戚面前的说法，会反过来锁死家长在家里的立场。

- **助攻位**：说过"现在孩子都这样"的那位。找他不是为了让他说服你妈，是为了让你妈知道"不止我家这样"。
- **补刀位**：习惯在饭桌上抛出比较句（"你看你表哥都二娃了"）的那位。他不是恶意，多数时候只是在填补冷场，但杀伤力是实打实的。
- 处理补刀位的原则：**当场不要反驳补刀者，反驳等于把家长逼到必须站队**。饭桌上接一句轻的过去，事后单独跟家长说。
- 效果量化：家庭聚会前后 72 小时内，家长的 `ANX` 临时 `+10`，`SOC` 临时 `−5`。这段时间不适合谈任何 `I≥3` 的事。

### 结构性沉默者

全程不说话，但事后执行另一位的决定。**这是最容易误判的角色。**

- 识别：`COM≤25` + `INV≤30`，冲突现场从不表态，但过后由他来收手机、来打电话、来下最后通牒。
- 误判后果：你以为"我爸不管这事"，实际他的 W 可能有 0.4。他不说话不是没意见，是**他的表达方式是行动不是语言**。
- 应对：不要在现场争取他表态，那会逼他站到主攻方一侧。**单独找他，用最短的话说结论**——沉默者受不了长篇论证，但接得住一句"爸，这事我定了，我跟你说一声"。

## A5. 家庭合力画像

**不是平均。** 简单平均会造出一个不存在的温和家长——家里有一个 `CTL=92` 的人，其他人再温和也不能把这个数稀释掉。

**基础式**

```
合力ᵢ = Σ(Wⱼ × 画像ⱼᵢ) / ΣWⱼ        （只计入 W ≥ 0.1 的角色）
```

**然后按顺序套三条覆盖规则：**

**规则一 · 极端值穿透**
任一角色某维度 ≥85 或 ≤15，且该角色 `W≥0.3`，则该维度**直接取这个角色的值**，不参与平均。
理由：极端维度是人格底色，在家庭里同样是底色。家里有一个人 `CTL=92`，这个家在控制这件事上就是 92。

**规则二 · 否决位优先**
掌握实物资源的角色，在**该资源相关维度**（通常是 `FIN`、`CTL`）上的值直接作为合力值。
你要钱，出钱那个人的 `FIN` 就是全家的 `FIN`，另一位再慷慨也没用。

**规则三 · 同盟增幅 / 分裂标记**
- 两个 `W≥0.25` 的角色在同一维度都 ≥65 → 合力值取 `max + 5`，封顶 100。两个人一起施压，压力大于两人中较强的那个。
- 两人在同一维度差距 ≥35 → 取 W 高者的值，并在输出里**单列一个"可用盟友"字段**，登记 W 低的那位及其差异维度。这个字段是 `counterplay.md` 迂回路线的直接输入。

**最后回读一遍 `dimensions.md` 第七章的耦合规则**——合力画像算出来之后可能触发单个角色都没有的耦合项，比如妈的 `CTL=78` 和爸的 `WRM=30` 合成之后落进"高压无温度"，而这个家庭里其实没有任何一个人是那样的。**触发了要标注"这是结构产生的，不是某个人产生的"**，否则用户会误以为是在说他爸。

**算例**（用 A2 那四个角色，场景=辞职考研）

W 先按 A3 算：人生选择场景看 `CTL + (100−VAL)`，妈 78+72=150，爸 45+65=110，妈主导；爸掌钱，`+0.2`；奶奶不同住不修正。归一后 `妈 0.55 / 爸 0.30 / 奶奶 0.10 / 姑姑 0.05`，姑姑 W<0.1 出局。

```
基础加权（分母 0.95）：
  CTL = (0.55×78 + 0.30×45 + 0.10×30) / 0.95 = 62.5 → 63
  ANX = (0.55×82 + 0.30×40 + 0.10×35) / 0.95 = 63.8 → 64
  WRM = (0.55×65 + 0.30×30 + 0.10×88) / 0.95 = 56.4 → 56
  其余同法：INV 63 / COM 31 / VAL 29 / EXP 65 / SOC 35 / IND 38

套覆盖规则：
  规则一  妈 INV=85 且 W=0.55≥0.3 → 穿透，INV 直接取 85（不是 63）
          奶奶 WRM=88 但 W=0.10 < 0.3 → 不穿透，WRM 保持 56
  规则二  钱在爸手上 → FIN 直接取爸的 70，不平均
  规则三  EXP 妈 75、爸 60，未同时 ≥65 → 不增幅，保持 65
          IND 妈 25、爸 60，差 35 → 分裂，取 W 高者（妈）25，登记爸为盟友
```

**输出示例**

```
【家庭合力画像】
  CTL:63  WRM:56  INV:85(穿透·妈)  ANX:64  COM:31
  VAL:29  FIN:70(否决位·爸)  EXP:65  SOC:35  IND:25(分裂·取妈)

【结构说明】
  · 参与度不是平均出来的，是妈一个人锁死的：这个家在"被介入"这件事上
    就是 85，爸的 25 和奶奶的 60 稀释不掉
  · 钱和放手权分别在两个人手上——你要钱得过爸，你要自主得过妈，
    这两件事不能在同一场谈话里一起要
  · VAL:29 + SOC:35 差 5 分就触发「门第观念」耦合，属于临界，
    婚恋场景里要按已触发处理

【可用盟友】
  爸（W:0.30）：IND 比妈高 35，VAL 高 7。在"要不要放手"这件事上是缺口。
  注意他 COM:20，属于结构性沉默者，别指望他当面帮你说话
```

## A6. 多角色对话输出格式

```
【场景】{时间 + 地点 + 在场的人}
【场上态势】{谁主攻、谁沉默、谁护短、谁补刀，一句话}
【交叉台词】
  角色（动作/语气）：「台词」
  ...
【暗线】{台词底下真正在发生的事}
【你的缺口】{这一局里最可能被撬动的那个人，以及第一句话该对谁说}
```

**示例：年夜饭**

```
【场景】除夕，老家客厅，饭桌。在场：妈、爸、奶奶、姑姑、你
【场上态势】妈主攻（催婚），爸沉默但掌钱，奶奶护短做缓冲，姑姑补刀（无恶意，填冷场）

【交叉台词】

  姑姑（夹菜，笑）：「哎哟，一年不见又瘦了。今年有对象没有啊？」

  妈（放下筷子，等这句话等了一晚上）：「你问他？他一个月给我打两次电话，
    我问一次他挂一次。他姑，你说说他。」

  爸（没抬头，夹了口菜）：「……吃饭。」

  奶奶（往你碗里放了个鸡腿）：「孩子刚回来，先吃饭。急什么，缘分的事。」

  姑姑（补刀，自己都没意识到）：「妈你不知道，现在跟以前不一样了。
    你看我们家小磊，二娃都会走路了。这个再拖两年，人家挑剩的都轮不上。」

  妈（拿到弹药，声调上来）：「你听见没有？我说的你不听，你姑说的总是真话吧。」

  你（不能反驳姑姑，反驳等于逼妈站队）：「姑，二娃真会走路啦？下次带过来我看看。」

  奶奶（接得很稳）：「就是，吃饭吃饭。他妈你也少说两句，一年就回来这几天。」

  爸（起身去厨房，走的时候说了半句）：「……先把工作弄稳当。」

【暗线】
  妈的目标不是今晚拿到答案，是当着亲戚把这件事挂起来，让你欠一个交代。
  姑姑不是敌人，她只是在填冷场，她的话对妈的杀伤力比对你大——
  「人家挑剩的」这句真正扎的是妈的面子。
  爸那半句是全场唯一的实质信息：他关心的是工作不是婚姻，
  他的 W 有 0.3 却整晚只说了四个字，典型的结构性沉默者。
  奶奶两次打断都成功了，但她改变的是节奏，不是结论。

【你的缺口】
  不在妈身上，在爸身上。
  今晚什么都别谈。明天下午找爸单独说一句：
  「爸，我工作这边我有打算，年后跟你说。你帮我跟我妈说一声，先别催我。」
  ——沉默者要的是被单独告知，不是被说服。给他一个「你先知道」的位置，
  他就有理由在妈那边替你挡一句。
```

**生成多角色对话时的三条要求**

1. **每个人的台词必须能反推出他自己的维度**，不能所有人都在说同一个立场的不同措辞。
2. **必须有人不说话或说错话。** 真实饭桌上永远有人在夹菜、有人在看手机、有人说了句跟主题无关的。全员在线的对话一眼假。
3. **不要让任何一个角色纯粹当反派。** 补刀的姑姑也是真心觉得在帮你，这一层要写出来。

# B. 背景修正因子

## B0. 先看这段

**下面所有数字都是统计倾向，不是决定论。**

- 个体差异远大于群体差异。同一年代、同一地方长大的两位家长，`CTL` 差 50 分是常事。
- **用户说的永远优先。** 优先级：用户的原话 > 用户给的分值 > 这张表推出来的偏移。三者冲突时，无条件采信用户。
- 偏移**只用来补全未知维度**，不用来修改用户已经说明的维度。用户说"我妈很开明"，就算背景因子算出 `VAL−15`，也不许往下调。
- 这些因子解释的是**处境**，不是**素质**。一个家长对新职业不了解，是因为他身边没人做过，不是因为他见识短。**任何时候都不要用这张表去判断一个家长"落后"。**
- 本表**不提供**基于地域、基于子女性别的偏移，也不把学历与开明程度挂钩。现实中确实存在差别对待，但那属于用户描述的事实——用户说了就按用户说的记，不由这张表预设。

## B1. 代际

按家长的出生年代。差异主要来自他们成长期的物质条件和信息环境。

| 家长年代 | 偏移 | 依据 |
|---------|------|------|
| **50 后** | `FIN −10`　`VAL −12`　`COM −8`　`IND +5`　`INV −8` | 经历过物质匮乏，对花钱天然谨慎；子女数量多，单个孩子分到的关注被摊薄 |
| **60 后** | `CTL +5`　`EXP +8`　`INV +8`　`VAL −5` | 子女多为独生，资源与期待同时集中 |
| **70 后** | `ANX +10`　`EXP +8`　`FIN +8`　`INV +10`　`COM +5` | 亲历教育竞争加剧，投入意愿和焦虑同步上升 |
| **80 后** | `COM +10`　`VAL +12`　`IND +8`　`INV +12`　`ANX +8` | 育儿信息获取渠道多，沟通意识强；但信息过载本身也制造焦虑 |

`ANX` 在 70 后和 80 后都是正偏移，原因不同：70 后的焦虑来自资源竞争，80 后的焦虑来自"我是不是没做对"。前者对数字有反应（`counterplay.md` T2 有效），后者对权威建议有反应（T1 有效）。

## B2. 城乡与城市层级

**城乡本身不是变量。** 它只是下面两个结构变量的粗略代理。**能直接问到结构变量就不要用代理**——用户能说清"我爸单位里有人辞职做自由职业吗"，就别去猜他家在几线城市。

| 结构变量 | 含义 | 取值与偏移 |
|---------|------|-----------|
| **新路径可见度** | 家长身边有没有人做过你想做的事 | 高：`VAL +8`　中：0　低：`VAL −8`　`ANX +5` |
| **熟人社交密度** | 家长的日常社交圈是否高度重叠、彼此知根知底 | 高：`SOC −6`，面子权重 ×1.4　中：×1.0　低：`SOC +4`，面子权重 ×0.7 |

**面子权重**是个乘数，不是维度。它放大 `SOC` 和 `VAL` 在婚恋、职业场景里的实际作用力，并直接决定 `counterplay.md` 里 T4 面子保全的优先级：面子权重 ≥1.4 时 T4 上升为首选战术。

粗略代理关系（**仅在拿不到直接信息时用**）：大城市通常新路径可见度偏高、熟人密度偏低；小城市和县镇通常反过来。这只是两个结构变量的分布差异，**不是对任何地方的人的评价**。

## B3. 独生子女 vs 多子女

| 情况 | 偏移 |
|------|------|
| **独生** | `INV +12`　`CTL +8`　`ANX +10`　`FIN +8`　`IND −8` |
| **多子女（期待均摊）** | 每个孩子身上 `INV −8`　`EXP −5`　`FIN −5` |
| **多子女（期待集中在你身上）** | 你身上 `EXP +12`　`INV +5`；其他孩子身上 `INV −15`　`EXP −15` |

独生的核心机制是**没有分母**：所有资源、所有期待、所有焦虑都只有一个出口。这也是为什么独生家庭里 `ANX≥75` + `FIN≥70` 的"焦虑变现"耦合特别常见。

多子女要额外注意**横向比较机制**：兄弟姐妹之间的对照会让家长的 `EXP` 在短期内剧烈波动——你表现好的时候她的 `EXP` 对另一个孩子上升，反之亦然。这个波动本身就是压力源，且它跟出生顺序关系不大。**排行造成的差异，多数其实来自家庭在不同时期的经济状况和精力状况，不是排行本身。**

## B4. 家庭结构

| 结构 | 偏移 |
|------|------|
| **双亲同住** | 基线，不修正 |
| **单亲** | 两种分叉，别混：<br>独自承担生计 → `INV −10`　`COM −8`<br>情感集中于孩子 → `WRM +8`　`CTL +8`　`ANX +10`　`IND −10` |
| **隔代抚养**（幼年由祖辈带大） | 家长：`INV −25`　`WRM −10`　`FIN +12`　重逢期 `CTL +10`<br>祖辈：`WRM +15`　`EXP −15` |
| **重组家庭** | `COM −5`；**决策权重必须单列**，不要合并计算 |
| **长期分离史**（留守、异地工作多年） | `ANX +8`　`COM −8`　`INV −12` |

隔代抚养这一条要说清楚：`WRM −10` 指的是**情感表达通道断了，不是爱少了**。这类家长常见的表现是补偿性给钱（`FIN +12`）加上突然的强控制（重逢期 `CTL +10`），叠起来正好落进 `dimensions.md` 里 `INV≤20 + CTL≥60` 的"诈尸式"耦合。**这是背景因子能解释诊断结果的典型例子**——用户觉得"我爸莫名其妙一管就往死里管"，根子在这儿。

重组家庭不预设任何负面偏移。需要单列决策权重，是因为这类家庭的 W 分布通常更复杂，不是因为关系更差。

## B5. 家长自身的职业与受教育经历

**先把一个偏见排除掉：受教育年限不等于开明程度。** 高学历家长可能同样保守，区别只在于**他要求你用更完整的论证**。学历影响的是"什么样的说服方式有效"，不是 `VAL` 的高低。

| 变量 | 取值 | 偏移与说明 |
|------|------|-----------|
| **自身职业的稳定性** | 长期在高保障岗位（体制内、事业单位、大型国企） | `VAL −8`（对不稳定路径）　`CTL +5`；期待目标常具体化为某类编制或职称 |
| | 个体经营、自雇、务农、灵活就业 | `VAL +6`（见过风险，容忍度高）；`ANX` 分叉——经营顺利过 `−8`，栽过跟头 `+12`，后者对"辞职创业"的反应远超其 `CTL` 分值预测 |
| **风险暴露史** | 本人经历过下岗、失业、生意失败 | `ANX +12`　`FIN −8`；对"稳定"的坚持是**具体的恐惧**，不是抽象的观念，讲道理没用，`counterplay.md` T3 焦虑对冲是唯一有效解 |
| **对你所在行业的了解通道** | 直接接触过 | 数字化说服（T2）有效 |
| | 只从亲戚口耳或短视频了解 | T2 效果减半，改用 T1 归因外移或 T7 借第三方 |
| **受教育年限** | 高 | 不修正 `VAL`。修正的是**论证门槛**：需要更完整的逻辑链，但一旦逻辑成立，翻盘更彻底 |
| | 低 | 不修正 `VAL`。改用具体案例代替抽象论证，效果更好 |

## B6. 家庭经济状况变化史

这一组的解释力经常比前面几组加起来都强。

| 轨迹 | 偏移 | 特征 |
|------|------|------|
| **一直宽裕** | `FIN +10`　`ANX −8`　`VAL +5` | 对试错的容忍度高，因为兜得住 |
| **一直紧张但稳定** | `FIN −10`　`ANX +5`　`EXP` 向"稳定"倾斜 | 反对的是波动本身，不是你的具体选择 |
| **由穷变富** | `FIN +12` 但消费审查 `CTL +8`　`EXP +10`　`ANX +10` | 对自己苛刻、对你慷慨，同时盯着你怎么花。核心是**怕跌回去** |
| **由富变穷** | `ANX +18`　`FIN −12`　`EXP +12`　`WRM −8`　面子权重 ×1.5 | 单独看下面一段 |

**由富变穷这一类要特别标注。** 它的焦虑特征和其他三类都不一样：

- 反应强度**远超其 `CTL` 分值的预测**。你说"我想辞职"，一个 `CTL=55` 的家长可能给出 `CTL=85` 的反应，因为你触发的不是控制欲，是**重演恐惧**——他见过一次从体面到不体面的滑落，他不打算见第二次。
- 对**体面**的执着强于对**收入**的执着。月薪两万的自由职业，在他这里可能不如月薪八千的"单位"。跟他谈钱是谈不通的，要谈"名分"：合同、社保、职称、工牌、能写在名片上的东西。
- `WRM −8` 是羞耻感造成的表达退缩，不是不爱。这类家长在孩子面前常有一种"我没能给你留下什么"的心理，你的任何一次失败他都会算到自己头上。
- 应对上，`counterplay.md` 的 T4 面子保全和 T3 焦虑对冲要同时上，而且 B 计划里必须包含一条"体面的退路"，不能只有"我饿不死"。

## B7. 叠加规则

1. **所有偏移相加，最后 clamp 到 0–100。**
2. **单个维度的偏移总量绝对值封顶 ±25。** 不封顶会叠出一个现实里不存在的极端人格——三四个因子同向叠加就能把 `ANX` 推到 100，那不是家长，那是漫画。
3. **偏移只作用于未知维度。** 用户已经说明的维度不动，哪怕算出来差很多。
4. **算完必须回读 `dimensions.md` 第七章。** 偏移可能触发新的耦合项，触发了就要在诊断里说明。
5. **偏移过的维度要标记来源**，例如 `ANX:78(背景推断)`。用户看到推断值有权反驳，标记了他才知道哪些是他说的、哪些是你猜的。
6. 多角色场景里，**每个角色单独走一遍背景修正**再进 A5 合力计算。祖辈和家长的代际因子不同，不能共用。

## B8. 三条提醒

**背景因子最多解释一半。** 剩下一半是这个人本身——他的性格、他年轻时候的某一次经历、他和你父母另一方的关系。算出来的偏移和用户描述对不上时，**是因子错了，不是用户记错了**。

**不要把因子讲给用户听成一个判决。** "你妈是 60 后 + 独生 + 由富变穷，所以她注定控制你"——这种话既不准确也没用。正确的说法是："这几个背景放在一起，能解释她为什么对不稳定这么敏感。这不代表改变不了，只是说明你要处理的是恐惧，不是观念。"

**因子是用来生成理解的，不是用来生成借口的。** 解释一个行为的来源，不等于认可这个行为。用户如果说"那她也是没办法"，可以接一句：她的处境能解释她为什么这样，但她这样对你造成的影响是真实的，两件事不冲突。

## 与其他文件的关系

- `dimensions.md`——维度、档位、耦合规则的唯一来源。本文件所有偏移都作用在它定义的 0–100 轴上。
- `counterplay.md`——多角色场景先在这里算出合力画像、W 分布和"可用盟友"字段，再拿去走可行性分级与路线选择。迂回路线的盟友人选直接来自 A4。
- `SKILL.md`——诊断模式在信息不足时，可以用 B 部分的背景因子做初步推断，但必须标记为推断值并向用户确认。
