# Move-Out Checklist (退租与押金退还)

The goal is a fast, documented deposit return.

## Before You Leave

- **Give proper written notice** (usually 30 days before the lease ends, or per
  the contract). Keep the dated message.
- **Settle all utilities**; take final meter readings and photos.
- **Clean the unit to move-in condition** (not showroom new) so cleaning is not
  a valid deduction.
- Remove your belongings; return all keys / access cards.

## Joint Walkthrough With The Landlord

- Do the walkthrough **together**, side by side, not by handing over keys
  remotely.
- Compare against the move-in handover list. Point out that existing defects were
  already documented.
- The landlord must show **evidence (photos + receipts)** for any damage beyond
  normal wear before deducting.
- Agree the deposit return amount and **get it in writing** (signed / chat
  confirmation) with the return date.

## If The Landlord Withholds The Deposit

1. Stay calm and reference the move-in photos/list and the normal-wear rule.
2. Ask for a written, itemized deduction with evidence.
3. Escalate channels:
   - **12345** — government service hotline / complaint.
   - **12348** — legal-aid hotline for advice.
   - Local housing / 住建部门 rental-discipline channel.
   - **Small-claims court** — disputes up to about **RMB 50,000** use a simplified
     procedure; bring the contract, receipts, move-in/out photos.

## Common Scam

- "We will return the deposit after we find the next tenant" — illegal; the
  deposit should be returned at the end of the agreed term, regardless of
  re-rental.
