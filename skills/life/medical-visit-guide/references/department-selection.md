# Department Selection Guide

Choose a department by **symptom**, not by a disease name you guessed online.
Picking the wrong department means a wasted trip and a referral that delays care.

## Pick by symptom (not by guessed disease)

| Symptom | First-choice department | Notes |
|---------|--------------------------|-------|
| Headache, dizziness, numbness, seizures, stroke-like signs | 神经内科 (Neurology) | stroke-like signs go straight to 急诊 |
| Chest pain, palpitations, shortness of breath, high blood pressure | 心内科 (Cardiology) | chest pain now = 急诊 |
| Cough, phlegm, asthma, wheezing, sleep apnea | 呼吸内科 (Respiratory) | fever with breathing difficulty = 急诊 |
| Stomach pain, acid reflux, diarrhea, constipation, liver issues | 消化内科 (Gastroenterology) | black stool / vomiting blood = 急诊 |
| Fever of unknown origin, infection symptoms | 发热门诊 / 感染科 (Fever clinic / Infectious disease) | follow local COVID-era fever clinic rules |
| Back pain, joint pain, sports injury, bone fracture concern | 骨科 (Orthopedics) | |
| Joint pain with morning stiffness, swelling across joints | 风湿免疫科 (Rheumatology) | |
| Rash, itching, skin lesions, acne | 皮肤科 (Dermatology) | |
| Urinary symptoms, blood in urine, prostate issues | 泌尿外科 / 肾内科 (Urology / Nephrology) | blood in urine not urgent but do not delay |
| Diabetes, thyroid, weight change, hormonal issues | 内分泌科 (Endocrinology) | |
| Anxiety, depression, insomnia, mood changes | 精神心理科 (Psychology / Psychiatry) | suicidal thoughts = emergency |
| Eye redness, vision change, eye pain | 眼科 (Ophthalmology) | sudden vision loss = 急诊 |
| Ear pain, hearing loss, sore throat, nosebleed | 耳鼻喉科 (ENT) | |
| Tooth pain, gum bleeding, dental work | 口腔科 (Dentistry) | |
| Pregnancy, prenatal care, gynecological issues | 妇产科 (OB/GYN) | pregnancy bleeding = 急诊 |
| Child fever, pediatric concerns | 儿科 (Pediatrics) | |

## 急诊 vs 门诊 (Emergency vs Outpatient)

| Go to 急诊 (Emergency) now | Book 门诊 (Outpatient) |
|----------------------------|------------------------|
| Any red flag on the emergency list (see red-flags reference) | symptoms stable, days-to-weeks duration |
| Sudden onset, severe, worsening by the hour | chronic, recurring, mild-to-moderate |
| Cannot walk / speak / breathe normally | can function, waiting days is acceptable |

If unsure, go to 急诊. Better to be sent home than to wait at home.

## Using the 导诊台 (triage desk)

Every hospital has a 导诊台 (information / triage desk) near the entrance. If you
are unsure which department to pick:

1. Bring your symptom anchor (one-line summary).
2. Tell the triage nurse your symptom and duration.
3. Ask them to direct you to the right department.
4. They can also flag if you should go straight to 急诊.

## Tip

When in doubt between two departments, pick the one the symptom most directly
points to. The doctor on site can write a referral (转诊) to the correct
specialist; that is faster than guessing wrong at home.
