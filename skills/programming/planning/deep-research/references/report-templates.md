## Markdown report template

```markdown
# Deep Research Report: {topic}

**Generated:** {timestamp}  
**Search rounds:** {rounds}  
**Source count:** {source_count}  
**Overall credibility:** {trust_score}/1.0

---

## Abstract

{core findings in 2-3 sentences}

---

## Key findings

### 1. {finding title}
{detailed description}

**Sources:**
- [Source 1](url) (credibility: ⭐⭐⭐⭐⭐)
- [Source 2](url) (credibility: ⭐⭐⭐⭐)

### 2. {finding title}
{detailed description}

...

---

## Multiple perspectives

| Perspective | Main view | Support |
|------|---------|--------|
| Technical implementation | {view} | ⭐⭐⭐⭐ |
| Performance comparison | {view} | ⭐⭐⭐ |
| Community feedback | {view} | ⭐⭐⭐⭐⭐ |

---

## Controversies and disagreements

{list conflicting information here, if any}

---

## Information gaps

{list uncovered points here, if any}

---

## Full source list

| # | Title | URL | Credibility |
|---|------|-----|--------|
| 1 | {title} | [link](url) | ⭐⭐⭐⭐⭐ |

---

*Generated by deep-research v1.0*
```

## JSON report template

```json
{
  "topic": "research topic",
  "generated_at": "ISO timestamp",
  "search_stats": {
    "rounds": 3,
    "queries": 12,
    "sources": 25,
    "deduped_sources": 18
  },
  "summary": "core findings summary",
  "findings": [
    {
      "title": "finding title",
      "content": "detailed description",
      "evidence": [
        {"source": "url", "title": "title", "trust": 0.95}
      ],
      "confidence": 0.88
    }
  ],
  "perspectives": {
    "technical": {"result_count": 10, "key_findings": [...], "trust_score": 0.85},
    "performance": {"result_count": 5, "key_findings": [...], "trust_score": 0.78}
  },
  "conflicts": [
    {
      "topic": "point of contention",
      "sources": ["url1", "url2"],
      "conflict": "disagreeing views",
      "resolution": "needs further verification"
    }
  ],
  "gaps": ["missing information about X"],
  "sources": [...]
}
```
