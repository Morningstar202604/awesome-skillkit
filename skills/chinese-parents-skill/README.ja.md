## 概要

お母さんに「あの家の子を見なさい」と言われたことはある？

テストで3位だったとき、まず褒めてから「じゃあ1位は何点？」と聞くお母さんはいる？

このプロジェクトは理論研究ではない。3つのことだけをやる。

- **シミュレーション** —— お母さんがどういう人か教えると、AIがその通りに演じる
- **診断** —— お母さんの行動を描写すると、再計算可能な次元プロフィールを逆算する
- **対策** —— 口に出す勇気が出ないことがある。その会話を先に一度リハーサルする

中国式の親は一つじゃない。「テストで3位」という同じ出来事でも、まず叱ってから聞く親もいれば、まず褒めてから聞く親もいるし、そもそも聞かない親もいる。10の次元、それぞれ0〜100点、理論上は**59049通りの親の形**をカバーする。

**このスキルの目的は一言で言えば：あなたと他人がどちらも再計算できる「中国式の親のプロフィール」を復元すること。** シミュレーション・診断・対策はすべて手段であり、プロフィールこそが目的だ。計算されたその「お母さん」は、筋が通っていなければならない（数式がある）、一致していなければならない（同じ人を2回聞けば同じ結果になる）、そして誠実に失敗しなければならない（データが欠けていれば「計算できない」と明言し、でっち上げない）。v0.5で補強した土台は、まさにこの3点のためだ。複数ターンの推演が本当に動くようになり、偽の数字は塞がれ、ドキュメント内のすべての数字にアサーションが守っている。

**v0.5での最大の変化**：v0.4には「計算機」があったが、最初のターンしか計算していなかった。「言い返したらどう反応する？」と聞いても答えられなかった。今は複数ターンの状態遷移マシンが完全に実装され、5ターンの対話が値ごとに再現できる。また、欠落した次元を黙って50で埋めること（これはv0.4自身が警告した偽数字の罠だ）はなくなり、known/inferred/blindの3段階の信頼度＋汚染追跡を通るようになった。

## 3つのモード

### 1. シミュレーション

プロフィールを教えれば、演じる。複数ターン対応 —— 言い返せば、彼女がどうエスカレートするか見られる。

```
あなた：うちの母は厳しいけど根は優しいタイプ。転職して自メディアやると言ったとする

AI： 【プロフィール】統制 厳格(72)・温度 温かい(58)・不安 不安(60)・価値観 伝統的(30)
     【状態】TEMP 24（構え）・BOND 69・譲歩閾値 70

     「自メディア？なんの仕事だ、年金も健康保険も誰が払ってくれるんだ？」
     ...
     ── TEMP 42 ↑18（圧力）│ BOND 66 ↓3 │ 説得進度 12/70

あなた：これは私の勝手だ、口を出さないで

AI： ── TEMP 75 ↑33（感情的）│ BOND 58 ↓8
     「お前の勝手？お前の人生で俺が心配してないことは一つでもあるか？いいだろう、
      お前の勝手だ、全部お前の勝手だ……」
```

「これは私の勝手だ」という言葉は地雷表で+40、さらに`CTL≥75`の親には追加で+10される。**これは語彙全体でコスパ最悪の一言だ —— 道理はこちらにあるが、勝負には負ける。**

### 2. 診断

行動を描写すれば、プロフィールを逆算する。あるいは30問のクイズを受ける。

```
  統制  █████████████████████░░░   88  支配的
  温度  ██████░░░░░░░░░░░░░░░░░░   25  理性的
  関与  █████████████████░░░░░░░   70  主体的
  不安  ████████████████████░░░░   85  パニック
  コミュニケーション  ████░░░░░░░░░░░░░░░░░░░░   18  命令
  価値観  █████░░░░░░░░░░░░░░░░░░░   20  伝統的
  金銭  ███████░░░░░░░░░░░░░░░░░   30  ケチ
  期待  ██████████████████████░░   92  極めて高い

  ── 発動した結合ルール ──
   ▸ 温かみのない圧力：家が管理事務所と化し、命令だけで感情の回路がない
   ▸ 行き場のない不安：不安の発散先がなく、絶え間ない小言と八つ当たりになる
   ▸ 成績にひもづく愛：失敗すれば愛を失い、無視が主な罰

   目標は説得ではなく、関係スコアを落とさずに次のラウンドまで持ちこたえること。
```

**これらの数字は飾りではない。** v0.3でもパーセンテージは印刷されていたが、文書全体にアルゴリズムはなかった —— 同じ人を2回聞けば2通りの報告が出た。v0.4は数式と計算機を提供した。自分で確かめられる。

### 3. 対策

これはv0.4で新しく加わり、多くの人が本当に求めていた部分だ。

診断は「お母さんは虎の親だ」と教えてくれる。だが本当に知りたいのは**この話をどう切り出すべきか**だ。

対策モードが提供するのは：目標の実現可能性グレード（勝てない戦いもあり、それは率直に言う）、3つのルート（正面／側面／既成事実）、12の戦術、3層の反応ツリー、そして破綻したときの収め方だ。

> **T4 メンツ（面子）の保全**
> 中国の家庭では、圧力の多くは親自身の望むものではない。親戚が食卓で何かを聞き、返答に窮して、圧力が下へ伝わるのだ。
> 食卓で言える一言を渡せば、圧力の源を彼女から取り除ける。
> さらに効くのは：「本当に追い詰められたら電話を私に渡して、私が話すから。」
> 彼女が求めているのはあなたの結婚ではなく、食卓で恥をかかないことだ。

*メンツ*（**面子** *miànzi*）とは、親戚の前で保つ彼女の立場のこと。公の場でそれを失うことは、中国の家庭において本当のコストであり、単なる比喩ではない。

## 10の次元、中国式の親を解体する

| 次元 | 何を測るか | 0端 → 100端 |
|------|-----------|--------------|
| 統制 `CTL` | 管理の幅 | 放任・適度・厳格・支配的 |
| 温度 `WRM` | 感情表現の濃度 | 冷酷・理性的・温かい・過保護 |
| 関与 `INV` | どれだけ精力を注いだか | 不在・受動的・主体的・過剰介入 |
| 不安 `ANX` | 未来への不安の強さ | 仏系的・適度・不安・パニック |
| コミュニケーション `COM` | 情報の流れの方向 | 命令・説教・相談・傾聴 |
| 価値観 `VAL` | 保守か革新的か | 伝統的・混合・革新的 |
| 金銭 `FIN` | 金を出す方法 | ケチ・適度・寛大 |
| 期待 `EXP` | 期待の高さ | 無関心・適度・極めて高い |
| 社交 `SOC` | 交友関係の管理 | 閉鎖的・誘導的・開放的 |
| 自立 `IND` | 育てるか代行するか | 代行・誘導・手放す |

**2つの直感に反する点**：

`温度`は「愛の量」ではなく、**感情表現の濃度**だ。0端の冷酷は愛を口に出せないこと、100端の過保護は息が詰まるほどの愛だ。両極端に問題がある —— これだけは中間やや高めが最適な次元だ。

`コミュニケーション`は「話す量」ではなく、**情報の流れの方向**だ。`COM=88`の親は一晩で3文しか話さないかもしれないが、どれも「で、どうなった？」「どう思う？」だ。おしゃべりを高得点と取り違えてはいけない。

### 1つの次元だけでは見えないもの

親が扱いにくいかどうかを決めるのは、往々にして組み合わせだ。

| 組み合わせ | それは何か |
|------------|-----------|
| `コミュニケーション高` + `統制高` | **偽りの民主主義**。40分話を聞いてから、元の計画を実行する |
| `関与低` + `コミュニケーション低` + `統制中` | **ゾンビ式育児**（*zhàshī-shì*、「死体が起き上がる」）。何ヶ月も消え、一夜にして全権掌握、前ぶれなし |
| `統制高` + `温度高` | **甘い窒息**。怒鳴らず罵らず、ため息と涙だけ。口論の入り口すら見つからない |
| `不安高` + `金銭低` | 行き場のない不安が、小言と八つ当たりに変わる |
| `期待高` + `温度低` | 愛が成績にひもづく。失敗すれば愛を失い、無視が主な罰 |

**偽りの民主主義は最も見分けにくい**。過程が「良いコミュニケーション」の基準をすべて満たすからだ。怒る理由すら見つからず、自分を疑うしかない。

判断基準は一つだけ：**聞き終わったあと、結論は変わったか？**

### 8つのアンカー

親の「種類」ではなく、地図上の8つの座標だ。類似度スコアリングに使う。あなたのお母さんはほぼ確実にその間にいる。完全なベクトルは[dimensions.md](references/dimensions.md)に。

| アンカー | `--type` 値 | 一言で |
|----------|--------------|--------|
| 虎の親 | `虎妈虎爸` | 最高のハードル、最低の温かみ、交渉なし |
| 詰め込み親 | `鸡娃家长` | *jīwá*（「鶏に血を注ぐ」ネット語——受験・習い事で子どもを燃やす）— 目覚めから就寝まで塾と習い事で埋め尽くし、金は惜しまず絶えずパニック |
| ヘリコプターペアレンツ | `直升机父母` | 関与が有用の範囲を大きく超えてる |
| 仏系親 | `佛系家长` | *fóxì*（「仏系」ネット語——本当にプレッシャーをかけない） |
| 寛容な親 | `开明家长` | 聞く、そして結論が本当に動く |
| 強権的親 | `强势家长` | 代わりに決め、説明せず、抵抗すればエスカレート |
| ゾンビ式育児 | `诈尸式育儿` | デフォルト不在、突然目覚めて全権掌握 |
| 未亡人式育児 | `丧偶式育儿` | *sàng'ǒu-shì*、「未亡人のように」——片親が家にいて実質不在 |

最後の2つの差は`CTL`と`ANX`だけ。未亡人式は本当に手を引いている（`CTL=12`）。ゾンビ式は数ヶ月無視してから全部やり直す（`CTL=30`に`COM=12`、純粋な命令）。ゾンビ式の方がダメージが大きい —— 予告なき介入だから。

## 計算機

### プロフィール

```bash
# 一部の次元を指定、残りは結合ルールから推論
python3 scripts/profile.py --scores "CTL=88,ANX=85,EXP=92"

# 参考タイプを読み込む
python3 scripts/profile.py --type 虎妈虎爸

# 30問のクイズにインタラクティブに回答
python3 scripts/profile.py --quiz

# 回答文字列は保存可能、次回そのまま再現
python3 scripts/profile.py --answers cdcbbdcddcaabbcbabcabdddaacbad

# 機械可読
python3 scripts/profile.py --scores "..." --json
```

純標準ライブラリ、依存ゼロ、Python 3.8+。次元の棒グラフ、極端な次元、結合ルール、類似度ランキング、6つのダイナミクス初期値と読み方を出力する。

**欠落した次元は推測しない：** `CTL=90`だけを与えると、残りは結合ルールから推論される（`inferred`、方向は信頼できるが数値は当てにするな）か、50で埋められる（`blind`、結論は無効）。埋められた次元が下流のダイナミクス量を汚染すると、出力に`⚠`が付き、**類似度と読み方が抑制される**。`blind`次元が4つ以上なら、単に「類似度は報告しない」となる。言わない方がまし、でっち上げるな。

**ドキュメント内のすべての数字はこのスクリプトの再計算と一致する**。8つの参考タイプ×6つのダイナミクス量の表も含めて。一致しなければバグなので、Issueを歓迎する。

### 複数ターン推演

```bash
# 地雷表／氷割り表のすべての技を表示
python3 scripts/profile.py --list-moves

# 組み込みの5ターン例を実行（dynamics.md §7.2）
python3 scripts/profile.py --simulate-demo

# 自分で技の並び・関係口座の初期値・チャネルを指定
python3 scripts/profile.py --type 虎妈虎爸 \
    --simulate T21 T9 T1 C2 C18 --bond 69 --channel wechat --who 我
```

`--simulate`は各ターンを行ごとの対账として印字する：どの台詞で、何度上がった・下がったか、BONDがどう動いたか、説得進度はどこか。最後に**判定**（真の譲歩／偽の譲歩／非譲歩）と**「最も高くついた一言」** —— 道理はこちらにありながら、関係スコアを最も削られた一言 —— を出す。直接対面以外（電話／WeChat）では加温が0.8倍、WeChatならさらに0.8倍になるが、BONDのダメージは×1.2される。

**この推演はデモではない。** `dynamics.md`第4〜7節の実行可能な仕様だ。加成效用は最高の1件だけを取り（合算しない）、1ターンの純加温は+35が上限、TEMP≥85では`[高温]`の項目だけが発動し×1.5、同じ氷割り台詞の2度目は×0.5、3度目は×0。`--simulate-demo`の5ターン結果はドキュメント§7.2と値ごとに一致し、数式を変えれば`scripts/test_profile.py`の68件のアサーションに即座に弾かれる。

## 18のシナリオ

最初の10個は古く、後の8個はv0.4で新たに加わった。完全な行列は[scenarios.md](references/scenarios.md)を参照。

| | シナリオ | 重要次元 |
|---|---------|---------|
| A | 学業／仕事の実績 | 統制・不安・期待 |
| B | 人生の選択（転職・起業・ギャップ年） | 価値観・統制・不安 |
| C | 恋愛・結婚 | 価値観・社交・統制 |
| D | 消費／金銭 | 金銭・統制 |
| E | 実家での同居 | 温度・関与 |
| F | 交友・社交生活 | 社交・統制 |
| G | ネット／電子機器 | 統制・不安 |
| H | 健康／生活習慣 | 温度・関与 |
| I | 外見／身だしなみ | 価値観・統制 |
| J | 学校選び・塾 | 不安・金銭・期待 |
| **K** | **親戚の集まりと横の比較** | 不安・社交・期待 |
| **L** | **結婚・出産・婚資金（聘金）の催促** | 価値観・不安・統制 |
| **M** | **住宅購入と実家からの資金** | 金銭・統制・自立 |
| **N** | **老親の介護と扶養** | 温度・関与・金銭 |
| **O** | **多子世帯とえこひいき** | 温度・金銭・期待 |
| **P** | **感情とメンタルヘルス** | 価値観・温度・コミュニケーション |
| **Q** | **プライバシーの境界（携帯を勝手に見る）** | 統制・社交 |
| **R** | **親戚が名前を言えないマイノリティ職業** | 価値観・不安・期待 |

*聘金*（**彩礼** *cǎilǐ*）は、結婚前に新郎側から新婦側の家族へ渡す金品のこと。中国の広い地域で今も生きた交渉事であり、两家が本当に争っているのはこれであることが多い。

新しいシナリオのうち、**M（住宅購入）**で争われるのは決して金銭そのものではなく、「この金を受け取ったあと、あなたにどれだけ発言権が残るか」だ。**O（えこひいき）**で最も重いのは、弟に回った10万元ではなく、あなたについて言われた「もうあいつには期待するな」の一言だ。

## 境界

このスキルは親子カウンセリングも、家族療法もせず、どちらかの肩を持たない。また、以下もしない。

- 身体的暴力、虐待、行動制限のシミュレーション
- 地域のステレオタイプ、あるいは出身地・学歴・職業による差別的帰因
- 「人格障害」「精神的虐待」といったラベルを人に貼ること —— 行動パターンを描写し、臨床的判断は下さない
- シミュレーションの末尾に「深く見れば親は皆あなたを愛している」と無理に付け加えること

**あなたの置かれた状況が身体的安全、深刻な情緒的虐待、経済的強要、あるいは自傷の念を含むなら、ここで台本を探さないでほしい。** それは表現を変えれば解決する問題ではない。現実で本当に助けてくれる人を探してほしい。

## 貢献

お母さんの、ここに収録されていない独特な一言がある？あるシナリオがお母さんらしくない？ある次元の得点帯がずれている？

我慢しないでほしい。このプロジェクトはみんなの共築で成り立っている。あなたのお母さんの経験は、大方他の人のお母さんにも当てはまるはずだ。

- 問題を見つけた → [Issueを立てる](https://github.com/weed33834/chinese-parents-skill/issues/new?template=bug_report.md)
- アイデアがある → [機能提案](https://github.com/weed33834/chinese-parents-skill/issues/new?template=feature_request.md)
- 新シナリオ → [シナリオ提案](https://github.com/weed33834/chinese-parents-skill/issues/new?template=scenario_suggestion.md)

PRを送る前に[CONTRIBUTING.md](CONTRIBUTING.md)を一読を。数式や次元ベクトルを変えた人は、`scripts/profile.py`を実行して、ドキュメントの数字がまだ合っているか確認してほしい。
