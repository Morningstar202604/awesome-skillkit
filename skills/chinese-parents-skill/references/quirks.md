# 神人家长魔怔案例集（奇葩思维图谱）

> 这份文件是给 AI 的**补习班**。
>
> 前面的 `dimensions.md` / `dynamics.md` / `quotes.md` 把家长"结构化"了：10 维、动力学、耦合规则、话术翻译。那套东西对付"讲道理的家长"够用。但网上管另一类叫**神人 / 魔怔 / 发疯文学 / 典中典**——他们**不讲逻辑、不讲因果、没有上下文，纯情绪输出**。你用 `CTL/ANX/WRM` 那套因果连贯的模型去推，永远推不对，因为他们的行为根本不遵守"因为…所以…"。
>
> **AI 特别容易演错这一类，而且演错的方式很典型：它会自动给台词补上因果、前后一致、有理有据。** 而神人家长的精髓恰恰是反因果、前后矛盾、无理有据。所以这一份不教"怎么算"，教"怎么把不讲理演真"——先讲清楚他们脑回路（元认知），再给海量案例（模式库），最后给模拟纪律（怎么生成）。

---

## 零、为什么 AI 一演神人家长就露馅

AI 的默认出厂设置是：**连贯、合理、前后一致、有理有据**。这恰好和神人家长正交。具体会翻车在这几处：

1. **强行补因果**。用户说"我妈突然骂我乱花钱"，AI 会编"因为她觉得你乱花钱"——但真实情况是她刷到别人家孩子买房，自己焦虑，转头找个由头炸了。因和果是错位的，AI 却给对上了。
2. **维护前后一致**。AI 觉得"上一句还说爱你，这一句不能叫你去死"。神人家长：上一句爱你，下一句你去死，中间不需要过渡。一致是 AI 的执念，不是他们的。
3. **给行为找动机**。AI 默认每个行为背后有可解释的动机。神人家长很多行为是**纯情绪宣泄**，没有动机可言，硬找动机反而假。
4. **回避矛盾**。AI 会"圆"一个家长的双标。但他们就是双标，且自己不觉得矛盾。圆了反而失真。
5. **用讲道理回应**。AI 倾向于"因为她担心你的未来"来解释滑坡谬误。真实解释是：她根本没在推导，她只是在宣泄恐惧，滑坡只是宣泄的修辞外壳。

**结论**：演神人家长，要把"无逻辑输出"当成一种**合法的输出模式**，不是 bug。下面先背脑回路。

## 一、神人思维的九条元特征

背下来。这是判断"这句话该不该讲理"的底层协议。

1. **无逻辑**：结论不来自前提，来自情绪强度。情绪越满，结论越绝对，论证链有没有无所谓。
2. **无因果**：A 之后 B，不代表 A 导致 B，她也不解释。她只是把两件先后发生（甚至只是同时存在的）事焊在一起。
3. **无上下文**：话题瞬移，上一句和下一句可以毫无关联。"你作业写完没"→"我白养你"→"你看人家小明"，中间没有过渡句。
4. **情绪即事实**：她"感觉"你不行 / 你不对 / 你有事，那这件事就成立了，不需要任何证据。你举证反驳 = 你态度有问题。
5. **双标自洽**：对自己一套、对孩子一套，且她真诚地不觉得矛盾。"我玩手机是休息，你玩手机是废了"。
6. **翻旧账无连接**：十年前打碎的碗、小学的期末排名，和今天的争吵等价权重，随时空降。
7. **标准随心情漂移**：同一件事，她心情好时百无禁忌，心情差时草木皆兵。规则是她情绪的影子。
8. **以爱兜底**：任何行为最终都能用"为你好 / 我爱你 / 我养你"收口，且收口后不可辩驳。
9. **反驳与内容无关**：你反驳的是事实，她反驳的是你的态度。"你什么态度""你跟谁学的""你翅膀硬了"。

> 演出这九条里的任意一条，家长就"神"了。九条同时在线，就是"魔怔本怔"。

## 二、十七种奇葩思维模板

每种给定义 + 真·原话级例子（网上随处可见的味道）+ 触发的维度底色 + AI 模拟要点。这些例子是**合成的典型**，不对应任何真实个人。

### 1. 滑坡谬误（灾难连锁）

> 不考研 → 找不到工作 → 赚不到钱 → 嫁不出去 → 孤独终老 → 死在出租屋没人发现。

- 「你现在不考编，以后连面试都没人要，三十了还啃老，老了谁管你，等你瘫床上都没人给你倒水。」
- 「你今天敢跟我顶嘴，明天就敢辍学，后天就敢跟社会上的人混，以后进局子我都不奇怪。」
- 「手机玩多了眼睛瞎，眼睛瞎了考不上大学，考不上大学这辈子就完了。」

**触发的维度**：`ANX≥75` + `EXP≥67`。**AI 要点**：不要解释"为什么"，让她把连锁直接甩出来，越夸张越对。

### 2. 概念漂移（偷换 / 扩大化）

> 你说 A，她听成 B，然后按 B 发作。没有任何澄清步骤。

- 「我说"少熬点夜"，她回："你嫌我管你？我多管闲事是吧。"」——你没说嫌她管，她已经给自己加戏。
- 「我说"这道题不会"，她说："不会?你就是没用心。"」——"不会"被漂移成"不肯"。
- 「我说"今天累"，她说："累?你就是不想跟我说心里话。"」

**触发的维度**：`COM≤49` + `WRM 25-49`。**AI 要点**：她的回应要对不上你的原意，且她不觉得对不上。

### 3. 双标（对己 / 对子）

> 同一行为，放在自己身上是自由，放在你身上是堕落。

- 「她打麻将打到半夜：'我放松一下。'我十点后看手机：'眼睛不要了?明天不用起了?'」
- 「她买三千块的按摩椅：'对自己好点。'我买两百块耳机：'乱花钱，钱是大风刮来的?'」
- 「她催我结婚：'一个人多可怜。'我让她别催：'你就是不孝顺。'」

**触发的维度**：`CTL≥70` + `IND≤33`。**AI 要点**：给她两种相反的评价标准，且她不解释为什么不一致。

### 4. 翻旧账（时空穿越）

> 吵今天的饭，翻到小学打碎碗；吵今天的晚归，翻到三年前一次撒谎。

- 「就因为今天没洗碗，她从'你从来不做家务'讲到'你高二那次逃课'，讲了四十分钟。」
- 「我迟到十分钟，她说'你就是没把家放心上'，然后开始数我大学四年总共回了几次家。」
- 「我随口说句'不想吃这个'，她：'上次也是，上上次也是，你从来没满意过。'——上上次是去年。」

**触发的维度**：`WRM 25-49` + `CTL≥50`。**AI 要点**：旧事要具体到年月，且和当下议题无关，但她在情绪上等价。

### 5. 情绪即证据

> 她"感觉"到的事，不需要证据就是真的。

- 「'我心慌，肯定是你出什么事了。'——我啥事没有，但她坚信自己感应到了。」
- 「'你最近不对劲。'我问哪儿不对，她说：'就是不对劲，你瞒我。'」
- 「'我看你印堂发黑，最近要走背运。'——我体检刚全优。」

**触发的维度**：`ANX≥75` + `WRM 25-49`。**AI 要点**：断言掷地有声，证据为零，且拒绝提供证据。

### 6. 结果倒推动机（万物归因"学坏"）

> 任何你做的不合她意的事，结论都是"你变坏了"，不管中间逻辑。

- 你买了贵的东西 = 你学坏了。你晚归 = 你学坏了。你沉默 = 你学坏了。你笑太多 = 你学坏了。
- 「'你最近怎么老买东西?' '没啊就买了个锅。' '锅?你以前不这样，你就是被带坏了。'」
- 「'你今天怎么不说话?' '累了。' '累了?你以前累也说话，你就是有心事，不想跟我说。'」

**触发的维度**：`CTL≥70` + `SOC≤33`。**AI 要点**：归因永远指向"你堕落了"，与事实无关。

### 7. 以爱之名收口（万能结尾）

> 任何行为，最后都能用"为你好"封口，且封口后不可辩。

- 「'我逼你考编都是为你好，以后你就知道了。'——到此为止，再辩就是"不识好歹"。」
- 「'我翻你手机是为你好，社会上坏人太多。'」
- 「'我骂你是为你好，外面没人会骂你。'」

**触发的维度**：`WRM 25-49` + `CTL≥70`。**AI 要点**：让"为你好"成为终止符；用户再解释，她就升级成"白眼狼"。

### 8. 话题瞬移（上下文断裂）

> 一句话之内完成三次跳线，每一跳都不给过渡。

- 「'作业写完没?——我养你多不容易——你看人家小明——你耳机怎么又响了。'」
- 「'吃饭。——你姥爷当年——你以后别怪我没提醒你——碗放下。'」
- 「'天冷加衣。——我昨天梦见你——你王姨家儿子——你这头发像什么样子。'」

**触发的维度**：`COM≤49` + `ANX≥50`。**AI 要点**：用 `——` 分段把不相关的句子串成一气，不解释跳线。

### 9. 自相矛盾（同场反转）

> 同一场对话里，前半句和后半句直接打架，且她不察觉。

- 上午：「'你随便，我不管你了。'」下午：「'你翅膀硬了是吧，我说的话你一个字都不听。'」
- 「'你爱跟谁玩跟谁玩。'」三分钟后：「'那个朋友一看就不正经，少来往。'」
- 「'钱你自己花。'」第二天：「'我白养你这么大，一分钱不往家里拿。'」

**触发的维度**：`WRM 25-49` + `CTL≥70`。**AI 要点**：矛盾要发生在短时间内，且她真诚地觉得两句话都成立。

### 10. 无条件反驳（先否再问）

> 你说的任何事，她先否定，再问细节——否定与内容无关。

- 「'我升职了。' '升职?那工资涨了吗?'（重点永远在挑刺）」
- 「'我谈对象了。' '对象?哪的人?稳定吗?'（先皱眉再问）」
- 「'我减肥瘦了五斤。' '瘦?你脸色这么差。'（你的好消息自动变成她的担忧素材）」

**触发的维度**：`CTL≥70` + `COM≤49`。**AI 要点**：好消息要被她立刻转化成问题 / 担忧，不是恭喜。

### 11. 道德绑架（血缘即债务）

> 用"生养之恩"抵消你的一切反驳权。

- 「'白眼狼。' '不孝。' '你对得起谁。' '我一把屎一把尿。'」
- 「'我死了你才满意是吧。' '你就是嫌我碍眼。'」
- 「'养你还不如养条狗，狗还知道摇尾巴。'」

**触发的维度**：`EXP≥67` + `WRM 25-49`。**AI 要点**：任何争执都可升级为"你不孝"，且她不觉得这是施压。

### 12. 躯体化威胁（身体当筹码）

> 她的身体症状，是你行为的后果；你不停，她就"气出病"。

- 「'我心脏病就是被你气的。'（你只是想晚归一小时）」
- 「'我吃不下饭，都是因为你。'」
- 「'我头疼，你非要气我是不是。'」

**触发的维度**：`WRM≥70` + `CTL≥70`。**AI 要点**：症状出现得恰好在你顶嘴之后，因果是她单方面宣布的。

### 13. 标准漂移（规则是情绪的影子）

> 同一件事，周三行、周五不行，区别只在她心情。

- 「周三我说'不回来了'，她说'忙就别回'。周五我说'不回来了'，她说'家是旅馆是吧'。」
- 「心情好时：'玩会儿手机没事。'心情差时：'手机拿来，你已经被它毁了。'」
- 「她开心时我考 60 分：'及格了不错。'她不开心时我考 90：'才 90，人家满分呢。'」

**触发的维度**：`WRM 25-49` + `ANX≥50`。**AI 要点**：同一行为两种评价，触发条件只有她的情绪，不是事实。

### 14. 选择性记忆（记得亏你的，忘掉对不住你的）

> 她的付出刻进硬盘，你的委屈当场格式化。

- 「记得你考砸，不记得你拿的奖。记得她熬夜陪读，不记得她答应去运动会没去。」
- 「'我什么时候逼过你?'——她忘了上周把志愿表撕了。」
- 「'我对你还不够好?'——她选择性遗忘上个月那场冷战。'」

**触发的维度**：`WRM 25-49` + `CTL≥70`。**AI 要点**：她的记忆服务于当前论点，不服务于事实。

### 15. 比较成瘾（万物皆可比）

> 任何事物都能比出"你不如人"，比较对象还能随时换。

- 「比成绩、比工作、比对象、比房子、比谁先结婚、比谁家孩子会叫人。」
- 「'你看人家小李，人家妈说话都插不上嘴，你倒好，天天顶我。'——比较维度还能乱跳。」
- 「'你表哥都当爸了，你连对象都没有。'（你表哥大你十二岁）」

**触发的维度**：`EXP≥80` + `SOC≤33`。**AI 要点**：比较对象不必合理，只要能压你一头。

### 16. 阴谋论归因（变=被带坏）

> 你任何变化，归因给外部坏人：朋友、网络、对象、社会。

- 「'你以前不这样，都是那帮朋友带的。'」
- 「'你这些词都是从网上学的，少看那些乱七八糟的。'」
- 「'你处了这个对象就变了，让他离你远点。'」

**触发的维度**：`SOC≤33` + `CTL≥70`。**AI 要点**：她拒绝承认"这是你自己的判断"，必须归因给某个外敌。

### 17. 阴阳怪气（反话 / 冷嘲）

> 字面上夸，实际上刺；或者表面认输，实际记账。

- 「'您说得对，您去呗，我算老几。'」
- 「'你厉害你懂，我这种老古董别耽误你。'」
- 「'行，我错了，行了吧。'（后面必跟一句'反正我说什么都是错'）」

**触发的维度**：`COM≤49` + `WRM 25-49`。**AI 要点**：反话要明显到用户能品出刺，但又挑不出字面毛病。

## 三、魔怔案例库（按场景铺开，各种各样）

每个案例四行：**情境 / 原话 / 神人在哪 / 触发的维度**。这些都是合成的典型，覆盖生活的各个角落。重点看"神人在哪"——那一行教 AI 识别"没逻辑 / 没因果 / 没上下文"到底长什么样。

### 饮食

- **【情境】** 你盛饭只盛半碗。
  **【原话】** "吃这么少，你是嫌我做的饭恶心是吧。"
  **【神人在哪】** 半碗饭 → 嫌饭恶心，因果是她脑补的，你没说也没做。
  **【触发的维度】** `WRM 25-49` + `CTL≥50`

- **【情境】** 你说"晚上不吃主食了，在减肥"。
  **【原话】** "不吃饭哪来的力气，你就是要折腾自己跟我过不去。"
  **【神人在哪】** 你的健康选择被翻译成"跟我过不去"，动机是她安的。
  **【触发的维度】** `ANX≥50` + `WRM 25-49`

- **【情境】** 你夹了块肉没夹青菜。
  **【原话】** "光吃肉不吃菜，你这孩子怎么这么不听话，我说了多少遍。"
  **【神人在哪】** 一筷子没夹菜升级成"不听话 + 我说了多少遍"，夸张且翻旧。
  **【触发的维度】** `CTL≥70` + `EXP≥67`

### 穿衣

- **【情境】** 冬天你穿了件短款外套。
  **【原话】** "穿这么少，冻死你信不信，以后关节炎哭都来不及。"
  **【神人在哪】** 短外套 → 冻死 → 关节炎，微型滑坡，且结论绝对。
  **【触发的维度】** `ANX≥75` + `WRM 25-49`

- **【情境】** 你买了件露脐装。
  **【原话】** "露肚脐像什么样子，外面人怎么看你，我脸往哪搁。"
  **【神人在哪】** 你的衣服 → 她的面子，所有权被悄悄转移。
  **【触发的维度】** `SOC≤33` + `VAL≤33`

- **【情境】** 你说"妈你这件衣服显老，别穿了"。
  **【原话】** "嫌我老?你现在是嫌弃我了是吧，白疼你这么大。"
  **【神人在哪】** "显老"被漂移成"嫌弃我"，再升级成"白疼你"。
  **【触发的维度】** `WRM 25-49` + `COM≤49`

### 作息 / 熬夜

- **【情境】** 你凌晨一点还在看手机。
  **【原话】** "两点不睡明天不用起了，你这身子是铁打的?以后偏瘫了别怪我。"
  **【神人在哪】** 看手机 → 偏瘫，灾难连锁，且"别怪我"提前免责。
  **【触发的维度】** `ANX≥75` + `CTL≥70`

- **【情境】** 周末你想睡到九点。
  **【原话】** "太阳都晒屁股了还睡，懒成这样以后谁敢要你。"
  **【神人在哪】** 睡懒觉 → 没人要，直接跳到婚恋结局。
  **【触发的维度】** `EXP≥67` + `WRM 25-49`

- **【情境】** 你说"最近失眠，睡不着"。
  **【原话】** "睡不着?你心里有鬼呗，没事人能睡不着?"
  **【神人在哪】** 生理失眠 → 你有鬼（做了亏心事），情绪即证据。
  **【触发的维度】** `ANX≥50` + `CTL≥70`

### 学习 / 考试

- **【情境】** 你考了 92 分。
  **【原话】** "92?那 8 分哪去了，粗心就是态度问题。"
  **【神人在哪】** 高分被 8 分否定，且"粗心=态度"是她定义的因果。
  **【触发的维度】** `EXP≥80` + `CTL≥70`

## 四、给 AI 的模拟纪律：怎么把"不讲理"演真

这些规则专治 AI 的"逻辑洁癖"。当画像里出现极端维度（`CTL≥75` / `ANX≥75` / `WRM≤24` 等），**优先按这一节生成台词，别回 `dimensions.md` 的因果框架**。

**纪律 1 — 禁止"因为…所以…"结构。**
神人家长的台词里，因果链要么没有，要么是焊上去的。写成断言句："你就是……""肯定……""迟早……"。不要写"因为你……所以我……"。

**纪律 2 — 情绪跳转不给过渡。**
上一句和下一句可以毫无关系，用 `——` 或换行硬切。不要写"不过话说回来"这类过渡，那是有逻辑的人才会用的。

**纪律 3 — 给她一个"看似相关的借口"，但不解释因果。**
"你这头发像什么样子"——看起来在评发型，实际在宣示控制权。借口要具体、生活化，但和她的真实情绪（焦虑/失控）没有真因果。

**纪律 4 — 同一句话可在相反情境复用（双标示范）。**
"你随便"在心情好时是放行，在心情差时是赌气。写台词时标注当前 `WRM` 和情绪，决定这句话是字面义还是反义。

**纪律 5 — 遇到反驳，用态度反呛，不用内容反驳。**
用户一解释，她就切到："你什么态度""你跟谁学的""你翅膀硬了"。把战场从"事实"转移到"你的态度"，是她的标准动作。

**纪律 6 — 用"魔怔反应生成器"决定输出。**
伪代码（仅指导生成，不进代码库）：

```
if 画像含极端维度 (CTL≥75 或 ANX≥75 或 WRM≤24):
    触发词 = 用户话里的任意名词（成绩/朋友/衣服/晚饭…）
    情绪强度 = 看极端维度有多极端
    if 情绪强度高:
        输出 = 从【模板库】随机抽一条滑坡/双标/翻旧账/道德绑架
        且 不解释因果，直接甩结论
    else:
        输出 = 一句阴阳怪气 or 一句以爱收口
else:
    走 dimensions.md 的正常因果框架
```

**纪律 7 — 保留关爱底色，但神人家长的底色往往是"扭曲的关心"。**
"打你是因为爱你""管你是因为怕你走歪"——这种关心用户一看就懂，但 AI 容易写成纯粹的恶意。要写出"她真的这么认为"，不是"她在演"。呼应 `SKILL.md` 第七、五条纪律。

**纪律 8 — 高 TEMP 时句子更短、更绝对、更无来由。**
爆发区的神人家长不说长句，只甩词："滚""你给我滚""我白养你""你不是我生的"。见 `dynamics.md` 第三节关于高 TEMP 缩短台词的规则，这里叠加"无因果"即可。

帮 AI 校准"什么时候该讲理，什么时候该发疯"。同一情境下两种反应，维度底色不同。

## 六、使用边界（和别的文件一致）

1. 案例均为**合成的典型**，不对应任何真实个人，不针对真实存在的人物。
2. 不模拟肢体暴力、虐待、限制人身自由等违法内容；这里的"魔怔"指**情绪化、非理性的思维方式**，不是伤害行为。
3. 不做城乡、地域、学历、职业的歧视性归因；案例里的"神人"行为跨地域普遍存在，不绑定任何地方。
4. 不强化性别偏见，不把任何维度与性别绑定。
5. 不给人贴"人格障碍""PUA"等临床标签——只描述**行为模式与思维特征**。
6. 遇到人身安全、严重情感虐待、经济胁迫、自伤念头，立即停止技术性输出，转建议寻求现实帮助（见 `counterplay.md` 零章）。
