# 对话动力学引擎

v0.3 只能出一次牌。用户问"我顶回去了，她会怎么反应"——答不上来，因为上一轮的话没在系统里留下任何东西。

这个文件补的就是状态。三个量：`TEMP`（这一刻多冲）、`BOND`（这些年攒下多少信任）、`YIELD`（她要什么才肯松口）。全部由 `references/dimensions.md` 的 10 维推导，不另设人格。

**依赖**：本文件所有输入变量（CTL/WRM/INV/ANX/COM/VAL/FIN/EXP/SOC/IND）以 `dimensions.md` 为准。本文件不重新定义维度。

**取整约定**：全文四舍五入，**.5 一律进位**（2.5→3，1.425→1.43）。TEMP/BOND/YIELD 取整数，K/D 保留两位小数。不这么规定的话不同人手算会差一度，对不上账。

**本文件是可执行规格，不是说明文档**。第四~七节的每一条规则都在 `scripts/profile.py` 里有实现，第二节速查表和 7.2 的五轮推演在 `scripts/test_profile.py` 里逐值钉成断言。改这里的任何数字，先跑一遍测试看它炸在哪：

```bash
python3 scripts/profile.py --simulate-demo    # 复现 7.2
python3 scripts/test_profile.py               # 全量对账
```

## 一、三个状态量

| 量 | 范围 | 含义 | 生命周期 |
|----|------|------|---------|
| `TEMP` | 0-100 | 情绪温度。0 平静，100 爆发 | 单次对话内变化，对话结束后回落到基线 |
| `BOND` | 0-100 | 关系账户。长期信任余额 | **跨对话累积**，需要显式存档 |
| `YIELD` | 0-100 | 让步阈值。分数线，不是状态 | 静态，由画像决定 |

另有三个静态系数，从画像一次算出，全程不变：

| 系数 | 作用 |
|------|------|
| `K` 升温增益 | 雷区伤害的放大倍率 |
| `D` 降温效率 | 破冰话的折扣率 |
| `COOL` 自然冷却 | 每轮末自动扣的度数 |

### 1.1 预备量

两个中间值，因为 `WRM` 和 `INV` 都是**两头都不好、中段最优**的轴（见 dimensions.md 第三节）。

```
WRM_eff = 100 − |WRM − 62|
INV_eff = 100 − |INV − 62|
```

`WRM_buffer` 查表，不用公式：

| WRM | 0-24 冷漠 | 25-49 理性 | 50-74 温暖 | 75-100 溺爱 |
|-----|----------|-----------|-----------|------------|
| buffer | 0 | 5 | 15 | 8 |

溺爱段 buffer 只有 8，不是 15——溺爱的家长照样炸，只是炸的形式是哭不是吼。

### 1.2 TEMP 初始值

```
TEMP₀ = 0.25×ANX + 0.15×CTL + 0.10×EXP − WRM_buffer − 0.10×COM
       clamp 到 [5, 60]
```

ANX 权重最大——**开场就绷着的人，绷的是对未来的想象，不是眼前这件事**。COM 是负项：一个会先问后说的家长，起手温度天然低。

### 1.3 升温增益 K

```
K = 1 + (ANX − 50)/100 + (CTL − COM)/200
    clamp 到 [0.6, 1.8]
```

`CTL − COM` 这个差值是关键。CTL=70/COM=70 的家长（假民主）和 CTL=70/COM=15 的家长（说一不二）控制欲一样强，但后者一句顶撞就能点着，前者会先跟你聊四十分钟。

**耦合修正**（叠加在 K 上，条件出自 dimensions.md 第七节）：

| 条件 | 修正 |
|------|------|
| `INV≤20` 且 `COM≤24` 且 `CTL≥25` — 诈尸式 | K **+0.25**。没有铺垫的干预，起手就是高档 |
| `ANX≥75` 且 `FIN≤33` — 焦虑无处释放 | K **+0.10** |
| `CTL≥70` 且 `WRM≥70` — 甜蜜的窒息 | K **−0.15**，但 BOND 伤害 **×1.5** |
| `COM≥75` 且 `CTL≥75` — 假民主 | K **−0.30**，且让步判定强制走假让步 |
| `WRM≤20` 且 `INV≤20` | TEMP 上限锁 **35**（见第七节反套路） |

### 1.4 降温效率 D

```
D = 1 + (COM − 50)/200 + (WRM_eff − 80)/200
    clamp 到 [0.6, 1.4]
```

### 1.5 自然冷却 COOL

```
COOL = 5 + COM/20 − ANX/20    四舍五入取整，clamp 到 [1, 10]
```

高焦虑的人自己冷不下来，因为她在你走开之后还在脑子里继续吵。

### 1.6 BOND 初始值

```
BOND₀ = 0.40×WRM_eff + 0.25×COM + 0.25×INV_eff + 0.10×(100 − CTL)
```

只有**首次**为某个家长建档时用这个公式。之后 BOND 从存档读，公式不再介入。

### 1.7 YIELD 让步阈值

```
YIELD = 0.35×CTL + 0.25×EXP + 0.15×(100−COM) + 0.15×(100−VAL) + 0.10×(100−IND)
```

权重和为 1，所以结果天然落在 0-100。CTL 和 EXP 是正项——**越想控制、要求越高，松口的代价越大**；COM、VAL、IND 反着算。

## 二、算例（可验算）

### 算例 A：强势家长（dimensions.md 锚点）

`CTL:92 WRM:18 INV:60 ANX:60 COM:10 VAL:15 FIN:45 EXP:88 SOC:15 IND:12`

```
WRM=18 → WRM_buffer = 0，WRM_eff = 100−|18−62| = 56
INV=60 → INV_eff = 100−|60−62| = 98

TEMP₀ = 0.25×60 + 0.15×92 + 0.10×88 − 0 − 0.10×10
      = 15 + 13.8 + 8.8 − 0 − 1 = 36.6 → 37

K = 1 + (60−50)/100 + (92−10)/200 = 1 + 0.10 + 0.41 = 1.51

D = 1 + (10−50)/200 + (56−80)/200 = 1 − 0.20 − 0.12 = 0.68

COOL = 5 + 10/20 − 60/20 = 5 + 0.5 − 3 = 2.5 → 3

BOND₀ = 0.40×56 + 0.25×10 + 0.25×98 + 0.10×8
      = 22.4 + 2.5 + 24.5 + 0.8 = 50.2 → 50

YIELD = 0.35×92 + 0.25×88 + 0.15×90 + 0.15×85 + 0.10×88
      = 32.2 + 22 + 13.5 + 12.75 + 8.8 = 89.25 → 89
```

读法：起手就在**施压区**（37），一句雷区话乘 1.51 直接进爆发；破冰打六八折；要她真让步得攒够 89 分说服力——这个分数在一次对话里基本攒不出来。对这种画像，正确目标不是"说服"，是"不掉 BOND 地拖到下一次"。

### 算例 B：开明家长

`CTL:38 WRM:65 INV:60 ANX:38 COM:85 VAL:80 FIN:55 EXP:50 SOC:78 IND:75`

```
WRM=65 → buffer = 15，WRM_eff = 100−3 = 97
INV=60 → INV_eff = 98

TEMP₀ = 0.25×38 + 0.15×38 + 0.10×50 − 15 − 0.10×85
      = 9.5 + 5.7 + 5 − 15 − 8.5 = −3.3 → 5（触底）

K = 1 + (38−50)/100 + (38−85)/200 = 1 − 0.12 − 0.235 = 0.645 → 0.65

D = 1 + (85−50)/200 + (97−80)/200 = 1 + 0.175 + 0.085 = 1.26

COOL = 5 + 4.25 − 1.9 = 7.35 → 7

BOND₀ = 0.40×97 + 0.25×85 + 0.25×98 + 0.10×62
      = 38.8 + 21.25 + 24.5 + 6.2 = 90.75 → 91

YIELD = 0.35×38 + 0.25×50 + 0.15×15 + 0.15×20 + 0.10×25
      = 13.3 + 12.5 + 2.25 + 3 + 2.5 = 33.55 → 34
```

同一句"我不想卷了"，控制型 ×1.51、民主型 ×0.65，差 2.3 倍。YIELD 34 意味着两三条硬信息就能过线。

### 算例 C：鸡娃家长

`CTL:68 WRM:60 INV:72 ANX:85 COM:35 VAL:45 FIN:78 EXP:92 SOC:50 IND:45`

```
WRM=60 → buffer = 15，WRM_eff = 98；INV=72 → INV_eff = 90

TEMP₀ = 21.25 + 10.2 + 9.2 − 15 − 3.5 = 22.15 → 22
K     = 1 + 0.35 + (68−35)/200 = 1.515 → 1.52
D     = 1 − 0.075 + 0.09 = 1.015 → 1.02
COOL  = 5 + 1.75 − 4.25 = 2.5 → 3
BOND₀ = 39.2 + 8.75 + 22.5 + 3.2 = 73.65 → 74
YIELD = 23.8 + 23 + 9.75 + 8.25 + 5.5 = 70.3 → 70
```

注意 TEMP₀ 只有 22，比虎妈（29）还低，但 K=1.52 全表第二高。这不矛盾：**鸡娃家长平时是笑着的，一点就着**。温度低不等于安全，要看 K。

## 三、TEMP 分区与语言特征

| TEMP | 状态名 | 家长表现 | 语言特征 | 还能不能谈 |
|------|--------|---------|---------|-----------|
| 0-20 | **常温** | 在听，也在问 | 完整句，有真问句（"然后呢"），允许沉默 | 能。这是唯一能推进新提案的区间 |
| 21-40 | **绷着** | 表面平和，话开始带钩 | 出现"我跟你说"、"你先听我说完"；问句变成反问句；开始给建议而不是问情况 | 能，但每句话都在被记账 |
| 41-60 | **施压** | 同一个论点反复说 | 同一句话说三遍；引入外部对比（"你表哥""隔壁小陈"）；开始下条件和期限 | 勉强。她已经不在收集信息，在找你的口子 |
| 61-84 | **情绪化** | 从谈事变成谈态度 | 句子掉到十个字以内；话题从"这件事"漂到"你这个人"；开始翻旧账（三年前那次）；出现"我白养你了"这类总账 | 基本不能。你说什么都会被读成态度问题 |
| 85-100 | **爆发** | 不再处理你说的内容 | 不接你的话头；最后通牒；断绝式表述；或者直接物理离场——挂电话、摔门、进屋不出来 | 不能。此区间只有止损，没有推进 |

**三个跨区信号**（生成对话时必须演出来，这比数字更重要）：

- **越过 40**：她不再问问题了。往前翻，如果她连续两句都不是疑问句，温度已经过 40。
- **越过 60**：主语从"这件事"变成"你"。"这个不稳定" → "你这个人就是不稳定"。
- **越过 85**：她开始说"你"的定语（"你这种人""你们这代人"），或者说时间（"我这辈子""从小到大"）。范围一旦拉大到人生尺度，已经在爆发区。

**爆发区不等于音量大**。`WRM≤24` 的家长爆发是极冷的短句和挂断，`WRM≥75` 的家长爆发是哭和"我不活了"式的躯体化。同一个 TEMP=92，演法完全不同。

## 四、升温 / 降温词条表

### 4.1 计算规则

```
升温：Δ = (基础Δ + 单条最高维度加成) × K × BOND升温系数    四舍五入
降温：Δ = (基础Δ + 单条最高维度加成) × D × BOND破冰系数    四舍五入
```

四条硬规矩：

1. **维度加成只取最高的一条，不叠加**。一句话再敏感也只算最痛的那个点。
2. **单轮净升温封顶 +35，净降温封顶 −30**。一句话不能把人从 0 送到 100。
3. `TEMP ≥ 85` 时，**只有标 `[高温]` 的破冰条目生效，且效果 ×1.5**；没标的条目不但无效，还按"爆发区说理反噬 **+10**"处理。
4. **同一条破冰在同一次对话里第二次用，效果 ×0.5；第三次起 ×0**。她听出来这是话术了。

BOND 系数：

| BOND | 升温系数 | 破冰系数 | 说明 |
|------|---------|---------|------|
| ≥75 | ×0.8 | ×1.2 | 有余额可以透支 |
| 41-74 | ×1.0 | ×1.0 | 常态 |
| 21-40 | ×1.15 | ×0.8 | 每句话都在旧伤口上 |
| ≤20 | ×0（改走冷处理） | ×0.5 | 见 5.3 |

**C13 是全表最不起眼也最实用的一条**。八个字打断情绪循环，没有立场，不能被反驳。爆发区往往就靠它撑到自然冷却。

## 五、状态转移

### 5.1 每轮末的自然冷却

```
本轮 TEMP 净上升  →  扣 COOL/2（向下取整），最小扣 1
本轮 TEMP 净下降或持平  →  扣 COOL 全额
TEMP 结果 clamp 到 [0, 100]
```

怒气有惯性。刚被顶完那一下，她冷不下来。

### 5.2 TEMP 对 BOND 的溢出伤害

TEMP 是会退的，BOND 不会。这是引擎里唯一不可逆的部分。

| 触发 | BOND |
|------|------|
| 单轮结束时 TEMP ≥85 | **−5** |
| 单轮结束时 TEMP ≥95 | **−8**（取代上一条，不叠加） |
| 本次对话中 TEMP 进入 61+ 的轮次 ≥3 | 对话结束时额外 **−3** |
| 非当面（电话／微信） | 上述所有 BOND 扣减 **×1.2**，见第八节 |
| 触发 T2 / T14 / T18（否定其付出、扯夫妻关系、否定既往安排） | 额外 **−3**，无论 TEMP 多少 |
| 破冰把 TEMP 从 85+ 拉回 40 以下 | **+3** |
| 达成真让步 | **+4** |
| 达成假让步 | **−2**（你会发现，她也知道你会发现） |
| `CTL≥70` 且 `WRM≥70`（甜蜜的窒息） | 上述所有 BOND 扣减 **×1.5** |

**"单轮结束时"指自然冷却之后**，不是升温刚落地那一刻。顺序固定为：出牌 → 加减 TEMP → clamp → 冷却 → **按此刻的 TEMP 结算 BOND**。不写死这一条，同一轮会算出两种 BOND（一句话把温度打到 96、冷却后 92，到底扣 8 还是扣 5），两个人手算就对不上账。`61+ 轮次`的计数同样按冷却后的轮末值。

**BOND 的自然恢复**：无冲突接触，每周 +1，上限回到 `BOND₀`。不能超过初始值——这个引擎不模拟关系变好，只模拟关系损耗和修复。想演关系改善，改画像，别改 BOND。

### 5.3 BOND 分段的行为切换

| BOND | 模式 | 表现 |
|------|------|------|
| ≥75 | 有余量 | 吵完能当天翻篇。会主动说"刚才我说重了" |
| 41-74 | 常态 | 吵完各自沉默半天，第二天用一顿饭找补 |
| 21-40 | 交易化 | 只谈事务——钱、证件、老家的房子、亲戚的事。不谈感受，不问近况。电话不超过五分钟 |
| ≤20 | **冷处理** | TEMP 上限锁死在 40。不再有情绪输出 |

**冷处理模式是这个引擎里最难破的状态，不是爆发。**

BOND ≤20 时家长的全部表现是："嗯。""知道了。""你忙吧。"——不追问，不反对，不生气。你说要辞职，她说"哦"。你说要搬走，她说"行"。

它难破在于**没有可以回应的对象**。爆发至少给你一个明确的靶子，冷处理连靶子都收走了。此状态下所有破冰条目效果 ×0.5，且单次接触最多回 +1 BOND。要出来只能靠**次数**：连续多次低强度、无所求的接触（不谈正事，只是打个电话说今天吃了什么），一次 +1，慢慢爬回 21。

生成时不要给冷处理模式的家长写长台词。她的台词就应该短到让人难受。

## 六、让步判定

### 6.1 说服力累计 PERSUADE

一次对话内累计，对话结束清零（**不跨轮存档**——这次没说服，下次得重来一遍）。

| 来源 | 加分 |
|------|------|
| 每次生效的破冰条目 | + 实际降温值的绝对值 |
| C3 首次给出明确期限 | +10 |
| C2 或 C16 首次给出可核查的钱的方案 | +12 |
| C7 首次引入她信任的第三方 | +10 |
| C14 首次让渡决定权 | +8（最多计 2 次） |
| C9 首次解决面子问题 | +10（`SOC≤33` 时 +15） |
| 已成事实无法更改（T12） | +15，但同时 BOND −3 |
| **TEMP ≥85 时说的任何道理** | **+0，不计**。她没听见 |

### 6.2 判定表

按顺序匹配，命中即停：

| 条件 | 结果 |
|------|------|
| `BOND ≤ 20` | **冷让步**——"随你便"。不是让步，是断连 |
| `COM≥75` 且 `CTL≥75`（假民主） | **强制假让步·条件型**，无论 PERSUADE 多高 |
| `PERSUADE ≥ YIELD` 且 `TEMP ≤ 35` 且 `BOND ≥ 35` | **真让步** |
| `PERSUADE ≥ YIELD` 且 `TEMP > 35` | **假让步·休战型** |
| `YIELD×0.6 ≤ PERSUADE < YIELD` 且 `TEMP ≤ 40` | **假让步·拖延型** |
| 其余 | **不让步**（可以是休战，但不是让步） |

`TEMP ≤ 35` 这个门槛是硬的。**气头上说的同意一律不算。**

### 6.3 真让步长什么样

只有一个可靠信号：**她开始问细节。**

```
「那你社保怎么办，断了以后买房子有影响。」
「房租一个月多少，什么时候到期。」
「你那个……账号，是要交税的吧？」
「我跟你爸怎么说。」
```

问细节 = 她已经在你的方案里做规划了。真让步还伴随三个附加动作：

- 主动提出具体的帮助（不是"要钱说话"这种客气话，是"我下周去给你问问那个"）
- 主动去跟家里其他人解释（她开始替你挡了）
- 隔天不翻案。翻案是假让步的定义特征

### 6.4 假让步的四种形态

**中国式家长的"行行行你自己看着办"，十次有八次不是同意。**

| 形态 | 台词 | 识别 | 通常什么时候翻 |
|------|------|------|--------------|
| **休战型** | 「行行行，你自己看着办。」「我说什么你都听不进去，我不说了。」 | 同意之后不问任何细节，立刻转移话题或起身走开 | 3 天内。而且多半不是她本人开口，是你爸／奶奶／某个姨突然打来电话 |
| **拖延型** | 「这事再说吧。」「过完年再讲。」「你先干着，不着急。」 | 既不否定也不同意，给出一个模糊的时间点 | 到时间了就换个理由再拖一次 |
| **条件型** | 「可以，但你得先……」「行，那你把 X 办了我就不管。」 | 附加条件的完成难度远高于原议题 | 不用翻，条件本身就是拒绝 |
| **行为型** | （嘴上完全同意，什么也不说了） | 转头去联系你的领导／对象／同学／中介 | 你从第三方口中得知的时候 |

**行为型是 `INV≥75` 的专属**。dimensions.md 里"过度介入"这一档的定义就是直接联系你的老师和同事——她不需要跟你争，她有别的接口。

### 6.5 一句话验真

同意之后，**她接下来问的第一句话是什么？**

- 问细节 → 真让步
- 转移话题（"饭好了""你爸回来了"）→ 休战型
- 给时间（"以后再说"）→ 拖延型
- 提另一个要求 → 条件型
- 什么也不问 → 行为型，警戒

## 七、多轮输出格式

### 7.1 格式规范

每轮最多三行元信息。**对话是主体，数字是脚注**，不要反过来。

开局打一次头，之后不重复画像：

```
【建档】妈 · CTL72 WRM48 INV68 ANX60 COM32 VAL30 FIN58 EXP68 SOC38 IND32
        TEMP 24（绷着）│ BOND 69 │ YIELD 70 │ K 1.30 │ D 0.94 │ COOL 4
```

每轮：

```
── 第 N 轮 ─────────────────────────
你：「……」
    ▸ T9 宣布非常规路径 (25+12)×1.30 = 48 → 封顶 +35
妈：「……」
    TEMP 42 → 75（情绪化）  BOND 69  说服 0/70
```

收尾：

```
【结算】TEMP 24 → 64 │ BOND 69 → 50（−19）│ 说服 30/70
        判定：不让步
        最贵的一句：第 3 轮「这是我自己的事」
```

跨对话存档一行：

```
【存档】妈 · BOND:50 · 上次话题:辞职做自媒体 · 未结 · 2026-08-09
```

### 7.2 完整推演：「我要辞职去做自媒体」

**画像**：`CTL:72 WRM:48 INV:68 ANX:60 COM:32 VAL:30 FIN:58 EXP:68 SOC:38 IND:32`

初始值手算：

```

TEMP₀ = 0.25×60 + 0.15×72 + 0.10×68 − 5 − 0.10×32
      = 15 + 10.8 + 6.8 − 5 − 3.2 = 24.4 → 24
K     = 1 + (60−50)/100 + (72−32)/200 = 1 + 0.10 + 0.20 = 1.30

      = 34.4 + 8 + 23.5 + 2.8 = 68.7 → 69   → BOND 系数 ×1.0
YIELD = 0.35×72 + 0.25×68 + 0.15×68 + 0.15×70 + 0.10×68
      = 25.2 + 17 + 10.2 + 10.5 + 6.8 = 69.7 → 70
```

## 八、反套路警告

公式是脚手架，不是剧本。下面这些情况，**先关掉公式再演**。

**`WRM≤20` 且 `INV≤20` — 不会升温的家长。**
套 TEMP 公式一定演错。这类家长不吵，也不是在忍——她们的反应机制里就没有"升温"这一档。你说要辞职，她说"哦"；你说要搬走，她说"钥匙记得留一把"。TEMP 上限锁 35，永远到不了爆发。她们的杀伤力全在 BOND 上，而 BOND 从一开始就只有四十几分。给这类画像做推演，主轴应该是 BOND 和"她没说的那句话"，不是 TEMP。

**`COM≥75` 且 `CTL≥75` — 假民主。**
全程 TEMP 不会超过 30。她会认真听完你说的每一句，会复述你的观点，会说"你的想法我明白了"。然后结论一个字没变。**不要把低 TEMP 当成谈得顺利**——这是全表最容易被误判的画像。判定强制走假让步·条件型，无论你攒了多少 PERSUADE。识别标准只有 dimensions.md 第七节那一句：听完之后，结论变了吗？

**`CTL≥70` 且 `WRM≥70` — 甜蜜的窒息。**
TEMP 照涨，但外显完全不是吼。是眼泪、是"妈没事，你去吧"、是"我这心口一直在跳"、是第二天病了。破冰表里 C5 认小错、C6 抬对方、C10 承认依赖效果翻倍，但**每用一次 BOND 额外 −2**——因为你是在借愧疚,而愧疚要还。这类画像最容易演成"看起来和好了，其实账越欠越多"。

**`ANX≥85` — TEMP 会自己涨。**
每轮末不但不冷却，还 **+5**。没人说话她也在涨，因为灾难化推演在她脑子里自动运行。你沉默三分钟，她已经从"辞职"推到"没社保""看不起病""老了怎么办"。对这类家长，沉默不是缓冲，是燃料。C13 转具体事务要频繁用。

**丧偶式：不适用让步判定。**
YIELD 算出来 34，看起来很好说服。但他不参与决策，"让步"这个动作对他不存在。他的"行"和他的"不行"信息量一样，都是零。这类画像应该走单轮输出，不要开状态机。

**多人在场：一人一套状态。**
家里有第三方（爸、奶奶、姑姑）的时候，别用单人状态机。每人一套 TEMP。而且"当着外人"会压制外显——**外显 TEMP = 实际 TEMP − 20**，但 BOND 伤害照实际算。所以过年饭桌上看起来风平浪静的那一场，账是记在初三晚上的。

**电话／微信 ≠ 当面。**
非当面：升温 Δ ×0.8（挂断太容易，冲突不容易累积），但 BOND 伤害 ×1.2（挂断本身就是伤害）。微信文字再打八折，但**已读不回等同 T11 沉默不答**。

**特殊时期先手调，别套公式。**
家里刚有人过世、她刚失业、体检出了问题、过年、你哥的事刚闹完——这些时候手动改 TEMP₀ 和 BOND，写清楚为什么改。公式不知道这些。

**别把 TEMP 100 演成暴力。**
上限行为是：不接话、最后通牒、挂电话、摔门、进屋不出来、几天不说话。不是动手。这条不是风格建议，是硬边界（SKILL.md 第八节）。

**用户只问一句的时候，别开状态机。**
"我妈会怎么说"——给一轮就够了。这套引擎是给"我顶回去了，然后呢"用的。上来就摆一堆 TEMP/BOND/YIELD 是自嗨。数字应该在需要解释"为什么她突然不说话了"的时候才出现。

**最后一条：所有爆发的底下都得留着关爱。**
第 4 轮那句"你辞了以后别跟我提钱"，翻译过来是"我怕你没钱了不敢跟我说"。演的时候可以不点破，但生成的时候心里要有——**没有这层，这个 skill 就只是个吵架模拟器**。
