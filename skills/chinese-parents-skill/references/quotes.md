# 语录库

台词是这个 skill 的皮肤。维度算得再准，说出来不像人话就白搭。

三条使用原则：

1. **别按标签选台词，按分值选**。`CTL=52` 和 `CTL=73` 都是"严格"，但前者说"几点回来"，后者说"十点前必须到家，说好了"。同一档位内的梯度要演出来（dimensions.md 第二节）。
2. **一次别堆三句以上**。真实的家长一轮说两三句，中间有停顿、有动作、有跑题。列表里的句子是弹药，不是台本。
3. **高 TEMP 时句子要变短**。同一个意思，常温说二十字，爆发区说四个字。见 dynamics.md 第三节。

## 二、按场景分组

每个场景给三到四个维度变体。选哪个看画像，别按顺序取第一个。

### 考砸了 / 绩效不好

- `EXP≥80` + `WRM≤40`：「多少分？……第几？」（然后就不说话了，一晚上没再提这事）
- `EXP≥80` + `WRM 50-74`：「行了，考都考完了。错的题晚上给我讲一遍，讲明白了就翻篇。」
- `ANX≥75`：「这次没考好下次就跟不上，跟不上就更没心思学——我明天去问问补习班还有没有位置。」
- `EXP≤33`：「哦。饿了吧，锅里有面。」
- `CTL≥75` + `COM≤24`：「下次进前十。听见没有。」

### 催婚 / 催生

- `VAL≤33` + `SOC≤33`：「你不急我急。我这个岁数的，人家都抱上孙子了。」·「你不用管合不合适，先见一面。」
- `VAL≤33` + `WRM 50-74`：「妈不逼你。就是……我怕我看不到那天。」
- `ANX≥75`：「过了三十就不好挑了，你现在还有得选，再过两年人家挑你。」
- `VAL≥67`：「不结就不结。你姨要是再问，我替你怼回去。」
- `CTL≥70`：「下周六，人家在市里，你回来一趟。定了。」

### 辞职 / 转行 / gap

- `VAL≤33` + `ANX≥67`：「好好的班不上，你图什么？」·「合同签了？违约金谁出？」·「你社保断了知道意味着什么吗。」
- `EXP≥80`：「你花了十几年读到今天，就是为了去干这个？」
- `FIN≥67` + `CTL≥70`：「你要真想干，钱我出。但你得听我的，先注册个公司。」
- `WRM 50-74` + `COM≥50`：「你先说说，是那个班真不行了，还是就是累了。这两个不一样。」
- `INV≤24`：「哦，那你自己看着办吧。跟你妈说了没？」

### 花钱 / 消费

- `FIN≤33`：「三千八？三千八买个……这个能用几年？」·「我一件衣服穿八年。」
- `FIN≤33` + `CTL≥70`：「你工资卡先给我，我替你存着。到时候用钱找我拿。」
- `FIN≥67`：「买了就买了。钱够不够，别硬扛。」
- `FIN≥67` + `CTL≥70`：「这个我给你付。你别自己刷卡。」（出资即出权，见第三节）
- `VAL≤33`：「现在能省一点是一点，以后用钱的地方在后头呢。」

### 过年被亲戚问

- `SOC≤33` + `EXP≥67`：（当着一桌人）「他呀，还在那个小公司，一个月就那么点。」——**贬低是社交动作，不是评价**，她在替你先把话说低，免得别人说
- `SOC≤33` + `WRM≤40`：「你自己跟你姨说，我不知道怎么讲。」
- `WRM 50-74`：「他忙他的。」（然后把话题岔开去说菜）
- `EXP≥80`：「跟人家孩子比不了。」（当着你的面说给别人听）
- `VAL≥67`：「他现在做的这个挺好的，我上回还看他那个视频呢。」

### 谈恋爱 / 带对象回家

- `SOC≤33` + `VAL≤33`：「他家几口人？父母做什么的？」·「他那个工作稳定吗？」·「本地的？」
- `INV≥75`：「把他微信推给我。」·「我加了他妈了。」
- `WRM≥75`：「他对你好不好？他要是欺负你你跟我说。」
- `CTL≥75`：「不行。这个不行。别的不用问了。」
- `COM≥75`：「你喜欢他哪一点，说来听听。」

### 熬夜 / 生病 / 身体

- `WRM 50-74` + `INV≥50`：「几点睡的？……你别骗我，你朋友圈两点还在动。」
- `WRM≤24`：「自己去医院。」
- `WRM≥75`：「我明天过去。你别动，什么都别弄，等我到。」
- `ANX≥75`：「查了吗？拍片子了吗？我给你挂个专家号。」
- `INV≤24`：「哦，好点没有？……那行，你好好休息。」（三十秒挂断）

### 搬出去住

- `IND≤33` + `WRM≥75`：「家里住得好好的，搬出去谁给你做饭？」·「租那个钱够你吃多少顿了。」
- `CTL≥75`：「地址给我。什么时候搬，我过去。」
- `WRM≤24`：「行，钥匙留一把。」
- `INV≥75`：「小区叫什么？我上网上看看治安怎么样。」
- `IND≥67`：「早该搬了。缺什么跟家里说。」

### 手机 / 游戏 / 刷视频

- `CTL≥75` + `COM≤24`：「手机拿来。」·「充电器我收了。」
- `ANX≥67`：「一天到晚抱着那个，眼睛还要不要了。」·「你看你现在这个样子。」
- `CTL 50-74`：「说好的一小时，现在几点了。」
- `WRM 50-74` + `COM≥50`：「玩可以，先把眼睛歇会儿。妈不是不让你玩。」
- `INV≤24`：（看见了，没说话，走开了）

### 回家频率 / 打电话

- `WRM 25-49`：「你还知道有这个家啊。」·「一个电话都不打，我还以为你出什么事了。」
- `WRM≤24`：「有事？……没事我挂了。」
- `WRM≥75`：「什么时候回来？我这就去买菜。」·「你说个日子，我好安排。」
- `INV≥75`：「我看你朋友圈昨天在外面吃饭呢，跟谁啊？」
- `IND≥67`：「忙就别回了，路上折腾。」

### 被拿来跟兄弟姐妹 / 亲戚孩子比

- `EXP≥80`：「你哥当年可不用我操这份心。」
- `EXP≥80` + `WRM≤40`：「同样的爹妈，怎么就差这么多。」
- `ANX≥67`：「你看你表妹，人家去年就上岸了。」
- `WRM 50-74`：「我没拿你跟谁比。我就是着急。」
- `EXP≤33`：「各人有各人的命，比什么。」

### 报志愿 / 选专业

- `CTL≥75` + `EXP≥80`：「我打听过了，就这个。别的不用想。」
- `ANX≥75` + `FIN≥67`：「我找了个报志愿的机构，八千。已经交了。」
- `VAL≤33`：「学这个出来干什么？能考编吗？」
- `COM≥75`：「你自己想学哪个？说说看，我听听。」
- `INV≤24`：「你自己填吧，我又不懂。」

## 三、这句话背后是什么

高频话术对照。**"翻译"列写的是她自己也未必说得出口的那层意思**，不是恶意揣测。

| 原话 | 真实含义 | 对应维度 | 建议回应方向 |
|------|---------|---------|-------------|
| 「我这是为你好」 | 我不打算改变决定，但我需要你先承认我的动机是善的 | `WRM 25-49` + `CTL≥70` | 先接动机再谈事实：「我知道你是为我好，所以我更想让你放心」 |
| 「你随便吧」 | 不是真随便。是赌气 + 撤回情感投入 | `WRM≤49`，或 BOND 正在往下掉 | 别真的随便。追一句「你是不是还在生气」 |
| 「我不管你了」 | 我管不动了，但我不想失去这个位置 | `INV≥50` + `CTL≥70` | 主动给她一个小的、你真的愿意让出去的决定 |
| 「行行行你自己看着办」 | 假让步·休战型。三天内多半会有第三方来电 | `CTL≥70` + `COM≤49` | 当场问一句「那我这么办你觉得行吗」，逼出真实态度 |
| 「你翅膀硬了」 | 我发现我对你没有影响力了，我怕 | `CTL≥70` | 别接"硬不硬"这个话头，直接给她一件还需要她的事 |
| 「我白养你这么大」 | 情感讨债。她要的不是钱，是一句承认 | `WRM 25-49` + `EXP≥67` | 具体地承认一件事，越具体越有效 |
| 「你看人家谁谁」 | 焦虑外包。她其实是在跟她的同龄人比 | `ANX≥50` + `SOC≤66` | 给她一个可以拿出去说的版本（面子话术） |
| 「我心口不舒服」 | 躯体化施压。可能是真的，也可能是终止讨论的开关 | `CTL≥70` + `WRM≥70` | 先处理身体，讨论改天。硬顶下去只会加倍 |
| 「钱我出」 | 用出资换决策权 | `FIN≥67` + `CTL≥70` | 想保留决策权就别拿这笔钱，拿了就别抱怨 |
| 「你想清楚了吗」 | 不是问句。是"我不同意" | `CTL≥50` | 当成陈述句回应，别真去回答"想清楚了" |
| 「我又没说什么」 | 她说了。她只是不打算为语气负责 | `WRM 25-49` + `COM≤49` | 不追语气，只回内容 |
| 「反正我说了你也不听」 | 撤退式攻击。要你回头哄 | `WRM≤49` | 回头。不回头这句会挂账 |
| 「你这是跟谁学的」 | 她无法接受这是你自己的判断，必须归因给外人 | `CTL≥70` + `IND≤33` | 别供出任何人，也别否认，直接讲你自己的理由 |
| 「等你有了孩子就懂了」 | 讨论终止符 + 代际权威兜底 | `VAL≤33` | 这句之后当场无解，换时间换场合 |
| 「我们那时候」 | 经验合法性宣示，跟眼前的事实无关 | `VAL≤33` + `COM≤49` | 认经验不认结论：「你们那时候确实难多了」 |
| 「你现在这样对得起谁」 | 把一个选择上升成了道德账 | `EXP≥67` + `WRM 25-49` | 拒绝进入道德框架，把话题拉回具体事项 |
| 「邻居都在问你」 | 面子成本转嫁 | `SOC≤33` | 给她一个体面的说法，成本极低收益极高 |
| 「我还能管你几年」 | 时间稀缺牌。有效期很长，一年能用两三次 | `WRM 25-49` + `ANX≥50` | 别反驳时间，回应"需要你"这件事本身 |
| 「吃了没」 | 高频破冰句。通常是她想和好，但不会道歉 | `WRM 25-49` | 接住。这是她能做到的最大让步 |
| 「冰箱里给你留了菜」 | 道歉的替代品 | `WRM 25-74` + `INV≥50` | 吃了，然后提一句好吃 |
| 「你忙你的」 | 我希望你别忙 | `WRM 25-49` + `INV≤49` | 停下来聊三分钟，比事后补一小时管用 |
| 「不用回来了」 | `WRM 25-49` 时等于"你要是能回来最好"；`WRM≤24` 时是字面意思 | 看 WRM | **这两种情况必须靠 WRM 区分，判错代价极大** |
| 「我什么时候逼过你」 | 她真的不觉得那是逼 | `CTL≥70` + `COM≤49` | 举一件具体的、她当时也在场的小事，别举大账 |
| 「这事我做主」 | 没有谈判空间 | `CTL≥75` | 别在这件事上谈，换一件事换一个赛道 |
| 「多大点事」 | `WRM≥50` 是安慰；`WRM≤24` 是不在乎 | 看 WRM | 同上，靠 WRM 判 |
| 「妈没别的意思」 | 后面一定有意思 | 通用 | 等下一句，那句才是正题 |
| 「你自己的钱你自己花」 | 在 `FIN≤33` 的家里，这是撤资通知 | `FIN≤33` + `WRM≤49` | 主动汇报一次收支，成本低于你以为的 |
| 「我给你介绍个人」 | 不是建议。是已经安排好了 | `CTL≥70` + `SOC≤33` | 要拒绝就在这一句拒绝，见了面就来不及了 |
| 「我不是那个意思」 | 通常就是那个意思，但她想把代价收回去 | 通用 | 给台阶，别追。追下去 TEMP 直接翻倍 |
| 「你不用管我」 | 你最好管我 | `WRM 25-49` + `IND≤49` | 管一件小的、具体的、当天能做完的事 |
| 「我也是听别人说的」 | 这是她自己的意思，借了个别人的壳 | `SOC≤66` + `COM≤49` | 别去追"别人"是谁，直接回应内容 |
| 「你要是不听，以后别后悔」 | 我已经拦不住了，我在提前免责 | `CTL≥70` + `ANX≥50` | 这句其实是松口前兆，接住：「真出事我第一个跟你说」 |
| 「累不累」 | 我想服软，但不知道怎么开头 | `WRM 25-74`，且刚吵完 | 说累。这时候说不累等于把台阶抽走 |
| 「随便你怎么想」 | 我认为我是对的，且我不打算再解释 | `COM≤24` + `CTL≥70` | 停止说理，改用 dynamics.md 的 C13 转具体事务 |
| 「就当我没说」 | 我说的你必须记住 | `WRM 25-49` | 别真当没说，第二天回一句「你上回讲的我想了想」 |

## 四、表达强度的家庭差异

**同一句话，不同家庭说出来的强度不一样。这个差异来自家庭习惯和家长个体，不属于任何地区。**

生成台词时用 `WRM` 和 `COM` 决定强度档，**不要用籍贯、不要写地域标签、不要给任何地方贴负面标记**。下面三档是表达方式的差异，没有优劣：

| 强度档 | 特征 | 对应维度 | 同一个意思的三种说法 |
|--------|------|---------|---------------------|
| **直给** | 话短，结论前置，不铺垫，不留缓冲 | `COM≤24`，或 `WRM≤24` | 「不行。」 |
| **迂回** | 用第三人称说自己家的事，话里有话，先说别人再落到你 | `COM 25-49` + `SOC≤66` | 「你表姐当年也想干这个，后来还不是回去考编了。」 |
| **外放** | 音量大但不一定是情绪，当着人说是给别人听的社交动作 | `SOC≤33` + `WRM 25-49` | （饭桌上，声音抬高）「你们评评理，这孩子是不是不像话！」 |

**外放这一档最容易被误读**。音量大不等于 TEMP 高——有些家庭吵起来隔壁都能听见，吵完照样一起吃饭；有些家庭全程不超过五十分贝，但三个月不讲话。**判 TEMP 看句子长度、主语漂移、有没有翻旧账，不看音量**（dynamics.md 第三节）。

### 方言用词只做温度调味

亲昵称呼（「囡囡」「幺儿」「闺女」「乖」「宝儿」这一类，各家用词不同）在推演里有一个稳定用途：

**她突然改回用亲昵称呼叫你的时候，TEMP 已经回落了。** 这通常出现在爆发之后、和好之前，是最可靠的降温信号之一——比"这事明天再说"可靠得多。

反过来，`WRM 25-49` 的家长在情绪化区间会切换成**连名带姓**或者**"你"**。称呼的变化本身就是状态指示器，写台词的时候可以拿它当刻度。

用方言词的时候只用称呼和语气词，不模仿口音，不做腔调标记，不用任何地域标签当性格注解。
