# Phrase Banks — Four Core Scenarios

> These banks hold Chinese scripts as **subject matter**, the way a grammar
> reference holds example sentences. Each entry: formula description (English),
> example scripts (Chinese + English gloss), what NOT to say, and register
> variants. All scripts must be used honestly — never to fake commitment or
> string someone along.

---

## 1. Decline (拒绝) — the sandwich

**Formula:** affirmation of the request/relationship + honest reason + an
alternative or softened door. Never a bare "no".

**Examples**

- *Declining extra work from a colleague (casual):*
  「这个事我很想帮你，不过我这周手上两个截止日期都压着，实在抽不出整块时间。要不我把之前整理的模板发你，你先照着搭，卡住了我中午帮你看十分钟？」
  *Gloss:* "I'd really like to help, but I'm up against two deadlines this week and can't carve out a solid block. How about I send you the template I used, and we can spend ten minutes at lunch if you get stuck?"

- *Declining a boss's unreasonable request (formal, pushback framing):*
  「领导，我明白这个事的重要性。我目前手上是 A 和 B 两个优先级任务，如果再接 C，三个并行我担心质量和进度都保不住。建议先聚焦 A 和 C，B 往后排，优先级您来定？」
  *Gloss:* "I understand how important this is. Right now I own A and B as priorities; if I take on C as well, I'm worried neither quality nor schedule holds across all three. I suggest focusing on A and C and pushing B back — could you set the priority?"

- *Declining a favor / loan (close):*
  「咱们这关系我不跟你客套。这笔钱数我最近真腾不出来，硬借了你我自己也周转不开。要不我先帮你问一圈有没有更合适的渠道？」
  *Gloss:* "Between us I'll be straight with you. I genuinely can't free up that amount right now; if I force it I'll be the one in trouble. Let me ask around for you for a better channel instead."

**What NOT to say (bad AI output)**

- 「这个任务无法完成。」 ("This task cannot be completed.") — bare, blunt, no face saved.
- 「抱歉，因客观条件限制，本请求暂不具备可执行性，敬请谅解。」 — stiff, bureaucratic, sounds like a bot.
- Ghosting / total silence, or 「再说吧」used deceptively to delay a real answer.

**Register variants:** formal = full honorifics + priority table; casual = direct but warm; close = drop the honorifics, be plain, still offer help.

## 2. Comfort (安慰) — observe + acknowledge + presence, NO advice

**Formula:** name the emotion you observe + acknowledge it is real + offer presence.
**Explicitly BANNED phrases:** 别难过 / 想开点 / 这有什么大不了的 / 我早就跟你说过 / 别哭了没事的. These minimize the feeling and shut the person down.

**Examples**

- *Comforting a grieving friend (close):*
  「听到这个消息我也不知道该说什么。你现在肯定特别难受吧，想说说就说，不想说我就陪你坐一会儿。」
  *Gloss:* "I don't quite know what to say hearing this. You must be in so much pain right now. If you want to talk I'm here; if not, I'll just sit with you."
  *(Note: no advice, no "everything happens for a reason", no quick fix.)*

- *Comforting a colleague who failed a pitch (casual):*
  「这次准备了你那么久，结果没成，换谁都会失落。要不要下楼喝杯东西？不聊工作也行。」
  *Gloss:* "You put so long into this and it didn't land — anyone would feel let down. Want to head downstairs for a drink? We don't have to talk work."

**What NOT to say (bad AI output)**

- 「别难过了，没事的，想开点。」 ("Don't be sad, it's fine, just look on the bright side.")
- 「这有什么大不了的，下次再来嘛。」
- 「我早就跟你说过应该……」 (starts advice + blame)

**Rule:** presence before fixing. Only offer advice if the person explicitly asks "你说我该怎么办？".

## 3. Apology (道歉) — specific behavior + impact + remedy

**Formula:** name the exact behavior + state its impact on the other person +
concrete remedy / prevention. Vague 「对不起」without specifics reads as empty.

**Examples**

- *Missing a deadline (formal):*
  「上周三答应交付的方案我晚了两天，这让你们周五的评审排期被打乱，是我的问题。我已经把终稿发你了，后续我会提前两天设一个自查节点，避免再出现这种情况。」
  *Gloss:* "The proposal I promised last Wednesday is two days late; this pushed your Friday review off schedule, and that's on me. The final draft is sent; going forward I'll add a self-check node two days ahead so this doesn't happen again."

- *Forgetting an appointment (close):*
  「昨晚把饭局忘了，让你一个人等了我半小时，真的很不好意思。今晚我请，你挑地方，下次我一定提前一小时设提醒。」
  *Gloss:* "I completely forgot last night's dinner and left you waiting half an hour — that's on me, sorry. It's my treat tonight, you pick the place, and I'll set an hour-ahead reminder next time."

**What NOT to say**

- 「对不起啊，不好意思哈。」 with no specifics and no remedy.
- 「抱歉，但当时情况是……」 (lead with excuse; it cancels the apology).
- Over-apologizing to the point of making the other person comfort *you*.

## 4. Criticism / Feedback (批评/反馈) — behavior not person + joint solving + blocker inquiry

**Formula:** talk about the observable behavior and its impact, never label the
person; frame it as a shared problem; then ask what is blocking them.

**Translation table (blunt label -> face-preserving version)**

| Blunt / AI-like (do NOT say) | Face-preserving version (say this) |
|------------------------------|-------------------------------------|
| 你不行 / 你能力不行 | 「这个任务对你可能挑战有点大，我们一起拆解一下？」 |
| 你效率太低了 | 「最近进度是不是有点紧？是不是遇到什么卡点了？」 |
| 你怎么听不懂 | 「可能是我没讲清楚，我换个方式再说一遍。」 |
| 你怎么又搞错了 | 「这两处和咱们对的口径不太一样，我们一起看下是哪里岔了。」 |

**Example (peer feedback, casual):**
「你这次交的数据里有两列和上次对不上，报表那边对了半天。是不是最近数据源换了你没同步？我们一起把口径对一下，省得后面再返工。」
*Gloss:* "Two columns in your data don't match last time and the reporting side spent ages reconciling. Did the source change and not get synced? Let's align the definitions together so we don't have to redo it again."

**What NOT to say:** person-level labels (你就是… / 你总是… / 你怎么这么…), public correction in front of others, or sarcasm.
