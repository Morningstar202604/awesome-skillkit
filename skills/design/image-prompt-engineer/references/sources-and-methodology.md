SKILL.md 暗知识 1–10 的采信纪律：图像 prompt 工程没有学术文献层，本轮调研的是**从业者指南**（工具站与工作流博客）。对这些来源的处理规则是——

> **只有 ≥2 个独立来源交叉验证的结论才写入 SKILL.md**；单一来源的数字与断言一律不采信。

## 未采信内容（采信纪律）

- 各来源中的 **百分比断言**（如"负向提示词能解决 90% 的问题""质量词提升 3 倍效果"）——无实验出处，属营销话术，一律不写入。
- 具体模型的版本号与定价（**月度级漂移**）——不写入 SKILL.md，改由 `model-dialects.md` 承载并附快照日期。
- "某参数必须设为 X"类的硬性数值（CFG=8、steps=30 等）：单一来源且随模型漂移 → 不进 SKILL.md。

## 诚实边界

本技能的暗知识来自**从业者实践共识**而非实验研究：交叉验证只保证"多个来源都这么说"，不保证"经实验证明"。凡涉及硬数字（长度上限、负向词个数），SKILL.md 统一给区间并标注为经验值。
