## W3C / WCAG 2.2

- **URL**: https://www.w3.org/TR/WCAG22/
- **Understanding docs**: https://www.w3.org/WAI/WCAG22/Understanding/
- **Quick reference**: https://www.w3.org/WAI/WCAG22/quickref/
- **License**: W3C Document License (https://www.w3.org/Consortium/Legal/2015/doc-license)
- **Extracted**: All numeric success criteria — contrast ratios (1.4.3,
  1.4.6, 1.4.11), text spacing values (1.4.12), reflow width (1.4.10),
  target size (2.5.8), focus appearance (2.4.11), error identification
  (3.3.1), labels/instructions (3.3.2), and all other AA-level requirements
  in the POUR structure.

## W3C ARIA Authoring Practices (APG)

- **URL**: https://www.w3.org/WAI/ARIA/apg/
- **License**: W3C Document License
- **Extracted**: Widget pattern roles, required ARIA attributes, and keyboard
  interaction contracts for tabs, modal dialog, combobox, menu, switch,
  listbox, treegrid, tooltip, alert/status.

- **License**: NNG content is copyright Nielsen Norman Group; facts (the 10

- **Extracted**: The exact 10 heuristic names and their core definitions.

## Material Design — Accessibility

- **URL**: https://m3.material.io/foundations/designing/structure

- **License**: Material Design is shared under the Apache 2.0 license.

- **URL**: https://developer.apple.com/design/human-interface-guidelines/accessibility
