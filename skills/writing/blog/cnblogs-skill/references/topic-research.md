## 1. 选题流程

```
1. 浏览博客园首页 → 发现高阅读量文章和热门话题
2. websearch搜索 → 获取话题的最新数据和背景
3. 分析2-3篇优秀文章 → 学习标题技巧、结构、引流方式
4. 确定差异化角度 → 找到别人没写过的切入点
5. 搜索素材 → 用数据、案例、趋势支撑文章
```

## 2. 发现热点

### 博客园首页

用 `webfetch` 抓取 `https://www.cnblogs.com/` 首页文章列表。

关注指标：
- 阅读量 > 100 的文章
- 推荐数 > 2 的文章
- 与AI/编程/就业相关的话题

### 全网搜索

用 `websearch` 搜索近期热点：

```
关键词组合：
- "博客园 热门文章 2026年8月"
- "程序员 技术热点 最新趋势 AI"
- "{具体话题} 2026年8月 最新"
```

### 热点判断标准

| 标准 | 说明 |
|------|------|
| 时效性 | 最好是本周或今天发生的事 |
| 数据支撑 | 有可引用的具体数字 |
| 痛点共鸣 | 程序员日常能感受到的问题 |
| 差异化空间 | 博客园上还没有人写过这个角度 |

## 3. 分析优秀文章

### 分析维度

| 维度 | 看什么 |
|------|------|
| 标题 | 用了什么句式？问句/数字/冲突/反直觉？ |
| 开头 | 怎么抓注意力？故事/数据/场景？ |
| 结构 | 几个章节？怎么分？有没有TL;DR？ |
| 数据 | 引用了哪些数据源？怎么呈现？ |
| 表格 | 用了几个对比表格？对比什么？ |
| 结尾 | 怎么收束？有没有要点回顾？ |
| 引流 | 标签怎么选？投了哪个分类？ |

## 4. 引流技巧总结

从优秀文章中学到的写法：

1. **标题用问句+反直觉答案**："为什么...？因为..."
2. **开头用故事/场景代入**：制造紧迫感，让读者觉得"这跟我有关"
3. **热点话题+实操角度**：不只报道新闻，教人怎么做
4. **TL;DR放最前面**：10秒内获取核心价值
5. **痛点驱动**：先抛问题再给方案
6. **对比/分类**：用表格做横向对比，读者一目了然
7. **数据密集且有出处**：不空谈，每个观点都有数字支撑
8. **结尾要点回顾**：有序列表总结全文核心
9. **标签选8个**：覆盖大词+长尾词
10. **投稿候选区**：选对网站分类，增加曝光

## 5. 差异化角度选择

### 选题矩阵

| 话题热度 | 博客园已有文章数 | 差异化难度 | 建议 |
|:---:|:---:|:---:|------|
| 高 | 少 | 低 | 最佳选择，抢首发 |
| 高 | 多 | 中 | 找新角度（如对程序员的影响） |
| 中 | 少 | 低 | 好选择，深度分析 |
| 中 | 多 | 高 | 换话题 |

### 三篇互补策略

同一热点话题可以从三个角度写系列文章：

1. **宏观方向**：技术趋势/范式演进（如"Prompt→Context→Harness三级跳"）
2. **微观痛点**：具体问题/数据揭示（如"AI代码质量危机"）
3. **行动指南**：程序员怎么应对/转型（如"Vibe Coding的幻觉"）

三篇形成完整闭环：**趋势在变 → 问题暴露 → 人该怎么转**。
