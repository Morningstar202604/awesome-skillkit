## 第 1 拍：讲

**核心结论：0.1 + 0.2 ≠ 0.3，不是数学错了，是"表示法"的问题。**

想象你在用**一把只有 3 位小数的尺子**量东西。

- 0.1 米 = 0.100 米 ✓ 能精确表示
- 0.2 米 = 0.200 米 ✓ 能精确表示
- 0.3 米 = 0.300 米 ✓ 能精确表示

这三把尺子没问题。但问题出在**二进制**（计算机的底层语言）上。

计算机不用十进制，用的是二进制（0 和 1）。就像中文和英文的表达能力不同，有些"整数"在二进制里是**无限循环小数**，永远写不完。

举两个例子：
- 十进制的 **1/3 = 0.333333...**（无限循环）
- 二进制的 **0.1 = 0.0001100110011...**（也是无限循环）

计算机只能存有限位，所以它存的是**近似值**，不是精确值。

> **一个类比**：你把一根绳子剪成三等份，每份都是 1/3。但你不可能用有限厘米的尺子精确量出 1/3 厘米——你只能近似。

所以：
- 0.1（二进制近似值）+ 0.2（二进制近似值）≠ 0.3（二进制近似值）
- 因为两个"近似值"加起来，精度误差叠加，结果偏离了 0.3 的近似值

**一句话机制**：**二进制无法精确表示 0.1 和 0.2，加法后累积误差，导致结果不等于 0.3 的二进制近似。**
