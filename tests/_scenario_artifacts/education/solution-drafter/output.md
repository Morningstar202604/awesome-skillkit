### 步骤 1：审题（已知/求）

*   **已知：**
    *   任务集 $V = \{A, B, C, D, E\}$
    *   耗时函数 $t$: $t(A)=3, t(B)=2, t(C)=4, t(D)=2, t(E)=3$
    *   依赖关系（前驱）:
        *   $A \to B$, $A \to C$ （A 是 B、C 的前驱）
        *   $B \to D$, $C \to D$ （B、C 是 D 的前驱）
        *   $D \to E$ （D 是 E 的前驱）
    *   规则：无依赖可并行；总时长 = 从开始到所有任务完成的最短时间（关键路径长度）。
*   **求：** 最小总时长 $T_{min}$

---

### 步骤 2：列式（建模）

将问题转化为**最早开始时间（Early Start, ES）**与**最早完成时间（Early Finish, EF）**的动态规划问题。

**定义状态：**
设 $EF_i$ 为任务 $i$ 的**最早完成时间**。
则：
$$EF_i = ES_i + t(i)$$
其中，$ES_i = \max_{j \in Pre(i)} \{EF_j\}$，$Pre(i)$ 是任务 $i$ 的所有前驱任务集合。若 $i$ 无前驱，则 $ES_i = 0$。

**计算顺序：** 按拓扑序依次计算（A → B/C → D → E）

---

### 步骤 3：逐步算（推导过程）

#### ① 任务 A（无前驱）
*   $ES_A = 0$
*   $EF_A = 0 + 3 = 3$

#### ② 任务 B、C（并行，依赖 A）
*   **任务 B：**
    *   $ES_B = EF_A = 3$
    *   $EF_B = 3 + 2 = 5$
*   **任务 C：**
    *   $ES_C = EF_A = 3$
    *   $EF_C = 3 + 4 = 7$
    *   *注：B 和 C 可同时开工，分别在第 5 秒和第 7 秒结束。*

#### ③ 任务 D（依赖 B 和 C）
*   $ES_D = \max(EF_B, EF_C) = \max(5, 7) = 7$
    *   *关键点：D 必须等最慢的前驱 C 完成后才能开始。*
*   $EF_D = 7 + 2 = 9$

#### ④ 任务 E（依赖 D）
*   $ES_E = EF_D = 9$
*   $EF_E = 9 + 3 = 12$

---

### 步骤 4：验算

**方法 1：枚举所有路径**
图中所有从起点到终点的路径及长度：
1.  $A \to B \to D \to E$: $3 + 2 + 2 + 3 = 10$
2.  $A \to C \to D \to E$: $3 + 4 + 2 + 3 = 12$

**关键路径**是耗时最长的路径，即路径 2 ($A \to C \to D \to E$)。
总时长 = 关键路径长度 = **12s**

**方法 2：反向检查**
*   E 在 12s 结束。
*   D 在 9s 结束，9+3=12 ✓
*   C 在 7s 结束，D 依赖 C，7+2=9 ✓
*   B 在 5s 结束，早于 C，不阻塞 D ✓
*   A 在 3s 结束，B/C 都依赖 A，3+max(2,4)=7 ✓

**结论：验算通过 ✓**
