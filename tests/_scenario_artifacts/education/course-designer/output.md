## 课程骨架

### CP1 · 概念地图：事件循环是什么
- **目标**：能用自己的话画出"同步 vs 异步"调度流程图，解释"协程""事件循环""回调"三个词的关系
- **前置**：无（仅需 Python 基础）
- **练习**：
  - 画出同步顺序执行 + 异步等待 IO 的对比图
  - 阅读一段简单 `async def` 代码，口头描述事件循环如何调度它
- **检查点判定**：能准确区分"挂起（await）"与"阻塞"，不混淆线程与协程

---

### CP2 · 核心机制：`async/await` 语法与协程对象
- **目标**：能给任意函数添加 `async/await`，解释"未 await 时协程对象为何不执行"
- **前置**：CP1（词汇基础）
- **练习**：
  - 将 3 个普通函数改写为 `async def`，观察未 await 时的输出
  - 用 `asyncio.run()` vs 手动 `loop.run_until_complete()` 两种方式运行同一协程
- **检查点判定**：能解释"协程对象是惰性的"，能写出正确的 `await` 调用

---

### CP3 · 动手应用：第一个异步函数
- **目标**：能写出一个简单的异步函数（模拟 IO），并用 `asyncio.run()` 运行它
- **前置**：CP1 + CP2
- **练习**：
  - 写一个 `async def fake_http_fetch(url)`，用 `asyncio.sleep(1)` 模拟延迟，打印结果
  - 比较顺序调用（串行）与并发调用（`await gather`）的总耗时
- **检查点判定**：能正确用 `gather`/`as_completed` 调度多个协程，观察到时间节省

---

### CP4 · 动手应用：并发多任务（核心里程碑）
- **目标**：能在给定场景里用 `asyncio.gather` / `as_completed` 并发执行多个异步任务
- **前置**：CP1 + CP2 + CP3
- **练习**：
  - 并发抓取 5 个 URL（模拟），统计成功/失败数
  - 用 `wait_for` 给单个任务加超时保护
- **检查点判定**：能写出"并发 + 超时 + 错误处理"的完整模式，不遗漏 `try/except`

---

### CP5 · 调试技能：追踪与排查常见异步 Bug
- **目标**：能通过日志/断点/`asyncio.run_debug()` 定位死锁、竞态、忘记 await 三类问题
- **前置**：CP4（必须先有 Bug 可查）
- **练习**：
  - 给一段故意有问题的代码（忘记 await / 顺序调用误以为并发）加调试，找出并修复
  - 开启 `asyncio.run_debug()` 运行有死锁的代码，读懂警告
- **检查点判定**：能识别"忘记 await 协程对象"和"在 async 函数里调用同步阻塞函数"两类经典错误

---

### CP6 · 核心机制：`asyncio` 核心 API 族
- **目标**：能解释 `Event`、`Lock`、`Queue`、`Future` 的适用场景并手写简化版
- **前置**：CP1 + CP2（理论模块，与 CP4 并行修读）
- **练习**：
  - 用 `asyncio.Lock` 实现一个线程安全的计数器（模拟生产-消费）
  - 用 `asyncio.Queue` 实现生产者-消费者模式
- **检查点判定**：能说出"Lock 解决什么、Event 解决什么"，能写出 Queue 模式

---

### CP7 · 整合实践：异步 HTTP 客户端
- **目标**：能写出一个完整的异步 HTTP 调用程序，含重试、超时、错误处理
- **前置**：CP4 + CP5 + CP6
- **练习**：
  - 用 `aiohttp`（或 `httpx.AsyncClient`）并发获取 10 个 API 端点，汇总结果
  - 添加指数退避重试 + 总超时控制
- **检查点判定**：程序能运行、能优雅处理网络错误、总耗时显著优于顺序版本

---

### CP8 · 迁移挑战：设计一个异步工具
- **目标**：能把异步思维迁移到表面上无关的场景（如并发文件处理 / 批量数据处理）
- **前置**：CP7
- **练习**：
  - **选题 A**：并发读取 100 个文件，按修改时间排序返回
  - **选题 B**：模拟一个异步任务调度器（带优先级队列）
  - 写一份 200 字的设计说明，解释为什么选异步而非多线程
- **检查点判定**：设计方案合理，代码能运行，能回答"为什么不选 threading"
