# 课程骨架：Python 异步编程（8 课时）

> 设计原则：掌握式路径，从概念到实战逐步深入；每课独立产出可判定的能力证据。

---

## 学习契约

| 字段 | 内容 |
|------|------|
| **范围** | asyncio 库 + 基础异步模式；不涵盖 aiohttp/asyncpg 等第三方库细节 |
| **级别** | intermediate（需有 Python 基础，无需异步先验） |
| **目标** | 结业时能解释并发模型区别、能用 asyncio 写非阻塞 I/O、能诊断常见死锁/竞态 |
| **约束** | 8 课时（每课约 60-90 分钟），使用 Python 3.11+ |

---

## 分课详情

### 第 1 课：事件循环与协程基础
- **前置**：Python 基础语法（函数、类、生成器）
- **目标**：
  - 能用自己的话解释"同步"与"异步"的区别
  - 能写出 `async def` 协程并理解 `await` 的语义
  - 能在 REPL 中运行简单事件循环
- **练习**：
  1. 实现一个 `sleep_and_print` 协程，打印问候语后等待 2 秒
  2. 用 `asyncio.run()` 运行 3 个协程，观察串行与并行输出差异
- **检查点**：口头解释"为什么 await 不会阻塞线程"

---

### 第 2 课：Task 与并发执行
- **前置**：完成 CP1
- **目标**：
  - 能用 `asyncio.create_task()` 并发运行多个协程
  - 能解释 Task 与协程对象的区别
  - 能处理并发任务的取消
- **练习**：
  1. 用 5 个 Task 并发模拟 5 个 HTTP 请求（用 `time.sleep` 替代）
  2. 实现任务超时取消：主任务等待某子任务超过 3 秒则取消
- **检查点**：解释"为什么不用 ThreadPoolExecutor 而用 asyncio"

---

### 第 3 课：Wait 组与 Future
- **前置**：完成 CP2
- **目标**：
  - 能用 `asyncio.gather()` 等待所有任务完成
  - 能用 `asyncio.wait()` 按条件等待（任意完成/全部完成）
  - 能手动创建和设置 Future 对象
- **练习**：
  1. 用 `gather` 聚合 3 个异步计算结果
  2. 用 `wait` 实现"第一个完成的任务决定结果"的逻辑
  3. 手动操作 Future：一个协程设置值，另一个等待
- **检查点**：对比 `gather` vs `wait` 的适用场景

---

### 第 4 课：异步文件 I/O
- **前置**：完成 CP3（Wait 组）
- **目标**：
  - 能用 `aiofiles` 异步读写文件
  - 能解释为什么 `open()` 是阻塞的而 `aiofiles.open()` 不是
  - 能批量异步处理多个文件
- **练习**：
  1. 异步读取 10 个文本文件并统计总词数
  2. 实现异步日志写入：多个协程同时写同一日志文件不冲突
- **检查点**：写出 `aiofiles` 与普通 `open` 的语义差异

---

### 第 5 课：异步网络请求
- **前置**：完成 CP4
- **目标**：
  - 能用 `asyncio.open_connection()` 处理 TCP 套接字
  - 能实现简单的异步 HTTP 客户端（用标准库）
  - 能理解 DNS 解析的异步化
- **练习**：
  1. 实现异步 TCP 回声客户端/服务器
  2. 批量异步请求 10 个 URL 并收集状态码（用 `urllib` 手动实现）
- **检查点**：画出"一次异步 HTTP 请求"的生命周期图

---

### 第 6 课：错误处理与资源管理
- **前置**：完成 CP5
- **目标**：
  - 能正确使用 `try/except` 捕获异步异常
  - 能用 `async with` 管理异步上下文管理器
  - 能实现带重试的异步操作
- **练习**：
  1. 实现一个异步函数，失败时自动重试 3 次
  2. 用 `async with` 管理异步数据库连接（模拟）
  3. 诊断并修复一个因异常未捕获导致的任务静默失败
- **检查点**：解释"为什么协程内部异常不回溯到调用方"

---

### 第 7 课：常见陷阱与调试
- **前置**：完成 CP6
- **目标**：
  - 能识别并避免阻塞调用（`time.sleep`, 同步 `open`）
  - 能诊断死锁场景并重构
  - 能用 `asyncio.wait_for` 和 `asyncio.timeout` 防止无限等待
- **练习**：
  1. 给定一段有死锁的代码，定位问题并修复
  2. 实现一个带超时的异步任务池
  3. 对比分析：什么时候该用多线程而非异步
- **检查点**：列举 3 种会导致事件循环阻塞的错误写法

---

### 第 8 课：综合项目
- **前置**：完成 CP7
- **目标**：
  - 能独立设计并实现一个异步爬虫/数据聚合程序
  - 能合理控制并发度避免被目标服务器封禁
  - 能写出结构清晰、错误处理完备的异步代码
- **练习**：
  - 项目：异步爬取某公开 API 的 100 条数据，聚合后写入 CSV
  - 要求：限速（每秒不超过 10 请求）、断点续传、进度显示
- **检查点**：提交代码 + 运行截图 + 一段文字说明设计决策
