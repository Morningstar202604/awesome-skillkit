# Style Anchor: 灵枢代码 (Lingshu Code)

**项目定位**：赛博修仙短片 · 16:9 横屏 · 3集 × 8分钟
**参考基因**：《攻壳机动队》（义体美学/哲学冷感）+《流浪地球》（重工业质感/宏观生存）

---

## 1. 色彩板 Palette

| 层级 | 色名 | HEX | 规则与纪律 |
|:---:|:---|:---:|:---|
| **主色 A** | 灵枢冷青 | `#0A2F3C` | 背景基调（阴影/空气/数据流底层）。全片不超过 60% 面积，营造"修仙"的幽冥感。 |
| **主色 B** | 工业锈蚀橙 | `#B85C38` | 中景过渡色（旧城金属/灵气泄露的光晕）。强调"废土修仙"的沧桑，禁止纯高饱和橙。 |
| **主色 C** | 义体银灰 | `#8A9A9B` | 远景/建筑材质（合金/混凝土）。低饱和、扁平化，作为画面的"画布"。 |
| **强调色** | 霓虹紫红 | `#E02B5A` | **唯一焦点色**。仅用于：①林一的眼睛/瞳孔数据化瞬间 ②核心法术（Ling-Gong）释放时的能量核心。遵循 60-30-10 法则，严禁大面积铺设。 |
| **肤色纪律** | - | - | 赛博格混血设定：林一面部保留 70% 血肉色（HEX `#D4A59A` 暖调），30% 为机械/符文覆盖。禁止将血肉部分调青或调灰，必须保持"人"的温度以对抗"机"的冷。 |

**色彩情绪字典**：
- 暖调（橙/红）= 灵气复苏、生命、危险、欲望
- 冷调（青/紫/灰）= 代码、虚空、技术、秩序
- **冲突美学**：利用青橙对比制造"道法自然"与"数据异化"的视觉张力，而非单纯的使用流行色调。

## 2. 光线 Lighting

**核心逻辑**：Practical Light（画内光源）优先，拒绝无影棚拍感。

1.  **环境光**：低照度。城市依靠全息广告、霓虹灯牌、飞行器尾灯照明。阴影浓重，细节隐藏在黑暗中（呼应《攻壳》夜间场景）。
2.  **主光方向**：
    -   **外景**：顶光或侧逆光，勾勒人物轮廓（Rim Light），强化赛博格边缘的金属反光。
    -   **内景/终端室**：来自显示屏/符箓终端的冷蓝色面光，打亮主角脸部一侧，另一侧隐入黑暗（Chiaroscuro 明暗对照法）。
3.  **灵气光效**：
    -   非普照亮光，而是**体积光（Volumetric Light）**或**粒子光雾**。
    -   施法时，光线应带有"故障艺术"（Glitch）纹理或像素化衰减效果，而非平滑的光束。
4.  **高光处理**：允许高光溢出（Bloom），但限制在霓虹区域；中间调保持克制，避免过曝导致的"塑料感"。

## 3. 材质 Materials

**矛盾并置**：古老器物感 vs. 未来科技感。

| 区域 | 推荐材质 | 禁止材质 |
|:---|:---|:---|
| **建筑/场景** | 粗糙混凝土、锈蚀钢板、湿滑沥青、苔藓（生长在电路板旁）、全息投影的噪点质感。 | 纯白墙壁、光滑无缝塑料、过度抛光的不锈钢。 |
| **服饰/道具** | 做旧防风衣（战术机能风）、半透明塑料雨衣、碳纤维法器、黄铜符箓槽、磨损的键盘/接口。 | 崭新制服、纯棉布料（缺乏质感）、高科技无磨损设备。 |
| **皮肤/义体** | 硅胶质感与金属咬合处可见螺丝/接缝；汗水、油污、血渍的细节。 | 完美无瑕的皮肤、毫无瑕疵的机械表面。 |

**触觉指令**：画面应让人感觉到"潮湿"、"冰冷"、"生锈"、"电流灼烧"。

## 4. 构图母题 Motifs

1.  **框中框（Frame within Frame）**：
    -   通过窗户、监控摄像头、破碎的屏幕、道观门洞观察角色。象征"被监视的修仙者"与"数字牢笼"。
2.  **垂直压迫感**：
    -   大量仰拍巨型建筑/巨型企业 Logo，人物渺小。体现《流浪地球》式的宏大生存压力。
3.  **对角线分割**：
    -   利用霓虹灯带、激光束、建筑边缘形成对角线构图，打破平衡，营造不安定感与动态张力。
4.  **数据覆盖现实**：
    -   前景偶尔插入半透明的 HUD 界面、滚动代码、符箓纹路，虚实叠加，暗示主角的"数据修士"视角。

## 5. 一致化规则 Consistency Rules

1.  **林一的视觉锚点**：
    -   **发型**：黑色短发，略显凌乱，右侧鬓角有一缕挑染的荧光蓝（受灵气侵蚀的数据色）。
    -   **眼部**：常态为人眼，施法或接入网络时，右眼瞳孔变为几何状的紫色光圈（强调色 #E02B5A）。
    -   **服饰**：深灰色战术夹克，领口有磨损，胸前挂着一枚老旧的玉佩（内嵌芯片）。
    -   **道具**：手中常持一根改装过的"光纤拂尘"或终端平板。
2.  **色调曲线统一**：
    -   全片采用 **Log 风格曲线**，暗部微微泛青（#0A2F3C），高光偏暖（保留 #B85C38 的余温），对比度中等偏高，避免死黑。
3.  **噪点与颗粒**：
    -   添加极轻微的胶片颗粒或数字噪点（ISO 噪音），增强"纪实感"和"粗糙的赛博风"，拒绝过度的数码锐化。
4.  **禁改清单**：
    -   林一的右眼发光特征不可移除或变色。
    -   玉佩芯片的绿光不可改为红光（红光用于敌对势力/危险信号）。
    -   全片禁止出现纯绿色调（避免《黑客帝国》既视感，除非是特定的数据流背景）。
