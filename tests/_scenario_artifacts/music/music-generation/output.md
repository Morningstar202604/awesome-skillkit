| 段落 | 时长占比 | BPM | 情绪 | 配器重点 |

## 三、BPM 参考

- **慢段**：60–80 BPM（冥想、闭关、孤独）
- **中段**：80–100 BPM（修炼积累、轻微冲突）
- **快段**：100–120 BPM（斗法、顿悟、高潮）
- **禁忌**：避免持续 140+ BPM（会偏向电子/动次打次，失去修仙的"气感"）

## 四、乐器清单

### ✅ 推荐
| 乐器 | 角色 | 备注 |
|---|---|---|
| 二胡 | 主奏旋律 | 滑音、颤音表现"气"流动 |
| 古筝 | 和声/织体 | 轮指、泛音营造空灵感 |
| 尺八 | 氛围/引子 | 气息声保留，不要修得太干净 |
| 低音大鼓/板鼓 | 节奏骨架 | 慢、重、留白，不要密集 |
| 埙/箫 | 情绪底色 | 可选，增加苍凉感 |
| 合成器 Drone | 空间感 | 低频 pad，模仿"天地气场" |

### ❌ 禁忌乐器
| 禁忌 | 原因 |
|---|---|
| 电吉他 / 失真音色 | 会带出摇滚/重金属感，破坏修仙意境 |
| 流行鼓组（4/4 强拍） | "动次打次"太现代，修仙需要"气口" |
| 铜管组（圆号/小号齐奏） | 容易变成好莱坞史诗，失去东方内敛 |
| 钢琴（主导） | 除非做极简点缀；钢琴音色偏西方学院 |
| 电子合成 Lead | 会引入赛博/科幻感 |
| 人声合唱（拉丁文/无词） | 除非明确要宗教感；中文吟唱可慎用 |
