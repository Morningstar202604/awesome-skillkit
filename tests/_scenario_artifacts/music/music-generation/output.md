# 修仙短片配乐 · Prompt 撰写指南

下面给出可直接填入网关的 prompt 模板、段落结构参数、BPM 区间与禁忌清单。按网关要求，prompt 须填满三槽位：**[风格流派] + [主导乐器] + [情绪与用途]**，段落/结构/BPM/禁忌作为附加参数透传（若网关 `params` 支持）；不支持则融合进 prompt 文本。

---

## 一、Prompt 三槽位填空（选一套套用）

### A. 入门觉醒 / 灵气复苏段
```
[风格流派]：新中式 Cinematic Ambient，融合东方玄幻电影配乐美学，慢板铺陈+骤强爆发
[主导乐器]：古琴泛音、尺八、大型混响铜钹、低弦 Pad（无鼓点起始）
[情绪与用途]：空灵→震撼，用于主角初入修仙界、灵气入体的顿悟时刻，营造"大道无声，天地骤开"的史诗感
```
**合并成网关可用 prompt 文本：**
> 新中式 Cinematic Ambient，古琴泛音与尺八主导，低弦 Pad 铺底；情绪从空灵静谧渐进至震撼爆发，用于修仙短片中主角灵气觉醒的顿悟瞬间，节奏先缓后骤起，营造大道无声、天地骤开的史诗感。

### B. 御剑飞行 / 游历段
```
[风格流派]：东方 Neo-Classical，动态速度感，弦乐群+民族吹管
[主导乐器]：京胡/二胡滑音、竹笛、弦乐群（小提琴群快弓）、定音滚奏
[情绪与用途]：飘逸迅捷、自由辽阔，用于御剑穿行云海、俯瞰仙山的游历镜头
```
**合并 prompt：**
> 东方 Neo-Classical，京胡与竹笛滑音主导，弦乐群快弓推进；情绪飘逸迅捷、自由辽阔，用于御剑飞行与云海游历镜头，营造乘风而行、天地在下的迅疾感。

### C. 斗法对决 / 高潮段
```
[风格流派]：Cinematic Orchestral × 中国打击乐，重型冲击节奏
[主导乐器]：中国大鼓/排鼓、铜管群、电吉他失真 Pad、电子 Sub-Bass、弦乐断奏
[情绪与用途]：激烈对抗、宿命对决，用于两派修士法宝交击、法术爆炸的高潮场面
```
**合并 prompt：**
> Cinematic Orchestral 融合中国打击乐，大鼓排鼓与铜管群主导，叠加电吉他失真 Pad 与 Sub-Bass；情绪激烈对抗、宿命对决，用于修士斗法高潮场面，强调法宝交击的节奏冲击与法术爆炸的声压感。

### D. 宗门静修 / 内省心境段
```
[风格流派]：Minimalist Chinese Chamber，极简留白
[主导乐器]：古筝轮指、箫、单件大提琴长音、极少量碰铃
[情绪与用途]：宁静内敛、禅意深远，用于闭关修炼、观心悟道的独白段落
```
**合并 prompt：**
> Minimalist Chinese Chamber，古筝轮指与箫主导，大提琴长音铺底；情绪宁静内敛、禅意深远，用于闭关修炼与观心悟道段落，大量留白，突出呼吸般的节奏与寂静中的张力。

## 二、段落结构与 BPM 参数表

| 段落 | 情绪曲线 | BPM 区间 | 推荐时长占比 | 关键动机 |
|---|---|---|---|---|
| **引子 Intro** | 空 → 微动 | 40–60 | 15% | 单音古琴/箫，泛音点缀，留白多 |
| **铺垫 Build** | 渐强 | 60–80 | 25% | 弦乐 Pad 进入，古筝轮指，低音持续 |
| **主题 Theme** | 舒展/壮阔 | 80–100 | 30% | 主旋律乐器（笛/胡/合成 Lead）完整呈现 |
| **对比重奏 Contrast** | 紧张/神秘 | 70–90（可变） | 15% | 打击乐重拍或电子脉冲，调性偏移 |
| **高潮 Climax** | 爆发 | 100–140 | 10% | 全编制进入，大鼓+铜管+弦乐强奏 |
| **收束 Outro** | 归于寂 | 40–50 | 5% | 主题动机单音再现，泛音淡出 |

> **网关 `params.duration`** = 各段相加总秒数。示例：30 秒片段可取 Intro 5s + Build 7s + Theme 9s + Contrast 4s + Climax 3s + Outro 2s。

### 参数化传递示例（若网关支持 `structure`/`bpm` 字段）
```json
{
  "prompt": "<上述合并 prompt>",
  "params": {
    "duration": "60",
    "instrumental": true,
    "bpm_range": {"start": 50, "mid": 90, "climax": 120},
    "structure": "intro-build-theme-contrast-climax-outro",
    "sections": [
      {"label": "intro",   "bpm": 50, "instruments": ["guqin", "pad"]},
      {"label": "build",   "bpm": 70, "instruments": ["guzheng", "cello_pad"]},
      {"label": "theme",   "bpm": 90, "instruments": ["dizi", "strings"]},
      {"label": "contrast","bpm": 80, "instruments": ["taiko", "synth_pulse"]},
      {"label": "climax",  "bpm": 120,"instruments": ["orchestra_full", "taiko", "brass"]},
      {"label": "outro",   "bpm": 50, "instruments": ["guqin_harmonic"]}
    ]
  }
}
```
> 若网关不支持结构化参数，将上表融入 prompt 文本末尾：*"段落结构：引子(空灵留白)→铺垫(渐强)→主题(舒展)→对比重奏(紧张)→高潮(爆发)→收束(归于寂)，BPM 区间 50-120，总时长 60 秒。"*
