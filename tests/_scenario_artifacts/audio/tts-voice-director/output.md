# 悬疑播客开场 TTS 配音导演方案

**项目**：单人旁白 | **引擎**：Kokoro 本地 | **参考音色族**：低沉男声（narrator_suspense）
**角色气质**：冷峻、观察者、压抑中的警觉

---

## 一、声音选角结论

| 参数 | 取值 | 依据 |
|------|------|------|
| 基线音色 | `narrator_suspense_male`（Kokoro 目录 ID） | 低沉男声，低频共振足，适合悬疑腔 |
| 备用对比 | `narrator_deep_grave` | 若前者过于平直，换此 ID 增加"地下感" |
| 声线定位 | 胸腔共鸣为主，口腔后部发音，尾音不扬起 | 悬疑感来自"下沉"，不是"紧张上扬" |

> ⚠️ 执行前核实：`test -f references/voice-catalog.md && echo CATALOG-OK`，确认目录中有上述 ID 及对应模型卡。

---

## 二、语速曲线（逐句标注）

```
整体基准：0.85x（慢于日常口播，制造"时间变稠"感）

seg-01 "深夜的城市并不安静"        → 0.90x（起势稍快，建立常态）
       "只是声音都躲进了电缆。"      → 0.75x（骤慢，"躲进"二字拖长，制造诡异感）

seg-02 "服务器机房里，"             → 0.85x（平稳过渡）
       "一台风扇的转速突然快了半拍。" → 0.70x（关键句，"突然"前停半拍，"快了半拍"每个字独立咬出）

seg-03 "三分钟后，"                 → 0.80x（数字略快，暗示倒计时）
       "一台机器下线了，"           → 0.75x（"下线"二字下沉，语气近乎叹息）
       "没有人注意到。"             → 0.65x（最慢，句号处留白 1.5s，让恐惧沉淀）
```

**曲线形态**：↗️ 0.90 → ↘️ 0.75 → ➡️ 0.85 → ↘️↘️ 0.70 → ➡️ 0.80 → ↘️ 0.75 → ↘️↘️ 0.65

## 三、停顿与重音标注

> 符号说明：**【】** = 标点内停顿；**//** = 额外气口（0.4s）；**【bold】** = 重音（音量+15%，时长+1.2x）

```
【深夜的城市】并不安静，//
只是声音都【躲进了】电缆。

服务器机房里，//
一台风扇的转速【突然】【快了半拍】。

三分钟后，//
一台机器【下线】了，
【没有人】注意到。
```

**重音逻辑**：
- "躲进"：动作诡异，重音揭示异常
- "突然 / 快了半拍"：技术细节，重音制造"听诊感"
- "下线 / 没有人"：死亡隐喻，重音压低但清晰，配合最慢语速

**停顿层级**：
- 逗号：0.3s
- 句号（段间）：0.6s
- `//` 处：0.4s（气口，不是标点停顿，用于呼吸感）
- 末句句号后：1.5s 静默（给 outro 音乐进场的空间）

## 四、拼接计划

```
[bgm_intro] fade_in 2s（低频脉冲+环境噪音层，-18dB）
  ↓ 0.5s gap
[seg-01] 主持人声（narrator_suspense_male, 0.85x）
  ↓ crossfade 400ms
[seg-02] 同上音色
  ↓ crossfade 400ms
[seg-03] 同上音色
  ↓ 1.5s 静默（末句留白）
[bgm_outro] fade_in 1s，匹配 intro 风格，与人声 last 2s crossfade 后淡出
```

**格式统一**：所有段落导出为 `pcm_s16le, 24000Hz, mono`，ffmpeg concat `-c copy` 无需重编码。

---

## 五、失败预案

| 风险 | 处置 |
|------|------|
| 音色不够"沉" | 换 `narrator_deep_grave` 重合成整条，不改参数 |
| "躲进"读得过于轻飘 | 改写为"缩进了电缆"或"渗进了电缆"，再合成 |
| 末句留白被 bgm 吞没 | 将 last 2s 人声 volume +3dB，或 bgm fade_in 从 1s 改为 2s |
| 专有名词"服务器/风扇"读错 | 记录进 shownotes 术语表，下次合成前 prep phoneme 表 |
