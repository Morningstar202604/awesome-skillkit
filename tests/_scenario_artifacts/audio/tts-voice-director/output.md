# 悬疑播客旁白配音导演方案

## 基础设定
- **引擎**：Kokoro 本地免费系
- **音色 ID**：`narrator_suspense`（低沉男声，参考目录低中频区、呼吸感明显的声线）
- **角色气质**：冷静观察者，带压抑的紧张感，不说教，只陈述事实

| 段落 | 文本 | 语速 | 停顿策略 | 重音标注 | 情绪标签 |

## 停顿与重音详细标注

```
【seg-01】
深夜的城市并不安静[200ms]，
只是声音都躲进了电缆[300ms]。
→ 重音：并不 / 躲进 / 电缆
→ 语气：陈述中带怀疑，"并不安静"微微加重，暗示反常

【seg-02】
服务器机房里[400ms]，
一台风扇的转速突然快了半拍[300ms]。
→ 重音：服务器机房 / 突然 / 半拍
→ 语气：机械感，"突然"略带惊疑，"半拍"轻读但清晰

【seg-03】
三分钟后[500ms]，
一台机器下线了[600ms]，
没有人注意到[300ms]。
→ 重音：三 / 下线了 / 没有人
→ 语气：最冷的一段，"没有人注意到"降调收尾，留白
```

## 拼接计划

```
[00:00] seg-01 合成（22 秒）
    ↓ crossfade 500ms（消除句间空白）
[00:22] seg-02 合成（18 秒）
    ↓ crossfade 600ms（制造"事件感"停顿）
[00:40] seg-03 合成（20 秒）
    ↓ 末尾静默 2 秒
[00:62] intro 音乐 fade in 3s（低频氛围垫，-18dB）
[01:05] outro 音乐 fade out 5s（匹配 intro 风格）
```

> **ffmpeg 指令模板**（逐段合成后拼接）：
> ```bash
> # 合成每段
> kokoro-tts --voice narrator_suspense --text "..." --speed 0.92 --output seg-01.wav
> # 统一格式后拼接
> ffmpeg -i concat_list.txt -c copy final_intro.wav
> # 加 crossfade
> ffmpeg -filter_complex "[0][1]acrossfade=d=0.5[seg12]; [seg12][2]acrossfade=d=0.6[seg123]" -map "[seg123]" final_narration.wav
> ```
