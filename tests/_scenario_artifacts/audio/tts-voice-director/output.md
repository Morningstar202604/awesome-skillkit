# 悬疑播客旁白配音导演方案

## 1. 角色-声音映射

| 项目 | 配置 |
|------|------|
| 角色 | 单人旁白（无对话者） |
| 气质关键词 | 低沉、冷静、隐约不安、克制 |
| 声音 ID | `narrator_suspense`（Kokoro 本地免费） |
| 音区定位 | 中低频，避免高频明亮感 |
| 全季一致性 | 本段声线写进节目配置，后续悬疑开场沿用 |

---

## 2. 语速曲线与停顿/重音标注

原文分段 + 标注说明：

```
[段落01] 深夜的城市并不安静，只是声音都躲进了电缆。
         语速：0.95（沉稳铺垫）
         标点停顿：逗号 300ms，句号 600ms
         重音：→暗 / 不→安静 / 躲→进
         情绪：低沉陈述，尾句"电缆"收弱不扬

[段落02] 服务器机房里，一台风扇的转速突然快了半拍。
         语速：0.90→渐快到1.00（紧张累积）
         标点停顿：逗号 400ms，句号 700ms
         重音：→突然 / →快了 / →半拍
         情绪："突然"微提音量但不尖叫，"半拍"收短促

[段落03] 三分钟后，一台机器下线了，没有人注意到。
         语速：0.85（缓慢拖长，制造悬置感）
         标点停顿：逗号 500ms，句号 800ms（留白最长）
         重音：→三分钟后 / →没有人
         情绪：冷静到近乎冷漠，"没有人注意到"轻轻落下，余韵留给 silence
```

### 停顿层级汇总

| 符号 | 时长 | 使用场景 |
|------|------|----------|
| 逗号 | 300-500ms | 句内自然换气 |
| 句号 | 600-800ms | 段末留白，越到后段越长 |
| 段间静默 | 1000ms | 段落切换前的呼吸感 |

---

## 3. 拼接计划

```text
[00:00] intro 音乐：低频嗡鸣 + 电子噪音（fade in 2s）
  → seg-01（narrator_suspense，speed=0.95）
    [pause 1000ms]
  → seg-02（narrator_suspense，speed=0.90→1.00 渐变）
    [pause 1000ms]
  → seg-03（narrator_suspense，speed=0.85）
    [pause 1200ms，留悬念余韵]
[00:xx] outro 音乐：同 intro 风格 fade out（与最后一句句号后的静默自然衔接）
```

### 拼接执行要点

- **格式统一**：三段均输出 `16kHz mono 16bit PCM → MP3 128kbps`（Kokoro 本地默认）
- **拼接命令**：
  ```bash
  ffmpeg -i concat:"seg-01.mp3|seg-02.mp3|seg-03.mp3" \
         -af "crossfade=d=500ms:c1=tri:c2=tri" \
         -c:a libmp3lame -b:a 128k output_narration.mp3
  ```
- **音乐叠加**：intro/outro 单独 render 后，用 `ffmpeg amix` 以 `-18dB` 以下音量垫底，不压人声
- **接缝检查**：播放后若发现 seg-02→seg-03 有爆音，将 crossfade 从 500ms 上调至 700ms

## 4. 失败处置预案

| 现象 | 处置 |
|------|------|
| 音色不够"悬疑" | 换 `narrator_deep` 或 `narrator_mystery` 做 A/B 试听对比 |
| 语速整体偏快 | 在标点处手动插入 `silence` 片段强制延长停顿 |
| "半拍"读成" Ban pai " | 改写为"半拍儿"或记录进 shownotes 术语表 |
| 情绪过于平淡 | 回到脚本：将"突然快了半拍"改为"突然——快了半拍"，用破折号强制引擎降速 |
