## Design Spec

```markdown
## Design Spec
- purpose:    独立音乐人单曲数字专辑封面，用于流媒体平台（Spotify/Apple Music等）展示，营造沉浸式、略带悬疑或忧郁的电影氛围。
- platform:   数字专辑封面 / Square 3000×3000px / 1:1 比例
- subject:    画面主体为一个抽象或具象的孤独轮廓（如侧影、背影或局部特写），置于深邃的黑暗背景中；单一强光源从侧上方或侧面打入，形成强烈的明暗对比（Chiaroscuro），光束中可见微尘或烟雾轨迹；环境细节极少，强调留白与负空间。
- style:      电影级摄影、高对比度、低调光（Low-key lighting）、胶片质感、粗颗粒、柔和焦点、极简构图、去数码锐化感
- palette:    主色：深炭黑 (#0a0a0a) 与 纯黑 (#000000) 渐变；辅色：冷调灰 (#2c2c2c) 用于轮廓边缘；强调色：单一暖白光或冷蓝光 (#e0e0e0 或 #a0c4ff) 仅用于光源照射区域；整体低饱和度，无鲜艳彩色。
- text:       层级1（最小）：艺人名称，底部居中或角落，细体无衬线，白色低透明度叠加；层级2（最大）：曲名/专辑名，位于光源焦点附近，简洁字体，白色；总字数 ≤ 6 字（中文）或 ≤ 3 词（英文），避免遮挡主体。若无文字需求则填 none。
- do-not:     禁止出现明显的AI生成痕迹（如过度平滑的皮肤、不自然的边缘光晕、过多细节堆砌）；禁止使用高饱和度霓虹色；禁止多光源导致杂乱阴影；禁止添加无关装饰性元素（如花朵、几何图形）；禁止文字过大破坏画面平衡；禁止背景过于复杂干扰主体。
```
