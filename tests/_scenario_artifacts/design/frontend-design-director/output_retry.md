2. **约束**：有无现有品牌色/字体规范？或者"快、稳、不花哨"是全新的方向，可以自行定？

同时我先基于 brief 给出两个差异化方向供你选，避免直接落到"又一套蓝白卡片"的默认值：

### 方向 A：终端直出（Terminal-First）

| 字段 | 内容 |
|------|------|
| 主题 | 开发者工具在真实终端里跑，页面本身就是终端的延伸 |
| 色板 | 背景 #0D0D0D · 文字 #E8E8E8 · 强调绿 #4ADE80 · 次强调灰 #525252 · 选中高亮 #1A1A1A |
| 字体 | 等宽字体族（JetBrains Mono / Fira Code）贯穿全局——标题、正文、导航全部用等宽，这是选择，不是偷懒 |
| 布局 | 左对齐单栏，像一屏终端输出：命令行式的导航锚点、代码块样式的 feature card、输出日志式的 stats 区 |
| 独特原则 | 页面本身读起来像一段终端 session——用户打开落地页就像打开一个新的 shell |

---

### 方向 B：工程蓝图（Engineered White）

| 字段 | 内容 |
|------|------|
| 主题 | 工具是精密仪器，页面像技术手册——干净、可度量、信息密度高 |
| 色板 | 纸张白 #FAFAF9 · 墨黑 #18181B · 蓝灰 #3F3F46 · 精确蓝 #0EA5E9（仅用于数字与测量标记） |
| 字体 | 标题用几何无衬线（Inter / Space Grotesk），正文用高可读度无衬线（Source Han Sans SC 或思源黑体） |
| 布局 | 严格的网格对齐，类似瑞士国际主义风格——内容区块边界用极细分割线（1px #E4E4E7），没有容器阴影 |
| 独特原则 | 每一个数字、每一个间距都是可量化的——排版本身就是"稳"的表达 |

---

**我的判断**：两个方向都比"默认落地页"更贴合「快、稳、不花哨」，但气质不同——

- **A** 的"不花哨"来自审美克制（终端黑底），**B** 的"不花哨"来自信息密度（网格与度量）。
- **A** 对终端用户的共鸣更直接（他们每天看终端），**B** 的专业感更泛化（类似 Linear/Vercel 的路线但更克制）。
