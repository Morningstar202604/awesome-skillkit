# 留存率数据图表推荐

## 数据形态速览

| 要素 | 取值 |
|---|---|
| 维度 | 月份（12）× 版本（3） |
| 列类型 | 分类（月份，有序） + 分类（版本，无自然序） + 数值（百分比 0–100%） |
| 样本量 | 36 个数值点（小） |
| 意图推断 | 「比较 3 个版本在各个月的留存表现」或「看每个版本的留存随时间变化」 |

## 意图确认

**你这张图想让读者看出什么？** 这决定最终选图。两种常见意图选图不同：

- **意图 A**：「版本 X 比 Y 留存高多少」（强调**比较**）
- **意图 B**：「留存随月份怎么走的」（强调**趋势**）

下面给出按两种意图分别的推荐。

---

## 方案对比

### 意图 A：侧重版本间比较

**方案 1A：分组条形图（推荐）**

- **优点**：同月内 3 根柱子并列，读者可直接比长短；条形编码用**长度**，精度在所有视觉通道里排第一梯队
- **代价**：12 个月 × 3 组 = 36 根柱子，宽度需够；若把月份当横轴标签，12 个标签会挤，建议竖放条形（月份做纵轴）
- **绘图规格**：
  - 纵轴：月份（降序，12 在上方）
  - 横轴：留存率（%），从 0 起，标 0 / 25 / 50 / 75 / 100
  - 颜色：3 版本用区分度高的定性色板（如蓝/橙/绿），图例放右侧
  - 注释：可在最高/最低点加小标签

**方案 1B：带误差带的折线小倍数图**

- 每月一张小折线？不——是**分面**：三列，每列一个版本，每列 12 个月
- **优点**：趋势清晰；单序列 3 张图互不干扰
- **代价**：占用空间大；版本间比较需跨列扫视，不如方案 1A 直观

---

### 意图 B：侧重时间趋势

**方案 2A：多序列折线图（推荐）**

- **优点**：趋势 + 拐点一目了然；3 条线缠绕风险低（≤3 序列）
- **代价**：同月比大小精度低于条形；读者需读数值而非直接比长度
- **绘图规格**：
  - 横轴：月份（升序，Jan→Dec）
  - 纵轴：留存率（%），0 起（**必须 0 起，百分比切勿截断**）
  - 颜色：3 版本各一色，每条线直接标名字（≤5 序列用直接标注，省图例）
  - 网格：浅灰横向网格线辅助读数
  - 注释：如有版本发布日期或大版本更新，加垂直参考线

**方案 2B：堆叠面积图**

- **不推荐**，原因见下「禁忌」部分

## 不该用的图（重点）

| 图型 | 为什么不合适 |
|---|---|
| **饼图 / 环形图** | 3 个版本是独立的时序序列，不是「部分占整体」；饼图比较角度的精度远低于条形/折线，读者很难看出 62% vs 65% 的差别 |
| **双 Y 轴图** | 3 个版本量纲相同（都是百分比），强行双 Y 轴只制造混乱 |
| **3D 柱状图** | 透视效应会系统性放大近端柱子，产生误读；毫无信息增益 |
| **矩阵热力图** | 36 格太稀疏，视觉冲击力弱；保留 12 个月 × 3 版本的细节更好 |
| **雷达图** | 3 轴对 12 个月无意义；角度比较精度在七类视觉编码里排倒数 |
| **箱线图** | 箱线图用于展示分布（大量重复测量），你只有 3 个独立序列、每个序列 12 个点，不适用 |

---

## 推荐结论

| 意图 | 首选 | 次选 |
|---|---|---|
| 比版本之间谁留存高 | 分组条形图（方案 1A） | 小倍数折线图（方案 1B） |
| 看留存随月份怎么走 | 多序列折线图（方案 2A） | — |

**一个决策捷径**：读者最可能问的问题是什么？
- 「版本 A 和 B 谁好？」→ 条形图
- 「版本 A 留存在下滑吗？」→ 折线图
