# 图表推荐：12 个月 × 3 版本留存率

## 意图复述
「对比三个版本在 1–12 个月的留存轨迹，判断哪个版本长期留存更好。」

## 数据形态

| 要素 | 取值 |
|---|---|
| 维度数 | 2（月份 × 版本） |
| 列类型 | 日期（月份，有序分类）× 数值（百分比 0–100%） |
| 分类基数 | 版本 = 3；月份 = 12 |
| 样本量 | 36 个点（极小） |
| 缺失 | 无 |

**归一化结构**：时间序列 × 3 组小倍数对比。

## 查词库

意图类型：**看趋势 + 比大小**（同时含）。

去 `references/chart-selection.md` 第二节查表：
- 「时间 + 数值」→ **折线图**（首选）
- 「3 条序列」→ 未超限，无需小倍数图

命中禁忌：
- 禁止双 Y 轴（这里不涉及多量纲，但以防万一）
- 禁止 3D
- 禁止截断 y 轴不标注

## 方案对比

### 方案 A：折线图（推荐）
- **优点**：趋势最直观，拐点 / 斜率一目了然；3 条序列完全可读；月份有序轴保证阅读顺序正确。
- **代价**：若用户只想「比某个月的大小」而非趋势，条形图精度更高；但此处「看留存演变」才是核心问题。
- **为什么它赢**：留存率的本质是「随时间衰减的轨迹」，折线恰好编码了这个语义。

### 方案 B：分组柱状图
- **优点**：每个月内三版本可直接比长短，精度略高于折线。
- **代价**：12 个月 × 3 柱 = 36 根柱子，视觉噪音大；趋势感被柱体打断；读者需要来回扫视比较跨月趋势。
- **适用场景**：如果受众只关心「第 12 个月谁最强」而非完整轨迹，才选这个。

### 方案 C：小倍数折线图（3 张 1×12 子图）
- **优点**：每条折线独占空间，互不缠绕；适合后续放大到 10+ 版本时扩展。
- **代价**：跨版本同月对比需要视线跳跃，不如单图并排直观；当前只有 3 个版本，过度设计。
- **适用场景**：版本数 >5 或需要单独打印每张图时。

**推荐：方案 A**。

## 不该用的图及理由

| 图型 | 为什么不合适 |
|---|---|
| **饼图** | 保留率是**顺序数据**（第 1 月 → 第 12 月），饼图编码的是「构成」而非「趋势」；3 个饼共 12 个月等于 36 块扇区，完全不可读。 |
| **堆叠面积图** | 会暗示「总量」语义，而留存率各自独立（不是同一个池子的切割）；多层面积互相遮挡，趋势更模糊。 |
| **气泡图 / 散点图** | 月份是有序维度，散点会丢掉顺序信息；读者需要自行脑补 x 轴的连续性。 |
| **双 Y 轴图** | 3 个版本量纲相同，双 Y 轴纯属画蛇添足，且词库第五节明确列为禁忌。 |
| **3D 柱状 / 折线** | 透视变形会系统性扭曲长度感知，词库第五节第 5 条禁忌。 |
| **雷达图** | 12 个维度撑不起有意义的多边形；各顶点连线没有方向含义，易产生误导的「面积大就好」直觉。 |

## 绘图规格

| 规格项 | 取值 |
|---|---|
| 轴 | x 轴：月份 1–12 升序（固定顺序，不按值排序）<br>y 轴：0–100%（从 0 起，**不得截断**） |
| 单位 | y 轴标注「留存率 (%)」；数字用百分比格式，如 `45%` 而非 `0.45` |
| 图例 | ≤5 条序列 → **直接在线标注**（在每条折线末端标签，而非靠图例翻找） |
| 注释 | 标注关键事件：如「v2 上线于第 4 月」「v3 优化于第 8 月」用浅灰垂直参考线 + 文字注释 |
| 排序 | 月份固定升序；版本按最终留存率降序排列（v1 / v2 / v3 中谁最后高谁放最上方），便于一眼读出优劣 |
| 缺失 | 无缺失，无需说明 |
| 配色 | 定性 3 色板，如 `#2C7BB6`（蓝）/ `#D7191C`（红）/ `#FDAE61`（橙）；三条线粗细一致；背景纯白，网格线浅灰 15% 不透明度 |
| 标记点 | 每个数据点加一个小圆点（半径 3px），强化具体数值位置，帮助精确读数 |
