# 图表推荐：12 个月 × 3 版本留存率

## 意图推断与数据形态

**分析意图**：比较 3 个版本在各月份的留存表现差异（趋势 + 对比）。

**数据形态**：

| 要素 | 取值 |
|---|---|
| 维度数 | 2（月份 × 版本） |
| 列类型 | 时间（月份，12 个有序类别）+ 分类（版本，3 个） |
| 数值 | 百分比（0%–100%） |
| 基数 | 月份 12、版本 3、共 36 个数据点 |
| 样本量 | 36 行（极小） |

---

## 方案对比

### 方案 A：多序列折线图（推荐）

- **优点**：月份天然升序，折线能直观呈现留存曲线形态（陡降 / 平缓）；3 条序列缠绕风险低，读者可一眼读出"哪个版本留存更好、哪个月份出现拐点"。
- **代价**：若三条线在 40%–60% 区间内过于接近，局部差异需放大图例或点标注才能看清；柱子/线条宽度需适中，避免重叠遮挡。
- **适配理由**：时间序列 + 少量序列（≤5）是折线图的最典型场景，视觉编码精度中等偏上，足以区分 3 条曲线的差异。

### 方案 B：分组柱状图

- **优点**：同一月份内 3 个版本的数值可直接比长短，**精度高于折线图**（人类对长度的判断优于对位置差别的判断）；适合强调"某个版本在某个月碾压其他"的瞬间。
- **代价**：12 个月 × 3 根柱 = 36 根柱，密度尚可但已接近可读上限；**趋势被切断**——读者必须脑内连线才能看出整体走向，牺牲了"留存曲线"的直觉。
- **适配理由**：当业务方更在意"某月绝对谁高"而非"整条曲线形态"时可选。

### 方案 C：小倍数折线图（3 张子图，每张一个版本）

- **优点**：彻底消除序列间缠绕问题；每个版本独立缩放 y 轴，微小差异也可见；适合深度对比各版本自身趋势。
- **代价**：**无法直接跨版本对比**——三张图的 y 轴刻度若不一致，读者必须扫视才能比较；空间占用约为单图的 3 倍。
- **适配理由**：当 3 个版本的留存量级差异很大（如 A 在 80%、B 在 30%）时，合并到同一坐标系会压缩弱势版本的可视度。

---

## 推荐结论

**首选方案 A（多序列折线图）**，原因：

1. 月份是**有序时间轴**，折线天然匹配其连续语义；
2. 3 条序列远低于缠绕阈值（≤5 条），可读性有保障；
3. 留存曲线的核心洞察是**斜率变化**（哪个月流失骤增），折线对此最敏感。

**次选方案 C**，仅当三个版本量级相差悬殊时使用。
**备选方案 B**，仅在业务强调"逐月横向排名"而非"整体趋势"时考虑。

## 不该用的图型及原因

| 图型 | 为什么不用 |
|---|---|
| **饼图** | 36 个百分比无法塞进一个饼；即使拆 3 个饼（每月一个），12×3=36 张饼图不可读，且角度比较精度远低于长度。 |
| **堆叠面积图** | 保留率是独立度量，堆叠暗示"总量由三部分构成"的语义错误；且 3 层面积图的下层被严重遮挡。 |
| **双 Y 轴折线图** | 没有理由把 3 条留存量纲不同的序列分到两个 Y 轴；强行分轴会引入数量级扭曲，且读者难以对齐阅读。 |
| **3D 柱状图 / 3D 折线图** | 透视变形会产生系统性误读（近处元素被放大）；数据可视化领域公认应避免 3D。 |
| **热力图** | 36 个格子虽可排列，但月份-版本矩阵中"趋势"的连续语义被破坏，读者只能看色块深浅，无法读斜率。 |
| **雷达图** | 12 个轴对应 12 个月，每条版本曲线变成 12 边形；形状比较精度极低，且月份之间的序关系被径向布局弱化。 |
| **等高线 / 气泡图** | 完全不适配：无二维空间坐标，只有时间-分类结构。 |

## 绘图规格

| 规格项 | 取值 |
|---|---|
| **轴** | x 轴：1–12 月，升序，等距；y 轴：0%–100%，**必须从 0 起**（百分比不可截断） |
| **单位** | y 轴标注"留存率 (%)"，刻度间隔 20%（0 / 20 / 40 / 60 / 80 / 100） |
| **图例** | 置于图右上或顶部居中，用版本名称直标在线段末端（≤5 条时可省图例，直接用标签） |
| **注释** | 标注关键月份：如"第 3 月所有版本骤降"（垂直虚线 + 文字说明） |
| **排序** | x 轴固定为 1–12 月升序，**不可重排**（否则破坏时间语义） |
| **缺失** | 若有某月某版本缺失，用虚线连接或在点处标注"N/A"，不可静默插值 |
| **配色** | 定性 3 色板（蓝/橙/绿或深色系），**强调的序列加深、其余变浅**；避免红绿配对（色盲友好）；三条线颜色区分度要高 |
| **点标记** | 建议保留数据点圆点，便于读数；线条粗细 1.5–2pt |
| **网格** | y 轴方向加浅灰水平网格线（每 20% 一条），便于目测对齐 |
| **字体** | x 轴标签旋转 0°（月份本身短），字号 10–11pt |
| **标题** | "各版本月度留存率对比（1–12 月）" |
